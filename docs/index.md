    Claude 데스크톱 앱 설치, 교육용 팀 계정 로그인, 가상화 확인까지 당일 함께 합니다.
    IT 담당자에게는 설치 페이지 링크를 미리 보내 가상화 확인을 부탁하세요.

임원 Claude 실습 과정 4~6회차의 따라 하기 가이드입니다. 오프라인 3시간씩 3번, 각자 자기 회사로 실습합니다.

!!! tip "이 사이트 쓰는 법"
    - 회색 상자의 지시문은 오른쪽 위 **복사 버튼**으로 복사해서 Claude에 붙여 넣으세요. [대괄호] 부분만 내 회사 내용으로 바꾸면 됩니다.
    - 예시는 교육용 가상 회사 **(주)한빛정밀** 기준입니다.
    - 교육이 끝나도 이 링크로 다시 들어와 지시문을 그대로 다시 쓸 수 있습니다.
