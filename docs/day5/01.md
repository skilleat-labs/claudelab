# 이 가이드 쓰는 법

오늘은 각자 자기 회사로 실습합니다. 가이드의 예시는 가상 회사 (주)한빛정밀 기준이고, 여러분은 [대괄호] 부분만 자기 회사 내용으로 바꿔 넣으면 됩니다.

| 표시 | 뜻 |
| --- | --- |
| 경로 | 어느 화면의 어느 메뉴를 누르는지. 영어 메뉴 이름은 공식 문서 기준입니다. |
| 입력 | 그대로 복사해 붙여 넣는 지시문. [우리 회사], [경쟁사 A]처럼 대괄호만 바꿉니다. |
| 기대 결과 | 제대로 됐을 때 화면에 보이는 것 |
| 주의 / 팁 | 자주 막히는 곳, 더 잘 쓰는 법 |
| (화면 확인) | 메뉴 이름이나 회사 계정(Team/Enterprise)에서의 동작이 문서로 확실하지 않은 곳. 실제 화면에서 비슷한 이름을 찾으세요. |
| ☐ 완료, 메모 | 끝나면 체크하고, 실제 메뉴 이름이나 떠오른 아이디어를 적습니다. |

## Windows, Mac 용어와 단축키

| 하는 일 | Windows | Mac |
| --- | --- | --- |
| 파일, 폴더 보는 창 | 파일 탐색기 (Windows 키 + E) | Finder (Dock의 웃는 얼굴 아이콘) |
| 오른쪽 클릭 메뉴 | 마우스 오른쪽 클릭 | Control + 클릭 (트랙패드는 두 손가락 클릭) |
| 새 폴더 | 바탕화면에서 마우스 오른쪽 › 새로 만들기 › 폴더 | 바탕화면에서 Control + 클릭 › 새로운 폴더 (⌘ + Shift + N) |
| 복사 / 붙여 넣기 | Ctrl + C / Ctrl + V | ⌘ + C / ⌘ + V |
| 전체 선택 | Ctrl + A | ⌘ + A |
| zip 압축 풀기 | zip에서 마우스 오른쪽 › 압축 풀기(모두 추출) | zip을 더블클릭 |
| 창 두 개 나란히 | Windows 키 + ← / → | 창 왼쪽 위 초록색 버튼에 마우스를 올려 왼쪽 / 오른쪽 배치 |
| 화면 캡처 | Windows 키 + Shift + S | ⌘ + Shift + 4 (영역 선택) |
| .md 파일 열기 | 마우스 오른쪽 › 연결 프로그램 › 메모장 | Control + 클릭 › 다음으로 열기 › 텍스트 편집기 |

!!! tip "화면이 가이드와 다를 수 있습니다"
    - 2026년 9월 16일부터 Chat과 Cowork가 하나의 Claude 화면으로 합쳐지고 있습니다. 개인 요금제가 먼저 바뀌고, 이 과정의 팀 계정(Team)은 나중에 바뀝니다.
    - 그래서 여러분 화면에는 'Cowork' 탭이 아직 따로 있을 수도, 이미 합쳐져 있을 수도 있습니다. 메뉴 이름이 조금 달라도 같은 기능을 찾으면 됩니다.

!!! warning "보안: 같은 조직에 다른 회사 참가자도 있습니다"
    - 이 과정의 계정은 운영 측이 만든 팀 조직 하나를 여러 회사, 기관 참가자가 함께 씁니다.
    - 넣어도 된다: 홈페이지, 보도자료, 기사, 업계, 정책 리포트, 공시(상장사), 내가 말로 알려 줄 수 있는 수준의 회사 정보
    - 넣지 않는다: 내부 문서 원본, 미공개 수치, 계약, M&A, 개인 인사 정보, 주민번호, 비밀번호, 계정 정보
    - 공유 버튼(Project 공유, Artifact 공유, 조직에 공개)은 쓰지 않습니다. 공유하면 다른 회사 참가자에게 보일 수 있습니다.
    - 계정은 교육이 끝나고 일정 기간 뒤 회수됩니다. 결과물은 내 PC의 작업 폴더에 저장해 둡니다.
    - 보내기, 삭제, 공유처럼 되돌릴 수 없는 일은 Claude가 승인을 물으면 내용을 읽고 누르세요.
