## 4회차를 못 들었다면: 15분 따라잡기

4회차에서 만든 작업 폴더와 스킬이 있어야 오늘 실습이 이어집니다. 아래 순서대로 하면 4회차를 들은 분과 같은 상태가 됩니다. 오늘은 예시 회사 (주)한빛정밀 자료로 진행합니다.

**만들어 둘 폴더 구조** 

| 폴더 | 들어가는 것 | 언제 쓰나 |
| --- | --- | --- |
| AI전략기획실 | 작업 폴더 (바탕화면). Cowork에 이 폴더 하나만 연결 | 매 실습 |
| ├ 00_회사자료 | 회사 자료 원본. 오늘은 한빛정밀 시연자료 + 주간업데이트 폴더 | 5회차 1, 2, 3교시 |
| ├ 01_산업경쟁사 | 4회차 산업, 경쟁사 분석 결과 | 5회차 3교시 브리핑 |
| ├ 02_밸류체인 | 4회차 밸류체인 진단, 핵심과제123_정의서 | 6회차 신사업 |
| ├ 03_브리핑 | 매일 아침 예약 작업 브리핑 | 5회차 3교시부터 |
| ├ 04_보고장표 | 주간 업데이트, 보고서 | 5회차 2교시 |
| ├ 05_신사업전략, 06_최종패키지 | 6회차 결과물 | 6회차 |
| └ 07_내스킬 | 스킬 사본, 스킬목록, 업로드용 zip | 5회차 2교시 |

### 0. 4회차 따라잡기

[:material-download: 한빛정밀_시연자료.zip](../files/hanbit-demo-materials.zip){ .md-button .md-button--primary }
[:material-download: 산업분석 백업 스킬](../files/industry-competitor-analysis.zip){ .md-button .md-button--primary }
[:material-download: 밸류체인진단 백업 스킬](../files/value-chain-diagnosis.zip){ .md-button .md-button--primary }

1. 바탕화면에 'AI전략기획실' 폴더를 만들고, Claude 데스크톱 › 새로 생성 › Cowork에서 이 폴더를 연결합니다.
2. 위 첫 번째 버튼으로 한빛정밀 시연자료를 받아 압축을 풀고, 안의 파일을 모두 AI전략기획실 › 00_회사자료에 넣습니다. (폴더는 다음 단계에서 Claude가 만들어도 됩니다)
3. 아래 지시를 보내 하위 폴더와 폴더 지침을 한 번에 만듭니다.
4. 백업 스킬 2개(산업분석, 밸류체인진단)를 받아 사용자 지정 › Skills › + 추가 › 업로드로 올립니다. 압축을 풀지 않고 zip 그대로 올립니다.
5. 새로 생성으로 새 작업을 열고 / 를 쳐서 두 스킬이 보이는지 확인합니다.

**입력, 그대로 복사해 보내세요**

```text
이 폴더(AI전략기획실) 안에 하위 폴더 8개를 만들어줘: 00_회사자료, 01_산업경쟁사, 02_밸류체인, 03_브리핑, 04_보고장표, 05_신사업전략, 06_최종패키지, 07_내스킬. 이미 있으면 건너뛰어.

그리고 아래 내용을 이 폴더의 폴더 지침으로 저장하고 보여줘.
이 폴더는 (주)한빛정밀(가상 회사) 전략기획실의 작업 폴더다.
- 결과물은 한국어로, 임원 보고용으로 짧고 명확하게 쓴다.
- 모든 숫자에 출처(파일명 또는 링크)와 날짜를 단다. 확인 못 한 숫자는 지어내지 말고 [확인 필요]로 둔다.
- 결과 파일은 알맞은 하위 폴더(01~07)에 저장한다.
- 회사 정보는 00_회사자료 파일을 기준으로 한다. 원본 파일은 고치거나 지우지 않는다.
- 보내기, 삭제, 공유는 실행 전에 반드시 나에게 묻는다.
```

!!! success "기대 결과"
    - AI전략기획실 안에 00~07 폴더 8개와 폴더 지침이 생긴다.
    - / 를 치면 industry-competitor-analysis, value-chain-diagnosis가 보인다.

!!! tip "4회차 결과물이 없어도 됩니다"
    - 01_산업경쟁사, 02_밸류체인이 비어 있어도 5회차는 진행됩니다. 3교시 브리핑은 00_회사자료를 기준으로 씁니다.
    - 6회차 전에 '/value-chain-diagnosis 00_회사자료로 한빛정밀 밸류체인 진단하고 핵심과제123_정의서를 02_밸류체인에 저장해줘'를 한 번 돌려 두면 6회차 신사업 실습이 이어집니다.
