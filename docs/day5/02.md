# 시작 전 체크

커넥터와 메모리는 회사 관리자 설정에 따라 안 보일 수 있으니 시작 전에 확인하세요.

| 확인할 것 | 어디서 | OK |
| --- | --- | --- |
| 앱 최신 버전, 회사 계정 로그인 | 메뉴 › 업데이트 확인 후 재시작 | ☐ |
| 4회차 폴더와 결과물이 그대로 있다 | AI전략기획실 › 01_산업경쟁사, 02_밸류체인 | ☐ |
| 스킬 2개가 켜져 있다 | Customize › Skills › industry-competitor-analysis, value-chain-diagnosis | ☐ |
| Google 커넥터 3개가 목록에 보인다 | 입력창 + › Connectors › Gmail, Google Calendar, Google Drive (회사 계정은 관리자가 먼저 켜야 함) | ☐ |
| 메모리 메뉴가 보인다 | Settings › Memory (회사 계정은 기본 꺼짐, 관리자 허용 필요) | ☐ |
| 예약 작업 메뉴가 보인다 | 왼쪽 메뉴 › Scheduled | ☐ |
| 회사 CI 색상 hex, 글꼴, 로고 파일 | 로고 파일은 00_회사자료에 'logo.png'로 넣어 두기 | ☐ |
