# 3교시 — 보고서 양식 스킬 → 경영진 보고 장표

**시간** 16:10–17:00 (실습 16:30–17:00)

**목표** 회사 공식 템플릿이 없으므로, 우리 회사 CI와 보고 규칙을 스킬로 만들어 어떤 문서든 같은 양식으로 나오게 한다.

!!! success "이 교시의 결과물"
    - ① 보고서양식 스킬 (exec-report-style, 우리 회사 CI)
    - ② 04_보고장표/경영진보고_5장.pptx (제목 = 결론)
    - ③ 인포그래픽 1장 (Artifact)
    - ④ 숫자 원천 대조표

### 3-1. 우리 회사 양식 규칙 정하기

1. 아래 표를 먼저 손으로 채웁니다. 모르는 칸은 비워 두고 Claude에게 제안받습니다.
2. 색상 hex 코드는 회사 홈페이지, 브랜드 가이드에서 찾습니다. 로고 이미지를 올리고 "이 로고의 주요 색 hex 코드를 알려줘"라고 물어도 됩니다.

| 항목 | 우리 회사 값 | 한빛정밀(가상) 예 |
| --- | --- | --- |
| 메인 색 (제목, 표 머리글) | # | #1F3B66 (네이비) |
| 강조 색 (우리 회사 데이터) | # | #1D6FE0 (블루) |
| 경고 색 (위험, 미달, 한 장에 1곳) | # | #C0392B (레드) |
| 글꼴 (제목 / 본문) |  | 맑은 고딕 Bold / 맑은 고딕 |
| 숫자 표기 |  | 억 원, 천 단위 쉼표, 비율 소수점 1자리, 증감은 %p, 추정은 (E) |
| 로고, 보안 표시 |  | 00_회사자료/logo.png, 모든 쪽 아래 '대외비' |

### 3-2. 헤드라인 장표 5장 요청 (PPTX)

회사 템플릿이 없으니, 먼저 우리 규칙을 담아 장표를 한 번 만들고 마음에 들게 고친 뒤 그 양식을 스킬로 저장합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
오늘 아침 브리핑(03_브리핑)과 02_밸류체인의 핵심과제123_정의서로 경영진 보고 장표 5장을 PPTX로 만들어줘.
보고 목적: 다음 경영회의에서 [핵심 과제 1번]의 담당 조직과 첫 90일 계획을 승인받는 것.

<브랜드>
- 메인 색 #[000000], 강조 색 #[000000], 경고 색 #[000000] (경고 색은 위험에만, 한 장에 1곳), 배경 흰색
- 글꼴: 제목 [맑은 고딕] 28pt 굵게, 본문 14pt 이상
- 로고: 00_회사자료/logo.png를 표지 오른쪽 위에. 없으면 회사명 글자로. 모든 장 아래에 '[대외비]'
</브랜드>

<숫자 표기>
- 금액은 억 원, 천 단위 쉼표 (예: 12,400억 원), 비율은 소수점 1자리, 증감은 ▲▼와 %p
- 추정치는 (E), 모든 장 아래에 출처와 기준일 한 줄
</숫자 표기>

<제목 규칙>
- 모든 제목은 결론 한 문장(헤드라인). '현황', '검토' 같은 명사형 제목 금지. 40자 이내, 마침표 없음.
- 한 장에 메시지 하나: 제목 = 결론, 본문 = 근거 3개, 맨 아래 = 출처 한 줄
</제목 규칙>

<구성, 5장>
① 결론과 요청 사항 ② 현황과 문제 ③ 원인과 근거 ④ 대안 비교와 권고 ⑤ 실행 계획, 리스크, 요청할 결정
</구성>

'경영진보고_5장'으로 04_보고장표 폴더에 저장해줘.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    - 메인 #1F3B66 (네이비), 강조 #1D6FE0 (블루), 경고 #C0392B (레드)
    - 제목 예: "미국 관세로 영업이익이 연 최대 280억 원 줄 수 있다"

!!! success "기대 결과"
    PPT 5장, 각 장 제목이 결론 문장이고 우리 회사 색으로 되어 있다.

!!! tip "팁"
    제목만 넘겨 읽어 보세요. 다섯 제목이 하나의 이야기로 이어지면 잘된 것입니다.

### 3-3. 1~2번 고치기

1. 색, 글꼴, 숫자 표기, 구성 중 마음에 안 드는 것을 고칩니다. 아래는 예시입니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
두 가지만 고쳐줘. ① [예: 표 머리글은 메인 색 바탕에 흰 글씨로] ② [예: 3장 근거를 차트 1개 + 숫자 3개로]. '경영진보고_5장_v2'로 저장해줘.
```

### 3-4. "이 양식을 보고서양식 스킬로 만들어줘"

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 고친 장표의 양식을 보고서양식 스킬로 만들어줘.
- 이름: exec-report-style
- 설명: 경영진 보고 장표, 문서, 인포그래픽을 만들 때 [우리 회사] 보고 양식(헤드라인 제목, 한 장 한 메시지, 색, 글꼴, 숫자 표기)을 적용한다. 보고서, 장표, 양식 통일 요청 시 사용.
- 색 hex, 글꼴, 숫자 표기, 제목 규칙, 5장 구성, 내가 고친 것을 모두 넣어줘.
- 1장 보고서(Word) 구성도 넣어줘: 결론 제목 → 핵심 3줄 → 근거 표 → 권고와 요청 사항 → 출처
보여주고 내가 확인하면 저장해줘.
```

!!! success "기대 결과"
    Customize › Skills에 exec-report-style이 켜져 있고, 색상 규칙에 우리 회사 hex 값이 들어 있다.

!!! tip "팁"
    막히면 강사 기본 스킬을 올리고(Customize › Skills › + › Upload › exec-report-style.zip) "이 스킬의 색 hex 값과 글꼴을 우리 회사 값으로 바꿔줘"라고 합니다.

### 3-5. 인포그래픽 1장 (Artifact)

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
오늘 아침 브리핑을 CEO가 30초 안에 보는 인포그래픽 한 장으로 만들어줘.

1. 맨 위: 결론 한 문장 (보고서양식 스킬의 제목 규칙)
2. 가운데: 이슈 3개를 영향 크기 순으로, 매출, 원가, 고객, 공급망 아이콘
3. 오른쪽: 권고 액션 3개와 담당, 기한
4. 맨 아래: 출처와 기준일

숫자는 브리핑 원문에 있는 것만 써. 새 숫자를 만들지 마.
```

!!! tip "팁"
    - Artifact가 안 되는 화면이면 HTML 또는 PNG 파일로 04_보고장표에 저장해 달라고 합니다.
    - "새 숫자를 만들지 마" 한 줄이 사고를 막습니다.

### 3-6. 숫자 원천 대조 검증

Anthropic 재무팀은 이사회 자료의 모든 숫자가 하나의 원천에서 나왔는지 Claude로 점검합니다. 고치기 전에 목록부터 받고, 판단은 내가 합니다.

1. 목록에서 숫자 2개를 골라 원천 파일을 직접 열어 확인합니다.
2. 어느 값이 맞는지 정해 "[숫자]는 [원천 파일] 값으로 고쳐서 v3로 저장해줘"라고 지시합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 장표 5장과 인포그래픽에 나온 숫자를 모두 표로 뽑아줘.

1. 숫자마다 원천 파일과 위치 (KPI 파일, 브리핑)
2. 원천과 다르거나 원천이 없는 숫자는 빨간색
3. 같은 숫자가 장마다 다르게 쓰인 곳

고치지 말고 목록만 먼저 보여줘.
```
