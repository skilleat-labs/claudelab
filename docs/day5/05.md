# 1교시 — Claude 기본기

**시간** 14:00–15:00 (같이 하기 14:20–14:27, 14:33–14:43, 14:52–15:00)

**목표** 지난 시간에 해 본 Chat과 Cowork, 화면을 복습한다. 스킬이 모인 사용자 지정 화면을 둘러보고 공식 스킬로 실제 일을 하나 해 본다. Claude가 무엇을 기억하고 무엇을 잊는지(컨텍스트, 지침, 메모리, 스킬) 눈으로 확인한다.

!!! success "이 교시의 결과물"

    - ② 사용자 지정 둘러보기

### 1-1. 복습: Chat과 Cowork, 무엇이 다른가

|  | Chat, 묻고 답하기 | Cowork, 일 맡기기 |
| --- | --- | --- |
| 무엇을 보나 | 내가 올린 파일만 | 연결한 내 PC 폴더 전체 |
| 결과는 어디에 | 대화창 안 | 내 폴더에 파일로 저장 |
| 잘하는 일 | 짧은 질문, 아이디어, 초안 | 자료 읽고 정리해 문서 만들기, 여러 단계 일, 스킬, 예약 작업 |

!!! example "4회차에 이미 해 봤습니다"
    4회차 첫 시간에 Cowork에 AI전략기획실 폴더를 연결해 주고 일을 맡겼습니다. Claude가 폴더의 자료를 직접 읽었고, 결과물이 그 폴더에 파일로 저장됐습니다. 그것이 Cowork입니다.

!!! note "복습: 우리는 왜 웹이 아니라 데스크톱 앱을 쓰나"
    - 웹(claude.ai)에서도 묻고 답하기는 됩니다. 하지만 내 PC 폴더에는 손이 닿지 않습니다.
    - 4회차에 설치한 앱이 있으니까 바탕화면 AI전략기획실의 PDF, 엑셀을 Claude가 직접 읽고, 결과물을 Word, 엑셀로 내 폴더에 바로 저장합니다. 4회차 결과물이 모두 폴더에 있는 이유입니다.
    - 오늘 3교시의 예약 작업(매일 아침 브리핑)도 앱에서 만듭니다.

**Cowork에서 폴더를 고르지 않으면?** 

|  | 폴더 없이 | 폴더를 고르면 |
| --- | --- | --- |
| 어디서 일하나 | Claude 작업 공간에서만 | 고른 폴더 안에서 |
| 내 PC 파일 | 못 읽는다 (대화창에 올린 파일만) | 폴더 안 파일을 직접 읽고 쓴다 |
| 결과물 | 대화창에서 내려받기. 대화를 닫으면 다시 찾기 어렵다 | 폴더에 파일로 남아 다음 작업에서 이어서 쓴다 |

!!! warning "폴더 = 권한"
    고른 폴더 밖은 보지 못하고, 고른 폴더 안은 모두 읽고 쓸 수 있습니다. 바탕화면 전체나 문서 폴더 전체는 연결하지 않고, 작업용 폴더 하나만 연결합니다. 폴더 없이 시작했을 때 화면은 계정마다 다를 수 있습니다. (화면 확인)

**파일로 받을까, 화면(아티팩트)으로 볼까?** 

|  | 파일 (Word, 엑셀, PPT) | 아티팩트 (화면) |
| --- | --- | --- |
| 어디에 남나 | 내 폴더 (AI전략기획실) | 대화 옆에 바로 뜨고, 왼쪽 메뉴 아티팩트에 모인다 |
| 무엇을 하나 | 고치고, 결재 올리고, 메일로 보낸다 | 눌러 보고, 숫자를 바꿔 보고, 같이 보며 이야기한다 |
| 잘 맞는 것 | 보고서, 회의록, 회사 양식 문서, 보관용 자료 | 대시보드, 인포그래픽, 비교표, 계산기, 도식 |
| 이렇게 요청 | "Word로 04_보고장표에 저장해줘" | "한 장짜리 대시보드로 보여줘" |

!!! tip "고르는 기준"
    남에게 보내고 보관할 것은 파일, 지금 같이 보며 이야기할 것은 아티팩트. 둘 다 필요하면 "대시보드로 보여주고, 엑셀로도 저장해줘". 아티팩트의 공유 버튼은 교육 계정에서 누르지 않습니다.

### 1-2. 복습: 화면 한 바퀴 + 사용자 지정 둘러보기 (같이 하기 ①)

메뉴가 어디 있는지 알면 막혔을 때 혼자 찾아갈 수 있습니다. 앞의 '화면 지도 (참고)' 페이지의 ③ 사용자 지정 화면 표를 옆에 띄워 두고 하나씩 눌러 봅니다.

!!! abstract "경로"
    왼쪽 메뉴 › 사용자 지정 (영어 화면: Customize)

1. 새로 생성을 누르고 Cowork에 폴더 AI전략기획실이 연결돼 있는지 봅니다.
2. 왼쪽 메뉴 사용자 지정을 누르고 Skills, 커넥터, 플러그인 탭을 차례로 눌러 봅니다.
3. 탭마다 내 항목과 탐색을 바꿔 봅니다. 내 항목은 내 계정에 있는 것(Anthropic 기본 제공 + 내가 '내 전체'로 저장하거나 올린 것), 탐색은 남이 만든 것입니다.
4. 오른쪽 위 + 추가를 눌러 메뉴만 봅니다. 고르지 않습니다.
5. 왼쪽 아래 내 이름 › 사용량, 언어(한국어)를 확인합니다.

!!! success "기대 결과"
    - 입력창 근처에 AI전략기획실이 보인다.
    - 사용자 지정의 탭 3개와 내 항목, 탐색을 눌러 봤다.

!!! warning "주의"
    - 위쪽 &lt;/&gt; 아이콘은 개발자용 Claude Code입니다. 들어갔으면 위쪽 말풍선 아이콘을 누릅니다.
    - + 추가 › 마켓플레이스 추가는 외부 출처를 통째로 연결하는 기능이라 쓰지 않습니다.

!!! tip "스킬을 부르는 두 가지 방법"
    - 알아서: 맞는 일이 오면 Claude가 스킬 설명을 보고 스스로 꺼내 씁니다.
    - 직접: 입력창에 / → 스킬 이름 고르기 → 하고 싶은 일 한 줄. 진행 화면에 스킬 이름이 보이면 그 스킬을 쓴 것입니다.

!!! note "시나리오: 상반기 실적, 목표와 어디서 벌어졌나"
    - 상반기가 끝났습니다. 다음 주 경영회의에서 목표 대비 실적을 보고해야 합니다. 어디서 얼마나 벌어졌는지, 왜 그런지, 하반기에 무엇을 봐야 하는지.
    - 재무팀이 매번 하는 '차이 분석'을 Anthropic이 만든 Finance 스킬로 해 봅니다. 파일은 4회차에 받은 한빛정밀 경영목표 KPI 엑셀이고, 모두 같은 파일로 해서 끝나고 결과를 비교합니다.

### 1-3. 공식 스킬로 일해 보기, 상반기 차이 분석 (같이 하기 ②)

스킬은 업무 매뉴얼입니다. 꼭 내가 만들어야 하는 것은 아닙니다. 남이 잘 만들어 둔 공식 스킬을 가져다 쓸 수도 있습니다.

!!! abstract "경로"
    사용자 지정 › Skills › 탐색 › Finance › +  →  새로 생성 › Cowork, 폴더 AI전략기획실

1. 사용자 지정 › Skills › 탐색에서 Finance를 찾아 '+'로 설치합니다.
2. 새로 생성을 누르고 Cowork에 폴더 AI전략기획실이 연결됐는지 확인합니다.
3. 아래 지시를 그대로 붙여 넣어 보냅니다.
4. 진행 화면에서 Finance 스킬 이름이 보이는지 확인합니다.
5. 차이가 가장 큰 항목이 무엇이었는지 옆 사람과 비교합니다.

**입력, 그대로 복사해 보내세요**

```text
99_예시_한빛정밀(또는 00_회사자료)에서 한빛정밀 2026 경영목표 KPI 엑셀(이름에 KPI가 들어간 파일)을 찾아 2026 상반기 목표 대비 실적 차이 분석을 해줘. 연습이라 이번에는 한빛정밀 자료를 써도 돼.

- 상반기 목표 = Q1 + Q2 목표. 매출, 영업이익률, 전동화 매출 비중, 신규 수주, 고객 상위 1개사 비중을 비교해.
- 차이가 큰 순서로 3개, 각각 원인 가설 2개(엑셀 비고 기준)와 하반기에 확인할 것 1개.
- 숫자는 엑셀 값 그대로 쓰고 계산식을 보여줘. 1쪽 표로.

끝나면 이번에 어떤 스킬을 썼는지 이름을 알려줘.
```

!!! success "기대 결과"
    - 진행 화면에 Finance 스킬 이름이 보인다.
    - 매출 상반기 실적 6,380억 원, 목표 6,550억 원(Q1 3,200 + Q2 3,350), 달성률 97.4%가 표에 나온다.
    - 차이 3개마다 원인 가설과 하반기에 확인할 것이 있다.

!!! warning "주의"
    - 스킬은 Claude가 그대로 따르는 매뉴얼입니다. 회사 계정에는 Anthropic이나 검증된 파트너가 만든 것만 설치합니다. 카드의 '제작'에서 만든 곳을 확인합니다.
    - '체험'이나 '+'가 안 보이면 조직 설정으로 막혀 있을 수 있습니다. (화면 확인)

!!! tip "팁"
    - 설치가 막혀 있으면 Finance 카드의 '체험'을 누르고, KPI 엑셀을 대화창에 직접 올린 뒤 같은 지시를 보냅니다.
    - KPI 엑셀이 폴더에 없으면 사이트 '내려받기'의 한빛정밀_시연자료.zip에 있는 02_2026_경영목표_KPI.xlsx를 씁니다.

**이미 잘 만들어진 스킬, 이럴 때 쓰세요 (모두 Anthropic 제작)** 

| 스킬 | 이럴 때 | 우리 업무에선 |
| --- | --- | --- |

계정마다 목록이 조금 다를 수 있습니다. 사용자 지정의 Skills, 플러그인에서 내 항목과 탐색을 봅니다.

!!! note "업무에 들인다면: 쓰고, 덧붙이고, 만든다"
    - ① 공식 스킬로 써 본다. 있는 스킬이면 그대로 쓴다.
    - ② 우리 기준을 덧붙인다. 예: "Finance 스킬로 하되 KPI 정의는 00_회사자료 기준으로"

    - 고르는 기준: 누가 해도 비슷한 일은 공식 스킬, 우리 회사만의 형식과 기준이 있는 일은 내 스킬.

### 1-4. 개념 지도: Claude는 무엇을 기억하고, 무엇을 잊을까

**이런 경험, 있으셨죠?** 

| 잊는다 (새 대화를 열면 사라지는 것) | 남는다 (어느 대화에서나 지켜지는 것) |
| --- | --- |
| 어제 대화에서 "결론부터"라고 한 말 | 폴더 지침에 적은 규칙 |
| 앞 대화에서 정리해 준 내용 | 폴더에 저장된 파일 |
| 대화창에만 올린 파일 | 스킬 (그 일이 오면) |

Claude를 새로 온 유능한 비서라고 생각하면 쉽습니다.

| 개념 | 한 줄로 | 비유 | 언제 쓰이나 | 어디서 정하나 |
| --- | --- | --- | --- | --- |
| 컨텍스트 | Claude가 지금 이 대화에서 보고 있는 모든 것 | 책상 위 | 이 대화 동안만 | 길어지면 새 대화 |
| 지침 | 늘 지켜야 하는 규칙 | 사내 규정집 | 항상 | 설정 › 전체 지침, 폴더 지침 |
| 메모리 | 대화 중 골라 적어 둔 나와 일에 대한 주제 | 비서의 수첩 | 켠 경우, 관련 있을 때 (내 PC에서 도는 Cowork는 안 씀) | 설정 › 메모리 (팀 계정은 관리자와 본인이 켜야) |
| 스킬 | 특정 일을 하는 방법 | 업무 매뉴얼 | 그 일이 올 때만 | 사용자 지정 › Skills |
| 지식 (선택) | 작업방(Project)에 올려 둔 회사 자료 | 참고 서류철 | 그 방 안에서 | Projects (부록 4) |

!!! note "메모리는 다 기억하지 않습니다"
    - 골라서 적는다: 대화 중에 역할, 진행 중인 일, 함께 일하는 사람, 말투와 선호를 주제별로 저장합니다. 대화를 통째로 기억하지 않습니다.
    - 적지 않는 것: 민감한 주제, 신분증, 계좌 번호 등(요청해도 안 함), 시크릿 대화, 메모리를 끈 채 시작한 대화.
    - 보고 고친다: 설정 › 메모리 › Topics에서 보고 고치고 지웁니다. 대화로 "이건 기억해 / 잊어"도 됩니다.
    - 팀 계정은 꺼져 있다: 관리자가 조직에서 켜고, 본인도 켜야 합니다. Project마다 따로 기억합니다.
    - 내 PC에서 도는 Cowork 작업은 메모리를 쓰지 않는다. 그래서 꼭 남길 것은 지침과 파일에 남깁니다.
    - 출처: Claude 도움말 What is memory and how does Claude use it

!!! note "왜 대화가 길어지면 답이 흐려질까"
    - ① 다 올라간다: 내 말, Claude의 답, 올린 파일, 지침, 불려 온 스킬이 모두 책상(컨텍스트)에 올라갑니다.
    - ② 주의가 나뉜다: Claude는 모든 단어를 다른 모든 단어와 견주어 읽습니다. 단어가 n개면 관계는 n²개. 길어질수록 앞 내용을 정확히 떠올리는 능력이 떨어집니다 (Anthropic은 'context rot'이라고 부릅니다).
    - ③ 앞부분을 요약한다: 한도에 가까워지면 앞부분을 요약해서 이어 가고, 이때 세부가 빠질 수 있습니다.
    - ④ 그래서: 주제가 바뀌면 새 대화, 이어 갈 내용은 파일로 정리해 넘깁니다. Anthropic도 중요한 내용은 책상 밖 노트에 적어 두고 필요할 때 다시 불러오게 합니다.
    - 출처: Anthropic, Effective context engineering for AI agents (2025.9)

!!! tip "그래서 이렇게 씁니다"
    - 책상엔 한도가 있다: 대화가 길어지면 답이 흐려집니다. 주제가 바뀌면 새 대화, 이어 갈 내용은 파일로 정리해 넘깁니다.
    - 대화끼리는 모른다: 새 대화는 앞 대화를 모릅니다. 계속 쓸 내용은 지침, 스킬, 폴더의 파일에 남깁니다.
    - 매번 하는 말은 지침: "결론부터", "존댓말로"처럼 매번 붙이는 말은 지침에 한 번만.
    - 매주 하는 일은 스킬: 주간 업데이트, 이슈 브리핑처럼 반복되는 일은 스킬로 저장해 한 줄로 부릅니다 (2교시).

**한 대화로 계속? 여러 개 동시에?** 

| 상황 | 이렇게 |
| --- | --- |
| 같은 일 (고치고 다듬기) | 같은 대화에서 이어서. 4회차 1-1~1-8처럼 |
| 주제가 바뀌면 | 새로 생성으로 새 대화. 다른 일을 섞으면 답이 흐려진다 |
| 대화가 너무 길어지면 | "지금까지 정리해서 파일로 저장해줘" → 새 대화에서 "그 파일 읽고 이어서" |
| 여러 개 동시에 | 서로 다른 일은 따로 맡겨 놓고 기다려도 된다. 2~3개까지, 결과는 다른 파일 이름으로 |
| 하지 말 것 | 같은 파일을 두 작업이 함께 고치기. 동시에 돌리면 사용량도 그만큼 빨리 준다 |

### 1-4a. 눈으로 확인: 새 대화는 앞 대화를 모른다 (같이 하기 ③-1)

1. 새로 생성 › 새 작업을 열고 아래 질문을 보냅니다.

**질문**

```text
방금 다른 대화에서 내가 무슨 일을 했지?
```

!!! success "기대 결과"
    '알 수 없다'고 답한다. 내 PC에서 도는 Cowork는 메모리를 쓰지 않으니 기억하지 못하는 게 정상이다.

### 1-4b. 눈으로 확인: 지침 한 줄 전후 비교 (같이 하기 ③-2)

!!! abstract "경로"
    설정 › Cowork › Global instructions › 편집. 합쳐진 새 화면은 설정 › 일반 › Instructions for Claude (화면 확인)

1. 새 작업에서 "회의를 잘 하는 법 알려줘."를 보내고 답의 길이를 봅니다.
2. 설정 › 전체 지침에 아래 한 줄을 넣고 저장합니다.
3. 다시 새로 생성 › 새 작업에서 같은 질문을 보내고 답을 비교합니다.

**지침 (전체 지침에 붙여 넣기)**

```text
답은 결론부터, 3줄 이내로 써줘.
```

!!! success "기대 결과"
    지침을 넣은 뒤에는 답이 짧아지고 결론이 맨 위에 온다.

!!! tip "팁"
    마음에 안 들면 지침 한 줄을 지웁니다. 4회차에 넣은 폴더 지침은 그대로 둡니다.
