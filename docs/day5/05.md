### 1-1. 화면 한 바퀴 돌기

메뉴가 어디 있는지 알면 막혔을 때 혼자 찾아갈 수 있습니다. 앞의 '화면 지도 (참고)' 페이지를 옆에 띄워 두고 하나씩 눌러 봅니다.

1. New를 눌러 새 작업을 엽니다. 위쪽 말풍선이 선택돼 있는지 봅니다.
2. Projects, Artifacts를 차례로 눌러 봅니다. 지금은 비어 있어도 괜찮습니다.
3. Customize를 누르고 Skills를 엽니다. 다음 단계에서 다시 옵니다.
4. 왼쪽 위 돋보기를 눌러 '산업분석'을 검색해 4회차 대화를 찾아봅니다.
5. 왼쪽 아래 내 이름 › 사용량을 열어 봅니다.
6. 왼쪽 아래 내 이름 › 언어가 한국어인지 봅니다.

!!! success "기대 결과"
    - 메뉴 6곳을 다 눌러 봤다.
    - 4회차 대화를 검색으로 찾았다.

!!! warning "주의"
    Code는 개발자용입니다. 누르지 않습니다. 들어갔으면 New를 누릅니다.

!!! tip "팁"
    Mac은 ⌘ + , 로 설정이 바로 열립니다.

### 1-2. 내 스킬 확인하기

!!! abstract "경로"
    왼쪽 메뉴 › Customize › Skills

1. 목록에서 4회차에 만든 industry-competitor-analysis, value-chain-diagnosis를 찾아봅니다.
2. 하나를 눌러 내용을 읽어 봅니다. # 제목과 - 목록 모양의 업무 매뉴얼입니다.
3. 오늘은 여기에 내가 처음부터 만든 스킬을 하나 더합니다.

!!! success "기대 결과"
    스킬 목록을 열어 봤다.

!!! tip "팁"
    4회차 스킬이 없어도 괜찮습니다. 필요하면 사이트 '내려받기'의 백업 스킬을 나중에 올립니다.

!!! note "오늘의 이야기: 월요일 아침, 주간 업데이트"
    - 지난주 회의록 PDF 2개와 실적 엑셀이 와 있습니다. 이걸 읽고 전 직원에게 보낼 주간 업데이트를 써야 합니다. 매주 하는 일입니다.
    - ① 읽기(PDF, 엑셀) → ② 쓰기(3P 형식) → ③ 스킬로 저장 → ④ 회사 색과 글꼴 입히기(6회차)
    - 3P는 진행한 것(Progress), 할 것(Plans), 문제(Problems)입니다. Anthropic 공식 예제 스킬 internal-comms가 쓰는 주간 업데이트 형식입니다.

### 1-3. 자료 받아 읽게 하기 (문서 처리)

Claude는 PDF, Word, 엑셀을 그냥 읽습니다. 파일을 폴더에 넣고 무엇을 뽑을지만 말하면 됩니다.

[:material-download: 주간업데이트_자료.zip](../files/weekly-update-materials.zip){ .md-button .md-button--primary }

1. 위 버튼으로 zip을 내려받아 압축을 풉니다. Windows는 마우스 오른쪽 › 압축 풀기, Mac은 더블클릭.
2. AI전략기획실 › 00_회사자료 안에 '주간업데이트' 폴더를 만들고 회의록 PDF 3개와 실적 엑셀을 넣습니다.
3. 새 작업(AI전략기획실 연결)에서 아래 지시를 보냅니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
00_회사자료/주간업데이트 폴더의 회의록_경영회의_1013, 회의록_영업회의_1015 (PDF)와 실적_3분기_잠정 (엑셀)을 읽어줘.

회의마다 결정된 것, 할 일(무엇을, 누가, 언제까지), 남은 문제로 나눠서 표로 정리해줘.
기한이 없는 할 일은 '기한 필요'로 표시하고, 실적 숫자는 엑셀 값 그대로 써.
```

!!! success "기대 결과"
    - 회의별 결정, 할 일, 남은 문제 표가 나온다.
    - '기한 필요'가 2~3곳 표시된다 (예: 전동화 라인 가동률 개선안).

!!! tip "팁"
    회의록_경영회의_1020은 1-6 테스트용이라 아직 쓰지 않습니다.

### 1-4. 3P 주간 업데이트 쓰고, 한 가지만 고치기 (사내 커뮤니케이션)

1. 결과를 읽고 마음에 안 드는 것 한 가지만 고쳐 달라고 합니다. 예: "할 것마다 담당과 기한을 괄호로 붙여줘", "한 줄 요약을 숫자로 시작해줘"

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 정리한 내용으로 전 직원용 주간 업데이트를 써줘.

형식: 맨 위 한 줄 요약 → 진행한 것(Progress) 3개 → 이번 주 할 것(Plans) 3개 → 문제와 도움 필요(Problems) 2개.
말투: 존댓말, 항목마다 2줄 이내, 숫자에는 출처 파일 이름.
'주간업데이트_1017'로 04_보고장표 폴더에 Word로 저장해줘.
```

!!! success "기대 결과"
    04_보고장표에 주간업데이트_1017.docx가 생긴다.

!!! tip "팁"
    여기서 고친 것이 스킬의 규칙이 됩니다. 내 보고 습관을 하나 넣어 보세요.

### 1-5. "주간업데이트 스킬로 만들어줘" + 07_내스킬

마음에 드는 결과가 나왔을 때 그 대화에서 바로 스킬로 저장합니다. 사본과 목록을 내 폴더에 두면 스킬이 늘어도 한눈에 보이고, 계정이 회수돼도 다시 올릴 수 있습니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 한 방식을 스킬로 만들어줘.
- 이름: weekly-update
- 설명: 회의록, 실적 자료(PDF, Word, Excel)를 읽고 전 직원용 주간 업데이트를 3P 형식(진행한 것, 할 것, 문제)으로 쓴다. 주간 업데이트, 주간 공지, 사내 소식 요청 시 사용.
- 형식, 말투, 내가 고친 것, '기한 필요' 규칙을 모두 넣어줘.
- 저장하면 AI전략기획실/07_내스킬 폴더(없으면 만들어)에 사본을 두고, 07_내스킬/스킬목록.md에 내 스킬을 표로 정리해줘: 이름, 하는 일, 언제 쓰나, 한 줄 사용 예.
- 앞으로 스킬을 만들거나 고치면 사본과 목록도 같이 고치도록 폴더 지침에 추가해줘.
보여주고 내가 확인하면 저장해줘.
```

!!! success "기대 결과"
    - Customize › Skills에 weekly-update가 켜져 있다.
    - 07_내스킬에 weekly-update 사본과 스킬목록.md가 있다.

!!! tip "팁"
    '이 폴더'와 '내 전체' 중에 고르라고 나오면 '내 전체'를 고릅니다. 매주 어디서나 쓸 스킬이니까요.

### 1-6. 다른 주 회의록으로 / 한 줄 테스트

긴 지시 없이 한 줄로 같은 형식이 나오면, 처음부터 만든 내 스킬이 동작한 것입니다.

!!! abstract "경로"
    New › 폴더 AI전략기획실 연결 › 입력창에 /

1. 새 작업을 열고 입력창에 / 를 쳐서 weekly-update를 고릅니다.
2. 아래 한 줄을 이어서 보냅니다.
3. 진행 화면에 스킬 이름이 보이는지, 1-4와 같은 형식인지 봅니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
00_회사자료/주간업데이트/회의록_경영회의_1020으로 이번 주 주간 업데이트 써줘.
```

!!! success "기대 결과"
    - 한 줄 요약, 진행 3, 할 것 3, 문제 2 형식으로 나온다.
    - '전동화 라인 가동률 개선안 미제출'이 문제에 들어간다.

!!! tip "팁"
    빠진 게 보이면 "[빠진 것]도 항상 넣도록 스킬에 추가해줘"라고 합니다. 쓸 때마다 다듬는 게 스킬입니다.
