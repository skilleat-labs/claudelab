# 부록 1 — 프롬프트 카드

오늘 쓴 지시문을 한 줄로 모았습니다. 전체 문장은 해당 단계의 '입력' 상자를 보세요. 회사에 돌아가서 이 표만 보고 다시 쓸 수 있게 만들었습니다.

| 단계 | 언제 | 핵심 지시 (요약) |
| --- | --- | --- |
| 1-4 | 1교시, 스킬을 / 로 불러 한 줄로 실행 | / 로 산업분석 스킬 → [경쟁사 한 곳] 중심으로 산업분석 (한 줄) |
| 1-5 | 1교시, 07_내스킬 폴더와 스킬목록 만들기 | 07_내스킬 폴더 → 스킬 사본(SKILL.md) + 스킬목록.md + '스킬 바꾸면 사본도' 폴더 지침 |
| 2-1 | 2교시, 지식 파일 준비, 회사 개요 1장 만들기 | 우리 회사 자료 → Project 지식용 회사개요_1장 (표 위주 2쪽, 없는 칸은 묻고 [확인 필요]) |
| 2-4 | 2교시, 지침 넣기, 전략 참모 | 지침 다섯 줄: [역할] 전략 참모, [형식] 결론부터, [기준] 출처, [금지], [먼저 질문] |
| 2-5 | 2교시, 같은 질문, Project 안과 밖 비교 | (Project 안, 밖 비교) "[가장 큰 이슈]가 우리에게 어떤 의미야?" |
| 2-6 | 2교시, KPI 엑셀 분석: 데이터 설명부터 | KPI 엑셀 분석: 데이터 설명 먼저 → 질문 3개 → 새 시트에 표, 차트(수식) → 대조할 숫자 2개 |
| 3-1 | 3교시, 뉴스 1건으로 브리핑 써 보기 | 뉴스 → 결론부터 브리핑 6단: 한 줄 결론, 무슨 일, 우리 영향, 시나리오 3, 권고 액션, 지켜볼 지표 |
| 3-2 | 3교시, 한 가지만 고치기 | 브리핑 한 가지 고치기 |
| 3-3 | 3교시, 스킬로 저장, 이슈브리핑 | "방금 한 브리핑 방식을 스킬로" (exec-issue-briefing, 사본은 07_내스킬) |
| 3-4 | 3교시, 예약 작업 프롬프트 | 평일 09:00, 키워드 뉴스 조사 → 최대 3건 스킬 형식 → 03_브리핑 폴더에 저장 |
| 3-6 | 3교시, (선택) Google 커넥터로 Drive 저장, Gmail 초안 | (선택) 예약 작업에 Drive 저장, Gmail 초안 두 줄 추가 |
| 3-7 | 3교시, 브리핑 고치기 → 스킬에 반영 | 브리핑의 아쉬운 점 → 스킬 수정 (사본도) |
