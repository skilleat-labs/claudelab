# 막혔을 때

혼자 5분 넘게 막히면 손을 들어 주세요. 강사의 백업 파일, 백업 스킬로 다음 단계부터 이어 갈 수 있습니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| Project 답이 회사 수치를 안 쓴다 | 질문이 지식과 연결되지 않음, 파일이 너무 많음 | "지식의 회사개요_1장 기준으로"라고 파일명을 말하기. 지식 파일을 요약본 위주로 줄이기 |
| 메모리 메뉴가 없다 | 회사 계정은 기본 꺼짐 | 관리자에게 허용 요청. 실습은 지식, 지침만으로 진행 |
| Connectors에 Google이 없다 | 관리자가 조직에서 안 켬 | 관리자에게 Gmail, Calendar, Drive 커넥터 활성화 요청 |
| Google 로그인이 막힌다 | 회사 Workspace가 외부 앱 연결을 막음, 다른 계정으로 로그인 | IT 담당자 확인. 맞는 계정으로 다시 로그인 |
| Scheduled 메뉴가 없다 | 앱 버전, Cowork 꺼짐 | 앱 업데이트 후 재시작. 없으면 관리자 확인 |
| 예약 작업이 아침에 안 돌았다 | 컴퓨터 꺼짐, 앱 닫힘, 로컬 폴더가 필요한 작업 | 실행 기록 확인 (화면 확인). 지금 실행으로 다시 돌리고, 당분간 컴퓨터를 켜 두기 |
| 메일이 초안이 아니라 보내지려 한다 | 프롬프트에 '초안만'이 빠짐, 승인 모드 | 승인 창에서 거절 → 프롬프트에 "초안만, 절대 보내지 마" 추가 |
| Gmail 첨부파일 내용을 못 읽는다 | Gmail 커넥터는 첨부를 못 읽음 | 첨부를 Drive나 작업 폴더에 저장한 뒤 그 파일을 읽게 하기 |
| PPT 색이 우리 회사 색과 다르다 | hex 코드 오타, 스킬이 안 불림 | 스킬의 색상 표 확인. 입력창 / 로 exec-report-style 직접 선택 |
| 제목이 '현황' 같은 명사로 나온다 | 제목 규칙이 약함 | "모든 제목을 결론 문장으로 다시 써줘" → 스킬에도 추가 |
