### 2-0. 개념 지도: Claude는 무엇을 기억하고, 무엇을 잊을까

내 스킬을 만들기 전에 하나만 짚고 갑니다. 왜 잘한 방식을 스킬로 남겨야 할까요? 답은 Claude가 무엇을 기억하고 무엇을 잊는지에 있습니다.

**이런 경험, 있으셨죠?** 

| 잊는다 (새 대화를 열면 사라지는 것) | 남는다 (어느 대화에서나 지켜지는 것) |
| --- | --- |
| 어제 대화에서 "결론부터"라고 한 말 | 폴더 지침에 적은 규칙 |
| 앞 대화에서 정리해 준 내용 (물으면 찾아는 본다) | 폴더에 저장된 파일 |
| 대화창에만 올린 파일 | 스킬 (그 일이 오면) |

Claude를 새로 온 유능한 비서라고 생각하면 쉽습니다.

| 개념 | 한 줄로 | 비유 | 언제 쓰이나 | 어디서 정하나 |
| --- | --- | --- | --- | --- |
| 컨텍스트 | Claude가 지금 이 대화에서 보고 있는 모든 것 | 책상 위 | 이 대화 동안만 | 길어지면 새 대화 |
| 지침 | 늘 지켜야 하는 규칙 | 사내 규정집 | 항상 | 설정 › 전체 지침, 폴더 지침 |
| 메모리 | 대화 중 골라 적어 둔 나와 일에 대한 주제 | 비서의 수첩 | 켠 경우, 관련 있을 때 (내 PC에서 도는 Cowork는 안 씀) | 설정 › 메모리 (팀 계정은 관리자와 본인이 켜야) |
| 스킬 | 특정 일을 하는 방법 | 업무 매뉴얼 | 그 일이 올 때만 | 사용자 지정 › Skills |
| 지식 | 작업방(Project)에 올려 둔 자료 | 참고 서류철 | 그 방 안에서 | Projects (1교시 스킬 고르기 참모, 부록 4) |

!!! note "메모리는 다 기억하지 않습니다"
    - 골라서 적는다: 대화 중에 역할, 진행 중인 일, 함께 일하는 사람, 말투와 선호를 주제별로 저장합니다. 대화를 통째로 기억하지 않습니다.
    - 적지 않는 것: 민감한 주제, 신분증, 계좌 번호 등(요청해도 안 함), 시크릿 대화, 메모리를 끈 채 시작한 대화.
    - 보고 고친다: 설정 › 메모리 › Topics에서 보고 고치고 지웁니다. 대화로 "이건 기억해 / 잊어"도 됩니다.
    - 팀 계정은 꺼져 있다: 관리자가 조직에서 켜고, 본인도 켜야 합니다. Project마다 따로 기억합니다.
    - 내 PC에서 도는 Cowork 작업은 메모리를 쓰지 않는다. 그래서 꼭 남길 것은 지침과 파일에 남깁니다.
    - 출처: Claude 도움말 What is memory and how does Claude use it

!!! note "왜 대화가 길어지면 답이 흐려질까"
    - ① 다 올라간다: 내 말, Claude의 답, 올린 파일, 지침, 불려 온 스킬이 모두 책상(컨텍스트)에 올라갑니다.
    - ② 주의가 나뉜다: Claude는 모든 단어를 다른 모든 단어와 견주어 읽습니다. 단어가 n개면 관계는 n²개. 길어질수록 앞 내용을 정확히 떠올리는 능력이 떨어집니다 (Anthropic은 'context rot'이라고 부릅니다).
    - ③ 앞부분을 요약한다: 한도에 가까워지면 앞부분을 요약해서 이어 가고, 이때 세부가 빠질 수 있습니다.
    - ④ 그래서: 주제가 바뀌면 새 대화, 이어 갈 내용은 파일로 정리해 넘깁니다. Anthropic도 중요한 내용은 책상 밖 노트에 적어 두고 필요할 때 다시 불러오게 합니다.
    - 출처: Anthropic, Effective context engineering for AI agents (2025.9)

!!! tip "그래서 이렇게 씁니다"
    - 책상엔 한도가 있다: 대화가 길어지면 답이 흐려집니다. 주제가 바뀌면 새 대화, 이어 갈 내용은 파일로 정리해 넘깁니다.
    - 기억이 아니라 찾아본다: 새 대화의 책상은 비어 있습니다. 물으면 지난 대화를 찾아 읽어 오지만 요약일 뿐입니다. 계속 쓸 내용은 지침, 스킬, 폴더의 파일에 남깁니다.
    - 매번 하는 말은 지침: "결론부터", "존댓말로"처럼 매번 붙이는 말은 지침에 한 번만.
    - 매주 하는 일은 스킬: 주간 업데이트, 이슈 브리핑처럼 반복되는 일은 스킬로 저장해 한 줄로 부릅니다 (2교시).

### 2-0a. 눈으로 확인: 기억이 아니라 찾아본다 (같이 하기 ③-1)

1. 새로 생성 › 새 작업을 열고 아래 질문을 보냅니다.
2. 답 위에 '사용한 도구 N개'가 보이는지 봅니다. 눌러 보면 지난 대화 기록을 찾아 읽은 흔적이 나옵니다.

**질문**

```text
방금 다른 대화에서 내가 무슨 일을 했지?
```

!!! success "기대 결과"
    - 지난 대화에서 한 일을 꽤 정확히 말해 준다. 다만 답 위에 '사용한 도구'가 보인다. 기억하고 있던 게 아니라, 물어보니까 지난 기록을 찾아 읽어 온 것이다.
    - 그래서 묻지 않으면 찾지 않고, 찾아와도 요약이라 세부는 빠질 수 있다. 이어 갈 일은 여전히 파일로 넘기는 게 확실하다.
    - 도구 없이 '알 수 없다'고 답하는 경우도 있다. 둘 다 정상이다.

### 2-0b. 눈으로 확인: 지침 한 줄 전후 비교 (같이 하기 ③-2)

4회차에 만든 폴더 지침을 씁니다. 설정 메뉴를 찾을 필요 없이 Claude에게 말로 한 줄 추가하게 합니다.

!!! abstract "경로"
    새로 생성 › Cowork, 폴더 AI전략기획실 › 새 작업

1. 새 작업에서 "회의를 잘 하는 법 알려줘."를 보내고 답의 길이를 봅니다.
2. 같은 대화에서 아래 지시를 보냅니다.
3. 다시 새로 생성 › 새 작업에서 같은 질문을 보내고 답을 비교합니다.

**입력, 그대로 복사해 보내세요**

```text
폴더 지침에 '답은 결론부터, 3줄 이내로 써줘' 한 줄을 추가해줘.
```

!!! success "기대 결과"
    지침을 넣은 뒤에는 새 작업에서도 답이 짧아지고 결론이 맨 위에 온다.

!!! tip "팁"
    - 마음에 안 들면 "폴더 지침에서 방금 넣은 한 줄을 지워줘"라고 합니다.
    - 모든 폴더, 모든 대화에 적용되는 전체 지침은 설정 쪽에 따로 있습니다. 화면마다 위치가 달라 오늘은 폴더 지침으로 합니다.

**한 대화로 계속? 여러 개 동시에?** 

| 상황 | 이렇게 |
| --- | --- |
| 같은 일 (고치고 다듬기) | 같은 대화에서 이어서. 4회차 1-1~1-8처럼 |
| 주제가 바뀌면 | 새로 생성으로 새 대화. 다른 일을 섞으면 답이 흐려진다 |
| 대화가 너무 길어지면 | "지금까지 정리해서 파일로 저장해줘" → 새 대화에서 "그 파일 읽고 이어서" |
| 여러 개 동시에 | 서로 다른 일은 따로 맡겨 놓고 기다려도 된다. 2~3개까지, 결과는 다른 파일 이름으로 |
| 하지 말 것 | 같은 파일을 두 작업이 함께 고치기. 동시에 돌리면 사용량도 그만큼 빨리 준다 |

!!! note "오늘의 이야기: 월요일 아침, 주간 업데이트"
    - 지난주 회의록 PDF 2개와 실적 엑셀이 와 있습니다. 이걸 읽고 전 직원에게 보낼 주간 업데이트를 써야 합니다. 매주 하는 일입니다.
    - ① 읽기(PDF, 엑셀) → ② 쓰기(3P 형식) → ③ 스킬로 저장 → ④ 회사 색과 글꼴 입히기(6회차)
    - 3P는 진행한 것(Progress), 할 것(Plans), 문제(Problems)입니다. Anthropic 공식 예제 스킬 internal-comms가 쓰는 주간 업데이트 형식입니다.

### 2-1. 자료 받아 읽게 하기 (문서 처리)

Claude는 PDF, Word, 엑셀을 그냥 읽습니다. 파일을 폴더에 넣고 무엇을 뽑을지만 말하면 됩니다.

[:material-download: 주간업데이트_자료.zip](../files/weekly-update-materials.zip){ .md-button .md-button--primary }

1. 1교시 1-3c에서 00_회사자료/주간업데이트에 자료를 넣었으면 1~2는 건너뜁니다.
2. 위 버튼으로 zip을 내려받아 압축을 풉니다. Windows는 마우스 오른쪽 › 압축 풀기, Mac은 더블클릭.
3. AI전략기획실 › 00_회사자료 안에 '주간업데이트' 폴더를 만들고 회의록 PDF 3개와 실적 엑셀을 넣습니다.
4. 새 작업(AI전략기획실 연결)에서 아래 지시를 보냅니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
00_회사자료/주간업데이트 폴더의 회의록_경영회의_1013, 회의록_영업회의_1015 (PDF)와 실적_3분기_잠정 (엑셀)을 읽어줘.

회의마다 결정된 것, 할 일(무엇을, 누가, 언제까지), 남은 문제로 나눠서 표로 정리해줘.
기한이 없는 할 일은 '기한 필요'로 표시하고, 실적 숫자는 엑셀 값 그대로 써.
```

!!! success "기대 결과"
    - 회의별 결정, 할 일, 남은 문제 표가 나온다.
    - '기한 필요'가 2~3곳 표시된다 (예: 전동화 라인 가동률 개선안).

!!! tip "팁"
    회의록_경영회의_1020은 2-4 테스트용이라 아직 쓰지 않습니다.

### 2-2. 3P 주간 업데이트 쓰고, 한 가지만 고치기 (사내 커뮤니케이션)

1. 결과를 읽고 마음에 안 드는 것 한 가지만 고쳐 달라고 합니다. 예: "할 것마다 담당과 기한을 괄호로 붙여줘", "한 줄 요약을 숫자로 시작해줘"

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 정리한 내용으로 전 직원용 주간 업데이트를 써줘.

형식: 맨 위 한 줄 요약 → 진행한 것(Progress) 3개 → 이번 주 할 것(Plans) 3개 → 문제와 도움 필요(Problems) 2개.
말투: 존댓말, 항목마다 2줄 이내, 숫자에는 출처 파일 이름.
'주간업데이트_1017'로 04_보고장표 폴더에 Word로 저장해줘.
```

!!! success "기대 결과"

!!! tip "팁"
    여기서 고친 것이 스킬의 규칙이 됩니다. 내 보고 습관을 하나 넣어 보세요.

### 2-3. "주간업데이트 스킬로 만들어줘" + 07_내스킬

마음에 드는 결과가 나왔을 때 그 대화에서 바로 스킬로 저장합니다. 사본과 목록을 내 폴더에 두면 스킬이 늘어도 한눈에 보이고, 계정이 회수돼도 다시 올릴 수 있습니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 한 방식을 스킬로 만들어줘.
- 이름: weekly-update
- 설명: 회의록, 실적 자료(PDF, Word, Excel)를 읽고 전 직원용 주간 업데이트를 3P 형식(진행한 것, 할 것, 문제)으로 쓴다. 주간 업데이트, 주간 공지, 사내 소식 요청 시 사용.
- 형식, 말투, 내가 고친 것, '기한 필요' 규칙을 모두 넣고, 맨 아래에 '주의사항' 칸을 만들어줘.
- 저장하면 AI전략기획실/07_내스킬 폴더(없으면 만들어)에 사본을 두고, 07_내스킬/스킬목록.md에 내 스킬을 표로 정리해줘: 이름, 하는 일, 언제 쓰나, 한 줄 사용 예, 고친 날짜.
- 앞으로 스킬을 만들거나 고치면 사본과 목록도 같이 고치도록 폴더 지침에 추가해줘.
보여주고 내가 확인하면 저장해줘.
```

!!! success "기대 결과"
    - 사용자 지정(Customize) › Skills › 내 항목에 weekly-update가 켜져 있다.
    - 07_내스킬에 weekly-update 사본과 스킬목록.md가 있다.

!!! tip "팁"
    - '이 폴더'와 '내 전체' 중에 고르라고 나오면 '내 전체'를 고릅니다. 매주 어디서나 쓸 스킬이니까요.
    - '이 폴더'로 저장한 스킬은 내 항목에 보이지 않고, 그 폴더를 연결했을 때 / 목록에만 나옵니다. 없어진 게 아닙니다.

### 2-4. 다른 주 회의록으로 / 한 줄 테스트

긴 지시 없이 한 줄로 같은 형식이 나오면, 처음부터 만든 내 스킬이 동작한 것입니다.

!!! tip "팁"
    빠진 게 보이면 "[빠진 것]도 항상 넣도록 스킬의 주의사항에 추가해줘"라고 합니다. 쓸 때마다 다듬는 게 스킬입니다.

### 2-5. 스킬이 많아지면: 관리 5원칙 (지난 시간 질문 ③)

| 원칙 | 이렇게 한다 |
| --- | --- |
| ① 하나에 하나 | 스킬 하나에 일 하나. 이름은 하는 일로 짓는다 (weekly-update, exec-issue-briefing) |
| ② 설명에 '언제' | 설명에 언제 쓰는지를 적어야 Claude가 알아서 꺼낸다 ("주간 업데이트 요청 시 사용") |
| ③ 목록 한 장 | 07_내스킬/스킬목록: 이름, 하는 일, 언제 쓰나, 한 줄 사용 예, 고친 날짜 |
| ④ 안 쓰면 끈다 | 켜 둔 스킬은 설명만으로도 책상(컨텍스트)을 조금씩 차지한다. 사용자 지정 › Skills에서 끈다 |
| ⑤ 틀리면 한 줄 | 틀린 결과가 나오면 스킬의 '주의사항'에 한 줄 더한다. 그렇게 스킬이 자란다 |

이름이 기억 안 나면 입력창에 / 를 칩니다. 쓸 수 있는 스킬이 목록으로 뜹니다.

**내 스킬 한눈에 보기** 

| 방법 | 어디서 | 보이는 것 |
| --- | --- | --- |
| 입력창에 / | 새 작업의 입력창 | 지금 쓸 수 있는 스킬과 명령 전체. 앞 글자 몇 개만 쳐도 걸러진다 (예: /fin) |
| 사용자 지정 › Skills › 내 항목 | 왼쪽 메뉴 | 내 계정의 스킬과 한 줄 설명, 켜짐 여부. 오른쪽 위 검색, 필터, 정렬 |
| Claude에게 묻기 | 아무 대화 | "지금 내가 쓸 수 있는 스킬을 표로: 이름, 하는 일, 언제 쓰나" |
| 스킬목록 한 장 | 07_내스킬/스킬목록.md | 폴더 지침 덕분에 스킬을 만들거나 고칠 때마다 저절로 최신이 된다 |

**입력, 스킬목록을 화면(아티팩트)으로 보기**

```text
07_내스킬/스킬목록.md를 한 장짜리 화면으로 보여줘. 업무별로 묶고, 스킬마다 이름, 하는 일, 언제 쓰나, 한 줄 사용 예를 카드로.
```

!!! tip "이름은 '업무 영역-하는 일'로"
    - / 목록은 이름순이라 앞머리가 같으면 업무별로 모여 보입니다. 예: report-weekly-update, report-exec-style / brief-issue, brief-morning / analysis-industry, analysis-value-chain
    - 설명은 맨 앞에 '언제 쓰는지'를 씁니다. 예: "주간 업데이트를 쓸 때 사용. 회의록과 실적을 읽고…"
    - 스킬이 아주 많아지면 비슷한 것끼리 하나의 꾸러미(플러그인)로 묶을 수 있습니다. 탐색의 Plugin Management가 이를 돕는 공식 도구입니다.

!!! note "관리는 Claude가 돕고, 결정은 내가 합니다"
    - 목록 갱신, 겹치는 스킬 찾기, 설명에 '언제'가 빠진 스킬 찾기는 Claude에게 맡깁니다.
    - 켜고 끄기, 지우기, 회사에 배포하기는 내가 결정합니다.
    - (선택) 매달 한 번 예약 작업: "07_내스킬 스킬목록을 점검해줘. 겹치는 스킬, 설명에 '언제'가 빠진 스킬, 석 달 넘게 안 고친 스킬을 표로 알려줘. 지우거나 고치지는 마."

!!! example "해외에서는 이렇게 관리합니다"
    - Anthropic 사내: 스킬을 정하는 위원회가 따로 없습니다. 누구나 시험 폴더에 올리고, 많이 쓰이면 공식 목록으로 올립니다. 여러 일을 한꺼번에 하려는 스킬은 Claude를 헷갈리게 해서, 잘 되는 스킬은 한 가지 일에 딱 맞습니다. 가장 값진 칸은 '자주 틀리는 점'을 모은 주의사항이고, 좋은 스킬도 몇 줄로 시작해 쓰면서 덧붙여 좋아졌다고 합니다.
    - 회사 단위 (Team, Enterprise 플랜): 관리자가 회사 공용 스킬을 전 직원에게 한 번에 배포합니다. 처음부터 켜져 있고, 각자 필요 없으면 끌 수 있습니다. 외부 스킬은 Anthropic의 공식 파트너 목록(Notion, Canva, Figma, Atlassian 등)에서 고릅니다.
    - 라쿠텐 (일본): 관리회계와 재무 업무를 스킬로 만들었습니다. 라쿠텐 AI 총괄 Yusuke Kaji는 "스킬이 관리회계와 재무 업무를 간소화한다"고 말했습니다.
    - 우리 회사로 옮기면: 내 스킬로 써 보고 → 팀원 반응이 좋으면 → 관리자에게 회사 전체 배포를 요청합니다.
    - 출처: Anthropic, Lessons from building Claude Code: How we use skills (2026.6), Skills for organizations, partners, the ecosystem (2025.12), Introducing Claude Skills (2025.10)

**스킬이 많아지면: 원본은 한 곳에, 쓰는 곳에 나눠 준다** 

| 규모 | 원본을 두는 곳 | 나눠 주는 방법 |
| --- | --- | --- |
| 개인 | 내 스킬 폴더 한 곳 (오늘의 07_내스킬) | 계정에는 지금 쓰는 것만 올린다. 여러 AI 도구에 설치해 주는 공개 도구도 '원본 한 벌 + 각 도구에 연결'을 권한다 |
| 팀 | 같이 쓰는 저장소의 스킬 폴더 | 팀이 함께 쓴다. 커지면 스킬 목록을 만들어 각자 골라 설치 (Anthropic 사내: 시험 → 반응 → 목록) |
| 회사 (Team, Enterprise) | 관리자 배포, 조직 공유 | 관리자가 올리면 전원 기본 켜짐(개인이 끌 수는 있고 지울 수는 없다). 동료, 그룹에 공유하면 받는 사람은 보기 전용. 조직 게시는 열림 / 검토 후 / 끔 |

출처: Claude Code 문서 Skills, Anthropic, How we use skills (2026.6), Claude 도움말 Provision and manage skills for your organization, vercel-labs/skills README

!!! warning "이 교육 계정에서는 공유, 게시하지 않습니다"
    - 이 교육 계정은 여러 회사가 한 조직을 함께 씁니다. 공유하거나 게시하면 다른 회사 참가자에게 보입니다.
    - Team 플랜은 조직 게시가 기본 '열림'인 경우가 많습니다. 버튼이 보여도 누르지 않습니다.
    - 오늘은 원본을 07_내스킬에 두고, 계정에는 '내 전체'로 저장만 합니다.
    - 회사 계정에서는: 내 계정에서 먼저 시험 → 팀원 반응 확인 → 관리자에게 배포 요청. 두루 쓰는 스킬은 기본 켜기, 전문 스킬은 필요한 팀만.

### 2-6. 백업과 복원 (같이 하기 ⑤)

스킬은 내 PC가 아니라 Claude 계정 안에 저장됩니다. 이 교육 계정은 일정 기간 뒤 회수되고, 회사 계정으로 옮길 때 다시 올려야 합니다. 순서: ① 07_내스킬에 사본과 스킬목록 → ② 스킬마다 업로드용 zip → ③ 새 계정에서 사용자 지정 › Skills › + 추가 › 업로드 → ④ / 로 불러 한 줄 테스트.

[:material-download: 산업분석 백업 스킬 (industry-competitor-analysis.zip)](../files/industry-competitor-analysis.zip){ .md-button .md-button--primary }
[:material-download: 밸류체인진단 백업 스킬 (value-chain-diagnosis.zip)](../files/value-chain-diagnosis.zip){ .md-button .md-button--primary }

1. 07_내스킬에 스킬 폴더, zip, 스킬목록.md가 생겼는지 봅니다.
2. 사용자 지정(Customize) › Skills › + 추가 › 업로드 창을 열어 봅니다.
3. 4회차 스킬이 없는 사람: 사이트 '내려받기'의 백업 zip(industry-competitor-analysis.zip, value-chain-diagnosis.zip)을 올립니다. 이것이 복원입니다. 올린 뒤 새 작업을 열면 / 목록에 나옵니다.
4. 4회차 스킬이 있는 사람: 같은 스킬이 두 개가 되지 않게 업로드 창은 취소합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
07_내스킬 폴더를 백업용으로 정리해줘.
1. 내가 만든 스킬(weekly-update, industry-competitor-analysis, value-chain-diagnosis 등)마다 07_내스킬/[스킬 이름] 폴더에 SKILL.md 사본이 있는지 확인하고, 없으면 만들어줘.
2. 스킬마다 업로드용 zip을 07_내스킬/[스킬 이름].zip으로 만들어줘. zip 안에는 스킬 폴더 하나가 있고, 그 안에 SKILL.md가 있게.
3. 07_내스킬/스킬목록.md를 표로 고쳐줘: 이름, 하는 일, 언제 쓰나, 한 줄 사용 예, 고친 날짜.
내 계정의 스킬 내용을 읽을 수 없는 것이 있으면 이름만 알려줘.
```

!!! success "기대 결과"
    - 07_내스킬에 스킬별 폴더와 zip, 스킬목록.md가 있다.
    - 사용자 지정 › Skills › 내 항목에 4회차 스킬과 weekly-update가 보인다.

!!! tip "팁"
    - zip은 압축을 풀지 않고 그대로 올립니다.
    - Claude가 읽지 못한 스킬은 사용자 지정 › Skills에서 그 스킬 오른쪽 ⋮ 메뉴에 내려받기가 있으면 받아서 07_내스킬에 넣습니다. (화면 확인)
