# 부록 3 — 입력창과 모델

## 입력창의 두 버튼, /와 +

| 버튼 | 하는 일 | 자주 쓰는 것 |
| --- | --- | --- |
| /  슬래시 | 기능을 부른다. / 만 치면 쓸 수 있는 명령이 목록으로 나온다. 앞 글자 몇 개만 쳐도 찾는다. | /deep-research (깊은 조사), /내 스킬 이름 (저장한 방식 실행), 설치한 플러그인 명령 |
| +  더하기 | 재료를 붙인다. | 파일, 사진, 폴더, 커넥터(Gmail, 드라이브), Research와 웹 검색 켜기 |

!!! note "왜 /로 부르나"
    Claude는 스킬 설명을 보고 맞는 일이면 알아서 꺼내 쓰기도 합니다. /로 부르면 '이걸 써'라고 확실하게 지정합니다. 스킬이 늘수록 / 메뉴가 나만의 업무 메뉴판이 됩니다.
