# 막혔을 때

혼자 5분 넘게 막히면 손을 들어 주세요. 강사의 백업 파일, 백업 스킬로 다음 단계부터 이어 갈 수 있습니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| Customize에 Skills가 없다 | 코드 실행이 꺼짐, 조직 설정 | 설정 › Capabilities 확인 → 강사(운영 측)에게 알리기 |
| / 를 쳐도 스킬이 안 보인다 | 스킬이 꺼져 있음 | Customize › Skills에서 켜기. 없으면 1-3 백업 스킬 올리기 |
| Project 답이 회사 수치를 안 쓴다 | 질문이 지식과 연결되지 않음, 파일이 너무 많음 | "지식의 회사개요_1장 기준으로"라고 파일명을 말하기. 지식 파일을 요약본 위주로 줄이기 |
| 한빛정밀 숫자가 섞여 나온다 | 99_예시_한빛정밀 파일을 지식에 올렸거나 폴더에서 읽음 | 지식에서 한빛정밀 파일 삭제. 지침에 "99_예시_한빛정밀은 읽지 마" 한 줄 추가 |
| 사용량 한도 안내가 뜬다 | Cowork, Research는 사용량을 많이 씀 | 프로필 › 사용량 확인. 잠시 뒤 다시 하거나 강사 화면 따라 보기 |
| Scheduled 메뉴가 없다 | 앱 버전, Cowork 꺼짐 | 앱 업데이트 후 재시작. 없으면 강사에게 알리기 |
| 예약 작업이 아침에 안 돌았다 | 컴퓨터 꺼짐, 앱 닫힘, 로컬 폴더가 필요한 작업 | 실행 기록 확인 (화면 확인). 지금 실행으로 다시 돌리고, 당분간 컴퓨터를 켜 두기 |
| Connectors에 Google이 없다 | 운영 측 조직 설정에서 꺼짐 | 3-6은 선택이니 건너뛰기 |
