# 부록 1 — 프롬프트 카드

오늘 쓴 지시문을 한 줄로 모았습니다. 전체 문장은 해당 단계의 '입력' 상자를 보세요. 회사에 돌아가서 이 표만 보고 다시 쓸 수 있게 만들었습니다.

| 단계 | 언제 | 핵심 지시 (요약) |
| --- | --- | --- |
| 1-1 | 1교시, 지식 파일 준비, 회사 개요 1장 만들기 | 사업보고서, KPI → Project 지식용 회사개요_1장 (표 위주 2쪽) |
| 1-4 | 1교시, 지침 넣기, 전략 참모 | 지침 다섯 줄: [역할] 전략 참모, [형식] BLUF, [기준] 매출, 원가, 고객, 공급망 + 출처, [금지], [먼저 질문] |
| 1-6 | 1교시, 같은 질문, Project 안과 밖 비교 | (Project 안, 밖 비교) "[가장 큰 이슈]가 우리에게 어떤 의미야?" |
| 1-7 | 1교시, 지침 한 줄 다듬기 | 아쉬운 점 → 지침에 넣을 한 줄 규칙 제안 |
| 2-1 | 2교시, 뉴스 1건으로 브리핑 써 보기 | 뉴스 → BLUF 브리핑: 한 줄 결론, 무슨 일, 우리 영향(매출, 원가, 고객, 공급망), 시나리오 3, 권고 액션, 모니터링 지표 |
| 2-2 | 2교시, 1~2번 고치기 | KPI 영향 열 추가, 권고 액션을 주, 월, 분기로 |
| 2-3 | 2교시, 스킬로 저장, 이슈브리핑 | "방금 한 브리핑 방식을 스킬로" (exec-issue-briefing) |
| 2-4 | 2교시, Google 커넥터 연결 | (연결 확인) 이번 주 회의 3개 + Drive 파일 찾기 |
| 2-5 | 2교시, Drive에 브리핑 폴더 만들기 | Drive에 AI전략기획실/03_브리핑 폴더 만들기 |
| 2-6 | 2교시, 예약 작업 프롬프트 | 평일 09:00, 키워드 뉴스 조사 → 최대 3건 스킬 형식 → 오늘 회의 3줄 → 03_브리핑 + Drive 저장 → Gmail 초안만 |
| 2-8 | 2교시, 브리핑 고치기 → 스킬, 예약 작업에 반영 | 브리핑의 아쉬운 점 → 스킬 수정 |
| 2-9 | 2교시, (보너스) 다음 회의 맞춤 브리핑 | 다음 회의 맞춤 브리핑 (상대 회사 이슈, 관계, 질문 3, 조심할 점) |
| 3-2 | 3교시, 헤드라인 장표 5장 요청 (PPTX) | 브리핑 + 핵심 과제 → 헤드라인 장표 5장 PPTX (&lt;브랜드 hex, 글꼴, 로고&gt; &lt;숫자 표기&gt; &lt;제목 = 결론&gt; &lt;5장 구성&gt;) |
| 3-3 | 3교시, 1~2번 고치기 | 장표 1~2번 고치기 (색, 글꼴, 숫자, 구성) → v2 |
| 3-4 | 3교시, "이 양식을 보고서양식 스킬로 만들어줘" | "이 양식을 보고서양식 스킬로 만들어줘" (exec-report-style, 색, 글꼴, 숫자, 제목, 구성) |
| 3-5 | 3교시, 인포그래픽 1장 (Artifact) | 브리핑 → 30초 인포그래픽 Artifact (결론, 이슈 3, 액션 3, 출처) "새 숫자를 만들지 마" |
| 3-6 | 3교시, 숫자 원천 대조 검증 | 숫자 원천 대조표 (원천, 위치, 불일치, 장마다 다른 숫자) "고치지 말고 목록만 먼저" |
