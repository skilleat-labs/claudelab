# 막혔을 때

혼자 5분 넘게 막히면 손을 들어 주세요. 강사의 백업 파일, 백업 스킬로 다음 단계부터 이어 갈 수 있습니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 사용자 지정(Customize)에 Skills가 없다 | 코드 실행이 꺼짐, 조직 설정 | 설정 › Capabilities 확인 → 강사(운영 측)에게 알리기 |
| / 를 쳐도 스킬이 안 보인다 | 설치 전에 열어 둔 대화, 스킬이 꺼져 있음 | 새로 생성으로 새 작업을 연다. 그래도 없으면 사용자 지정(Customize) › Skills에서 켜져 있는지 보기 |
| 내 항목에 내가 만든 스킬이 없다 | '이 폴더'로 저장했거나, PC 폴더에만 있는 스킬 | 그 폴더를 연결하고 / 로 찾기. 어디서나 쓰려면 zip으로 묶어 + 추가 › 업로드 |
| Chat에서 했더니 폴더가 안 열리고 파일이 안 생긴다 | Chat을 고른 상태 | 입력창 왼쪽 아래에서 Cowork를 고르고 폴더를 연결한 뒤 다시 보낸다 |
| Finance 설치가 안 된다 (1-3) | 조직 설정에서 설치가 막힘 | Finance 카드의 '체험'을 누르고 KPI 엑셀을 대화창에 올린 뒤 같은 지시를 보낸다 |
| Data 대시보드가 안 뜬다 (1-3b) | 설치가 막힘, 명령 이름을 못 찾음 | 지시만 보낸다. 그래도 안 되면 1-3 대화에 "대시보드로도 보여줘" 한 줄 |
| PDF Viewer로 PDF가 안 열린다 (2-1b) | 설치가 막힘, 파일 경로가 다름 | "00_회사자료/주간업데이트 폴더의 PDF 목록을 보여줘"로 이름을 확인한 뒤 다시. 안 되면 건너뛴다 |
| KPI 엑셀을 못 찾는다 (1-3) | 4회차에 파일 이름이 바뀜 | 내려받기의 한빛정밀_시연자료.zip에서 02_2026_경영목표_KPI.xlsx를 받아 99_예시_한빛정밀에 넣는다 |
| 탐색 탭, '체험', '+'가 안 보인다 | 조직 설정에서 막힘, 앱 버전 | 카드를 눌러 설명만 읽는다. 앱 업데이트 후 재시작. 그래도 없으면 강사에게 (화면 확인) |
| 스킬 업로드가 안 된다 | zip을 풀어서 올림, zip 안에 SKILL.md가 없음, 같은 이름 스킬이 이미 있음 | 압축을 풀지 않은 zip을 올린다. "07_내스킬의 [스킬] zip을 업로드 형식에 맞게 다시 만들어줘" |
| 한빛정밀 숫자가 섞여 나온다 | 폴더의 99_예시_한빛정밀을 읽음 (부록 4: 지식에 올림) | 지시나 폴더 지침에 "99_예시_한빛정밀은 읽지 마" 한 줄 추가. 부록 4는 지식에서 한빛정밀 파일 삭제 |
| 사용량 한도 안내가 뜬다 | Cowork, Research는 사용량을 많이 씀 | 프로필 › 사용량 확인. 잠시 뒤 다시 하거나 강사 화면 따라 보기 |
| 더보기에 예약됨이 없다 | 앱 버전, Cowork 꺼짐 | 앱 업데이트 후 재시작. 없으면 강사에게 알리기 |
| 예약 작업이 아침에 안 돌았다 | 컴퓨터 꺼짐, 앱 닫힘, 로컬 폴더가 필요한 작업 | 실행 기록 확인 (화면 확인). 지금 실행으로 다시 돌리고, 당분간 컴퓨터를 켜 두기 |
| (부록 4) Project 답이 회사 수치를 안 쓴다 | 질문이 지식과 연결되지 않음, 파일이 너무 많음 | "지식의 회사개요_1장 기준으로"라고 파일명을 말하기. 지식 파일을 요약본 위주로 줄이기 |
