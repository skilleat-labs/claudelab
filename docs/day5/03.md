# 지난 시간 질문에 대한 답

!!! note "내가 올린 자료가 다른 사람에게 보이나요?"
    - 회사용(Team) 플랜의 대화와 파일은 기본으로 AI 학습에 쓰지 않습니다. 그래서 다른 사용자의 답이나 검색 결과에 내 자료가 나오지 않습니다.
    - 예외는 공유 버튼입니다. 공유하면 같은 조직 사람이 볼 수 있습니다. 이 교육 계정은 여러 회사가 같은 조직을 씁니다.
    - 그래서 손익, 경영계획 원본은 교육 뒤 회사 자체 계정에서 하고, 여기서는 공개 정보와 말로 알려 줄 수 있는 수준까지만 넣습니다.

!!! note "스킬 저장할 때 '이 폴더'와 '내 전체'는 뭐가 다른가요?"
    - 내 전체(내 계정): Customize › Skills 목록에 보이고, 어느 폴더, 어느 대화에서나 꺼내 씁니다. 계속 쓸 스킬은 여기로.
    - 이 폴더: 그 폴더 안에 파일로 저장되고, 그 폴더를 연결했을 때만 씁니다. 특정 프로젝트 전용 스킬에 씁니다. (화면 문구는 조금 다를 수 있음)

!!! note "만든 스킬을 한눈에 관리하려면?"
    - 입력창에 / 를 치면 쓸 수 있는 스킬이 목록으로 뜹니다.
    - Customize › Skills에서 켜고 끄고 내용을 봅니다. 안 쓰는 스킬은 끕니다.
    - 오늘 1-5에서 07_내스킬 폴더에 스킬 사본과 스킬목록(이름, 하는 일, 언제 쓰나, 한 줄 사용 예)을 만듭니다. 계정이 회수돼도 이 폴더로 다시 세울 수 있습니다.

!!! tip "Mac 노트북을 새로 산다면 사양은?"
    - Claude 데스크톱과 Cowork 기준: macOS 14(Sonoma) 이상, Apple 칩(M 시리즈) 모델이면 됩니다.
    - 여러 작업을 같이 돌리려면 메모리 16GB 이상, 저장 공간은 여유 있게 512GB 이상을 권합니다. Cowork 작업 공간과 결과 파일이 쌓입니다.
    - 가장 비싼 모델이 필요하지는 않습니다. 무거운 계산은 Anthropic 서버에서 하기 때문입니다.

!!! tip "데이터 분석을 더 효율적으로 하고 싶어요"
    오늘 2교시 2-6에서 KPI 엑셀로 연습합니다. 핵심은 '분석 전에 데이터부터 설명하게 하기'와 '계산은 수식으로 남기기'입니다.

## 오늘 나오는 말

| 말 | 쉽게 말하면 |
| --- | --- |
| Customize | 스킬과 커넥터를 모아 둔 곳. 왼쪽 메뉴에 있다 |
| / (슬래시) | 입력창에 치면 쓸 수 있는 스킬과 기능이 목록으로 뜬다 |
| 사용량 | 내 사용 한도를 얼마나 썼는지. Cowork와 Research는 많이 쓴다 |
| Project (프로젝트) | 자료와 규칙을 미리 넣어 둔 작업방. 그 안의 대화는 늘 그 자료와 규칙을 보고 답한다 |
| 지식 / 지침 | 작업방에 올려 둔 자료 / 작업방에서 Claude가 지킬 일하는 방식 |
| KPI | 핵심 성과 지표. 회사가 목표로 관리하는 숫자 |
| BLUF (블러프) | 결론을 맨 위에. 첫 줄만 읽어도 판단할 수 있게 쓰는 방식 |
| 예약 작업 (Scheduled) | 알람처럼 정해진 시간에 Claude가 알아서 시작하는 일 |
| 커넥터 | Claude와 Gmail, 캘린더, 드라이브 같은 앱을 잇는 연결선 |

!!! note "오늘은 천천히 갑니다"
    - 단계마다 '개념 한 장 → 강사와 같이 → 화면 확인 → 다음 단계' 순서로 갑니다.
    - 앞서가지 않아도 됩니다. 각 단계의 '기대 결과'가 보이면 손을 들어 주세요.
    - 막히면 그 단계는 강사 화면을 보고, 다음 단계에서 다시 같이 합니다.
