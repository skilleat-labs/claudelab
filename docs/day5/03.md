# 지난 시간 질문에 대한 답

!!! note "내가 올린 자료가 다른 사람에게 보이나요?"
    - 회사용(Team) 플랜의 대화와 파일은 기본으로 AI 학습에 쓰지 않습니다. 그래서 다른 사용자의 답이나 검색 결과에 내 자료가 나오지 않습니다.
    - 예외는 공유 버튼입니다. 공유하면 같은 조직 사람이 볼 수 있습니다. 이 교육 계정은 여러 회사가 같은 조직을 씁니다.
    - 그래서 손익, 경영계획 원본은 교육 뒤 회사 자체 계정에서 하고, 여기서는 공개 정보와 말로 알려 줄 수 있는 수준까지만 넣습니다.

!!! note "스킬 저장할 때 '이 폴더'와 '내 전체'는 뭐가 다른가요?"
    - 내 전체(내 계정): 사용자 지정(Customize) › Skills › 내 항목에 보이고, 어느 폴더, 어느 대화에서나 꺼내 씁니다. 계속 쓸 스킬은 여기로.
    - 이 폴더: 그 폴더 안에 파일로 저장되고, 그 폴더를 연결했을 때 / 목록에만 나옵니다. 내 항목에는 보이지 않습니다. (화면 문구는 조금 다를 수 있음)
    - 2교시 2-3에서 주간업데이트 스킬을 저장하면서 다시 봅니다.

!!! note "만든 스킬을 한눈에 관리하려면?"
    - 관리 5원칙: ① 스킬 하나에 일 하나 ② 설명에 '언제 쓰는지' ③ 목록 한 장(07_내스킬/스킬목록) ④ 안 쓰면 끄기 ⑤ 틀리면 주의사항에 한 줄.
    - 원본은 한 곳(07_내스킬)에 두고, 계정에는 쓰는 것만 올립니다. 팀은 같이 쓰는 저장소, 회사는 관리자 배포와 조직 공유로 넓힙니다.
    - 2교시 2-5에서 해외 사례와 함께 보고, 2-6에서 07_내스킬에 사본과 업로드용 zip을 만듭니다.

!!! tip "Mac 노트북을 새로 산다면 사양은?"
    - Claude 데스크톱과 Cowork 기준: macOS 14(Sonoma) 이상, Apple 칩(M 시리즈) 모델이면 됩니다.
    - 여러 작업을 같이 돌리려면 메모리 16GB 이상, 저장 공간은 여유 있게 512GB 이상을 권합니다. Cowork 작업 공간과 결과 파일이 쌓입니다.
    - 가장 비싼 모델이 필요하지는 않습니다. 무거운 계산은 Anthropic 서버에서 하기 때문입니다.

!!! tip "데이터 분석을 더 효율적으로 하고 싶어요"
    오늘은 기본기에 시간을 더 쓰기 위해 '부록 4, (선택) 혼자 해 보기'의 A-6에 남겼습니다. 핵심은 '분석 전에 데이터부터 설명하게 하기'와 '계산은 수식으로 남기기'입니다. 1교시 1-3의 Finance 차이 분석도 같은 KPI 엑셀로 해 봅니다.

## 오늘 나오는 말

| 말 | 쉽게 말하면 |
| --- | --- |
| Chat / Cowork | 묻고 답하는 곳 / 내 폴더를 연결해 일을 맡기는 곳 |
| 컨텍스트 | Claude가 지금 이 대화에서 보고 있는 모든 것. 비서의 책상 위. 대화가 끝나면 치워진다 |
| 지침 | 늘 지켜야 하는 규칙. 사내 규정집. 전체 지침, 폴더 지침, Project 지침이 있다 |
| 메모리 | 대화 중 골라 적어 두는 나와 일에 대한 주제. 비서의 수첩. 팀 계정은 기본 꺼짐, 내 PC에서 도는 Cowork는 쓰지 않음 |
| 스킬 | 특정 일을 하는 방법을 적은 업무 매뉴얼. 그 일이 올 때만 꺼낸다 |
| 아티팩트 | Claude가 대화 옆에 띄워 주는 화면(대시보드, 인포그래픽, 표). 파일은 폴더에, 화면은 아티팩트에 |
| 사용자 지정(Customize) | 스킬, 커넥터, 플러그인을 모아 둔 곳. 왼쪽 메뉴에 있다 |
| 탐색 / 체험 | 남이 만든 스킬 구경하는 탭 / 설치 전에 대화로 한 번 써 보기 |
| 플러그인 | 스킬과 커넥터를 한 묶음으로 담은 꾸러미 (예: Data, Finance) |
| / (슬래시) | 입력창에 치면 쓸 수 있는 스킬과 기능이 목록으로 뜬다 |
| 사용량 | 내 사용 한도를 얼마나 썼는지. Cowork와 Research는 많이 쓴다 |
| Project (프로젝트) | 자료(지식)와 규칙(지침)을 미리 넣어 둔 작업방. 오늘은 부록 4 (선택) |
| KPI | 핵심 성과 지표. 회사가 목표로 관리하는 숫자 |
| BLUF (블러프) | 결론을 맨 위에. 첫 줄만 읽어도 판단할 수 있게 쓰는 방식 |
| 예약 작업 (예약됨, Scheduled) | 알람처럼 정해진 시간에 Claude가 알아서 시작하는 일. 왼쪽 메뉴 더보기 안에 있다 |
| 커넥터 | Claude와 Gmail, 캘린더, 드라이브 같은 앱을 잇는 연결선. 6회차에 다 같이 연결한다 |

!!! note "오늘은 기본부터 다시 천천히 갑니다"
    - 단계마다 '개념 한 장 → 강사와 같이 → 화면 확인 → 다음 단계' 순서로 갑니다.
    - 앞서가지 않아도 됩니다. 각 단계의 '기대 결과'가 보이면 손을 들어 주세요.
    - 막히면 그 단계는 강사 화면을 보고, 다음 단계에서 다시 같이 합니다.
