# 화면 지도 (참고)

메뉴가 어디 있는지 헷갈릴 때 보는 페이지입니다. 1교시 1-1에서 이 페이지를 옆에 띄워 두고 하나씩 눌러 봅니다.

## ① 왼쪽 메뉴

| 메뉴 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| New | 새 대화나 작업 시작 | 매 실습의 시작점 |
| Projects | 자료와 규칙을 담아 둔 작업방 | 오늘 2교시 |
| Artifacts | 지금까지 만든 한 장짜리 화면(인포그래픽, 표, 대시보드) 모아 보기 | 만든 결과 다시 찾기 |
| Code | Claude Code, 개발자용 | 쓰지 않습니다 |
| Customize | 스킬, 커넥터 관리 | 스킬 켜고 끄기, 올리기, 내용 보기 |
| Pinned | 자주 쓰는 Project나 대화를 위에 고정 | 전략 참모 Project 고정 |
| Chats and tasks | 지난 대화와 작업 목록 (오른쪽 아이콘은 필터) | 4회차 대화 다시 열기 |
| 맨 위 돋보기 | 지난 대화 검색 | '산업분석'으로 찾기 |

## ② 프로필 메뉴 (왼쪽 아래 내 이름)

| 메뉴 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| 설정 (Mac ⌘ + ,) | 기능 켜기, 메모리, 지침 | 메모리, 전체 지침 |
| 사용량 | 내 사용 한도를 얼마나 썼는지 | 한도에 걸리면 여기서 확인 |
| 언어 | 화면 언어 | 한국어로 |
| 도움 받기 | 공식 도움말 | 막힐 때 |
| 앱 및 확장 프로그램 다운로드 | 데스크톱 앱, 크롬 확장, 모바일 앱 | 휴대폰에서 브리핑 보기 |

교육용 팀 계정에서는 '플랜 업그레이드', '게스트 패스', 'API 키' 같은 메뉴가 안 보이거나 다를 수 있습니다. 쓰지 않는 메뉴라 괜찮습니다.
