## 화면 지도 ② 프로필 메뉴 (왼쪽 아래 내 이름)

| 메뉴 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| 설정 (Mac ⌘ + ,) | 기능 켜기, 메모리, 지침 | 메모리, 전체 지침 |
| 사용량 | 내 사용 한도를 얼마나 썼는지 | 한도에 걸리면 여기서 확인 |
| 언어 | 화면 언어 | 한국어로 |
| 도움 받기 | 공식 도움말 | 막힐 때 |
| 앱 및 확장 프로그램 다운로드 | 데스크톱 앱, 크롬 확장, 모바일 앱 | 휴대폰에서 브리핑 보기 |

교육용 팀 계정에서는 '플랜 업그레이드', '게스트 패스', 'API 키' 같은 메뉴가 안 보이거나 다를 수 있습니다. 쓰지 않는 메뉴라 괜찮습니다.

### 1-1. 화면 한 바퀴 돌기

메뉴가 어디 있는지 알면 막혔을 때 혼자 찾아갈 수 있습니다. 위 표를 보면서 하나씩 눌러 봅니다.

1. New를 눌러 새 작업을 엽니다. 위쪽 말풍선이 선택돼 있는지 봅니다.
2. Projects, Artifacts를 차례로 눌러 봅니다. 지금은 비어 있어도 괜찮습니다.
3. Customize를 누르고 Skills를 엽니다. 다음 단계에서 다시 옵니다.
4. 왼쪽 위 돋보기를 눌러 '산업분석'을 검색해 4회차 대화를 찾아봅니다.
5. 왼쪽 아래 내 이름 › 사용량을 열어 봅니다.
6. 왼쪽 아래 내 이름 › 언어가 한국어인지 봅니다.

!!! success "기대 결과"
    - 메뉴 6곳을 다 눌러 봤다.
    - 4회차 대화를 검색으로 찾았다.

!!! warning "주의"
    Code는 개발자용입니다. 누르지 않습니다. 들어갔으면 New를 누릅니다.

!!! tip "팁"
    Mac은 ⌘ + , 로 설정이 바로 열립니다.

!!! note "스킬, 다시 한 번"
    - 스킬은 잘된 일하는 방식을 저장해 둔 업무 매뉴얼입니다. 파일 이름은 SKILL.md(4회차에 본 .md 파일)입니다.
    - 맞는 일이 오면 Claude가 알아서 꺼내 쓰고, 입력창에 / 를 치면 직접 고를 수 있습니다.
    - 4회차에 만든 스킬: 산업분석(industry-competitor-analysis), 밸류체인진단(value-chain-diagnosis).

### 1-2. 내 스킬 확인하기

!!! abstract "경로"
    왼쪽 메뉴 › Customize › Skills

1. 목록에서 industry-competitor-analysis와 value-chain-diagnosis를 찾습니다.
2. 있으면 켜져 있는지(스위치) 봅니다. 하나를 눌러 내용을 읽어 봅니다.
3. 없으면 1-3으로, 있으면 1-4로 갑니다.

!!! success "기대 결과"
    스킬 2개가 켜져 있다 (또는 없다는 걸 확인했다).

!!! tip "팁"
    스킬 내용을 열면 # 제목과 - 목록 모양이 보입니다. 사람이 읽어도 이해되는 업무 매뉴얼입니다.

### 1-3. (없을 때만) 백업 스킬 올리기

!!! abstract "경로"
    Customize › Skills › + › Upload

[:material-download: industry-competitor-analysis.zip](../files/industry-competitor-analysis.zip){ .md-button .md-button--primary }
[:material-download: value-chain-diagnosis.zip](../files/value-chain-diagnosis.zip){ .md-button .md-button--primary }

1. 위 버튼으로 zip 파일을 내려받습니다. 압축을 풀지 않습니다.
2. Customize › Skills › + › Upload에서 zip 파일을 고릅니다.
3. 목록에 생기고 켜져 있는지 봅니다.

!!! warning "주의"
    스킬은 믿을 수 있는 곳에서 받은 것만 올립니다. 모르는 스킬에는 숨은 지시가 들어 있을 수 있습니다.

### 1-4. 스킬을 / 로 불러 한 줄로 실행

스킬의 힘은 긴 지시문 없이 한 줄로 같은 품질이 나오는 데 있습니다. 4회차에 30분 걸린 분석이 한 줄로 됩니다.

!!! abstract "경로"
    New › 폴더 AI전략기획실 연결 › 입력창에 /

1. 새 작업을 열고 AI전략기획실 폴더가 연결돼 있는지 봅니다.
2. 입력창에 / 를 치고 industry-competitor-analysis를 고릅니다.
3. 아래 한 줄을 이어서 입력하고 보냅니다.
4. 진행 화면에 스킬 이름이 보이는지 봅니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
[우리 경쟁사 또는 비교 기관 한 곳]을 중심으로 산업분석 해줘. 결과는 01_산업경쟁사에 Word로 저장해줘.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    [우리 경쟁사 또는 비교 기관 한 곳] = 화성정공

!!! success "기대 결과"
    4회차 2교시 리포트와 같은 목차로 결과가 나오고, 01_산업경쟁사에 Word 파일이 생긴다.

!!! tip "팁"
    결과를 기다리는 동안 다음 설명을 듣습니다. 10분이 넘으면 손을 들어 주세요.

### 1-5. 07_내스킬 폴더와 스킬목록 만들기

스킬이 늘어나면 이름도 기억이 안 나고, 이 교육 계정은 일정 기간 뒤 회수됩니다. 스킬 사본과 목록을 내 폴더에 두면 한눈에 보이고, 새 계정에서도 그대로 다시 올릴 수 있습니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
AI전략기획실 안에 07_내스킬 폴더를 만들어줘.

1. 지금 내 계정에 있는 스킬(industry-competitor-analysis, value-chain-diagnosis 등)의 SKILL.md 내용을 07_내스킬/스킬이름/SKILL.md로 사본 저장해줘.
2. 07_내스킬/스킬목록.md를 만들어 표로 정리해줘: 스킬 이름, 하는 일, 언제 쓰나, 한 줄 사용 예, 만든 날.
3. 앞으로 스킬을 새로 만들거나 고치면 이 폴더의 사본과 목록도 같이 고쳐줘. 이 규칙을 폴더 지침에 추가해줘.
```

!!! success "기대 결과"
    - 07_내스킬 안에 스킬 폴더와 스킬목록.md가 생긴다.
    - 폴더 지침에 사본 규칙이 추가된다.

!!! tip "팁"
    - Claude가 스킬 내용을 못 읽는다고 하면, 1-3의 백업 스킬 zip을 07_내스킬에 넣어도 됩니다. (화면 확인)
    - 스킬목록.md는 메모장(Mac은 텍스트 편집기)으로 열어 바로 볼 수 있습니다.
