# 화면 지도 (참고)

메뉴가 어디 있는지 헷갈릴 때 보는 페이지입니다. 1교시 1-2에서 이 페이지를 옆에 띄워 두고 하나씩 눌러 봅니다. 메뉴 이름은 한국어 화면 기준이고, 괄호 안은 영어 화면 이름입니다.

## ① Cowork 화면: 지난 시간에 일한 곳

| 보이는 것 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| 위쪽 말풍선 아이콘 | Claude (묻고 답하기, 일 맡기기) | 이 과정은 모두 여기서 |
| 입력창 왼쪽 아래 Cowork | 일 맡기기 | 선택 버튼이 없으면 통합 화면 |
| 폴더 선택 | AI전략기획실 연결 = Claude에게 준 권한 | 입력창 근처에 폴더 이름이 보인다 |
| 진행 화면 | 할 일 목록, 읽은 파일, 쓰인 스킬 | 스킬을 썼는지 확인 |
| 더보기 › 예약됨 (Scheduled) | 정해진 시간에 도는 예약 작업 | 오늘 3교시 |
| 위쪽 &lt;/&gt; 아이콘 | Claude Code, 개발자용 | 쓰지 않습니다 |

## ② 왼쪽 메뉴, 그리고 Chat

| 메뉴 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| 검색 | 지난 대화와 작업 찾기 | '산업분석'으로 4회차 대화 찾기 |
| 새로 생성 (⌘N) | 새 대화나 작업 시작 | 매 실습의 시작점 |
| 아티팩트 (Artifacts) | Claude가 만든 화면(대시보드, 인포그래픽, 표) 모아 보기 | 지난번 대시보드 다시 열기 |
| 사용자 지정 (Customize) | 스킬, 커넥터, 플러그인 | 스킬 구경, 체험, 켜고 끄기, 올리기 |
| 더보기 | 예약됨(예약 작업), Projects 등 나머지 메뉴 | Projects는 1-3a, 예약됨은 3교시 |
| 입력창 왼쪽 아래 Chat | 폴더 없이 묻고 답하기 | 짧은 질문, 아이디어, 초안 |
| 내 이름 ▾ | 설정, 사용량, 언어 | 멈추면 사용량부터 |

## ③ 사용자 지정 화면

| 보이는 것 | 뜻 | 이 과정에서 |
| --- | --- | --- |
| Skills 탭 | 업무 매뉴얼 | 1, 2교시 |
| 커넥터 탭 | Gmail, 캘린더, 드라이브 같은 앱 연결 | 6회차에 다 같이 |
| 플러그인 탭 | 스킬, 커넥터를 묶은 꾸러미 | 구경만 |
| 내 항목 / 탐색 | 내 계정에 있는 것(기본 제공 + '내 전체'로 저장, 업로드) / 남이 만든 것 | 탐색에서 Finance 체험 (1-3) |
| 카드의 체험 / + | 설치 전에 써 보기 / 설치 | 제작자 확인 후 |
| + 추가 › 업로드 | 스킬 zip 올리기 | 2교시 백업과 복원 |
| + 추가 › 마켓플레이스 추가 | 외부 출처를 통째로 연결 | 쓰지 않습니다 |

## ④ 프로필 메뉴 (왼쪽 아래 내 이름)

| 메뉴 | 뭐 하는 곳 | 이 과정에서 |
| --- | --- | --- |
| 설정 (Mac ⌘ + ,) | 기능 켜기, 메모리, 전체 지침 | 막힐 때 기능이 켜져 있는지 확인 |
| 사용량 | 내 사용 한도를 얼마나 썼는지 | 한도에 걸리면 여기서 확인 |
| 언어 | 화면 언어 | 한국어로 |
| 도움 받기 | 공식 도움말 | 막힐 때 |
| 앱 및 확장 프로그램 다운로드 | 데스크톱 앱, 크롬 확장, 모바일 앱 | 휴대폰에서 브리핑 보기 |

교육용 팀 계정에서는 '플랜 업그레이드', '게스트 패스', 'API 키' 같은 메뉴가 안 보이거나 다를 수 있습니다. 쓰지 않는 메뉴라 괜찮습니다.
