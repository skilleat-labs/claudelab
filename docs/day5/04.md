# 2교시 — 이슈 브리핑 스킬 → 매일 아침 브리핑 에이전트

**시간** 15:10–16:00 (실습 15:25–16:00)

**목표** 뉴스 한 건을 '우리 회사 영향'으로 바꾸는 방식을 스킬로 만들고, 평일 아침마다 알아서 돌게 한다.

!!! success "이 교시의 결과물"
    - ① 이슈브리핑 스킬 (exec-issue-briefing)
    - ② Google 커넥터 3개 연결
    - ③ 예약 작업 '매일 아침 이슈 브리핑' (평일 09:00)
    - ④ 첫 브리핑: 03_브리핑 폴더 + Drive + Gmail 초안

### 2-1. 뉴스 1건으로 브리핑 써 보기

!!! abstract "경로"
    Project '전략 참모' › 새 대화

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
<뉴스>
[기사 링크 또는 본문 붙여 넣기]
</뉴스>

이 뉴스를 우리 회사 경영진용 이슈 브리핑으로 써줘. 아래 순서와 제목을 그대로 써.

1. 한 줄 결론 — 우리에게 좋은지 나쁜지, 얼마나 큰지 한 문장
2. 무슨 일인가 — 사실 3줄 (누가, 무엇을, 언제부터) + 출처와 날짜
3. 우리 영향 — 매출, 원가, 고객, 공급망 4칸 표. 칸마다 영향 범위(억 원 또는 %p)와 계산 근거
4. 시나리오 3개 — 낙관, 기본, 비관. 각각 전제 조건과 영향 규모
5. 권고 액션 — 3개 이내, 담당 조직과 기한
6. 모니터링 지표 — 지켜볼 지표와 '이 값을 넘으면 다시 보고' 기준

회사 수치는 Project 지식을 기준으로 하고, 1쪽을 넘기지 마.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    - 뉴스: 미국 USMCA 원산지 요건 강화 (06_뉴스샘플/a_미국_원산지요건_강화.md)
    - 한 줄 결론 예: 멕시코 공장 미국향 물량에 관세가 붙으면 영업이익이 연 최대 [ ]억 원 줄 수 있다

### 2-2. 1~2번 고치기

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
두 가지만 고쳐줘. ① 우리 영향 표에 KPI 영향(예: 영업이익률 -0.3~-0.6%p) 열을 추가해. ② 권고 액션을 '이번 주, 이번 달, 이번 분기'로 나눠.
```

!!! tip "팁"
    내 보고 습관(예: 표 먼저, 3줄 이내)을 여기서 넣어 두면 매일 아침 브리핑이 그 모양으로 옵니다.

### 2-3. 스킬로 저장, 이슈브리핑

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 한 브리핑 방식을 스킬로 만들어줘.
- 이름: exec-issue-briefing
- 설명: 뉴스나 이슈를 받아 우리 회사의 매출, 원가, 고객, 공급망 영향을 추정하고 시나리오와 권고 액션을 담은 1쪽 경영진 브리핑을 쓴다. 이슈 브리핑, 뉴스 영향 분석, 아침 브리핑 요청 시 사용.
- 내가 고친 것(KPI 영향 열, 주, 월, 분기 액션)을 형식에 넣어줘.
- 영향은 반드시 범위와 계산식으로, 출처와 날짜 필수.
보여주고 확인 후 저장해줘.
```

!!! success "기대 결과"
    Customize › Skills에 exec-issue-briefing이 켜져 있다.

!!! tip "팁"
    막히면 백업 스킬 exec-issue-briefing.zip을 Customize › Skills › + › Upload로 올립니다.

### 2-4. Google 커넥터 연결

!!! abstract "경로"
    입력창 + › Connectors › Gmail, Google Calendar, Google Drive 각각 켜기 › Google 로그인

1. 세 커넥터를 하나씩 켭니다. Google 로그인 창이 뜨면 회사 Google 계정으로 로그인하고, 요청하는 권한을 읽은 뒤 허용합니다.
2. 모든 동작은 기본적으로 내 승인을 받고 실행됩니다.
3. 연결 확인 질문을 입력합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
내 Google 캘린더에서 이번 주 남은 회의 3개를 보여주고, Drive에서 '[최근 작업한 파일 키워드]' 파일을 찾아줘.
```

!!! warning "주의"
    - 회사 계정(Team, Enterprise)은 관리자가 조직에서 Google 커넥터를 먼저 켜야 목록에 보입니다.
    - 회사 Google Workspace가 외부 앱 연결을 막아 두었으면 로그인 단계에서 막힙니다 → IT 담당자 확인.
    - Gmail 커넥터는 첨부파일 내용을 읽지 못합니다.

### 2-5. Drive에 브리핑 폴더 만들기

1. 승인 창이 뜨면 내용을 읽고 허용합니다. 직접 Drive에서 만들어도 됩니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
내 Google Drive에 'AI전략기획실' 폴더를 만들고, 그 안에 '03_브리핑' 폴더를 만들어줘.
```

### 2-6. 예약 작업 만들기, 평일 09:00

예약 작업은 정해진 시간에 알아서 일하는 직원입니다. 한 번 만들어 두면 교육이 끝난 다음 날에도 계속 돌아갑니다.

!!! abstract "경로"
    왼쪽 메뉴 › Scheduled › New task › Set up manually

1. 아래 표대로 칸을 채웁니다. 'Create with Claude'를 고르면 대화로 설정할 수도 있습니다.

| 칸 | 입력값 |
| --- | --- |
| 이름 | 매일 아침 이슈 브리핑 |
| 프롬프트 | 아래 '예약 작업 프롬프트' 전체를 붙여 넣기 |
| 승인 모드 | 실행 전에 묻는 쪽(가장 보수적인 모드)으로 선택 (화면 확인)<br>익숙해지면 파일 저장만 자동 허용으로 바꿔도 됨 |
| 주기 | 평일 (Weekdays), 09:00  — 출근 전에 보고 싶으면 07:30 등으로 |
| 모델 (선택) | 비워 두거나 Opus 5.5. 매일 도는 작업이라 사용량이 걱정되면 Sonnet 5.5 |
| 폴더 | AI전략기획실 |

**예약 작업 프롬프트, [대괄호]만 바꿔 붙여 넣기**

```text
너는 [우리 회사]의 아침 이슈 브리핑 담당이다. 이슈브리핑 스킬(exec-issue-briefing)을 사용해.

1. [조사] 지난 24시간(월요일은 지난 72시간) 동안 나온 뉴스 중 우리 회사에 영향이 큰 이슈를 찾아.
   - 관심 키워드: [우리 회사], [경쟁사 A], [경쟁사 B], [경쟁사 C], [핵심 고객사], [관세, 규제 키워드], [주요 원자재]
   - 출처가 분명한 언론, 공시, 정부 발표만 쓴다. 중요한 사실은 두 곳 이상에서 확인한다.
2. [선별] 영향이 큰 순서로 최대 3건. 나머지는 제목과 링크만 '참고' 목록에 둔다.
3. [작성] 건별로 스킬 형식(한 줄 결론, 무슨 일, 우리 영향, 시나리오 3, 권고 액션, 모니터링 지표).
   회사 수치는 00_회사자료 폴더의 파일을 기준으로 한다.
4. [오늘 회의] 내 Google 캘린더에서 오늘 일정 중 외부 미팅과 경영회의를 찾아,
   회의마다 '회의 전에 알아 둘 것' 3줄을 덧붙인다.
5. [저장] '브리핑_YYMMDD' 이름의 Word 파일로 03_브리핑 폴더에 저장하고,
   Google Drive의 'AI전략기획실/03_브리핑' 폴더에도 올린다.
6. [알림] 결론 3줄과 Drive 파일 링크를 담아 나에게 보내는 Gmail '초안'만 만든다. 절대 보내지 않는다.
7. 새 이슈가 없으면 '특이 이슈 없음'과 확인한 키워드만 한 줄로 남긴다.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    키워드: 한빛정밀, 대성오토텍, 화성정공, 브렌텍, A사, USMCA, 철강 알루미늄 관세, 알루미늄 가격

!!! warning "주의"
    - 회사 계정(Team, Enterprise)에서 컴퓨터가 잠자기 상태이거나 앱이 닫혀 있을 때도 도는지는 문서가 불명확합니다 (화면 확인). 첫 주는 컴퓨터를 켜 두고 확인하세요.
    - 로컬 폴더(03_브리핑)에 저장하는 작업은 그 컴퓨터에서만 실행됩니다.

### 2-7. 수동 1회 실행, 첫 브리핑 받기

!!! abstract "경로"
    Scheduled › 매일 아침 이슈 브리핑 › 지금 실행(Run now) (화면 확인)

1. 지금 한 번 돌려 결과를 확인합니다. 내일 아침 9시를 기다리지 않습니다.
2. Drive 업로드, Gmail 초안 승인 창이 뜨면 내용을 읽고 허용합니다.
3. 결과를 세 곳에서 확인합니다: 03_브리핑 폴더, Drive 'AI전략기획실/03_브리핑', Gmail 임시보관함

!!! success "기대 결과"
    - 03_브리핑/브리핑_YYMMDD.docx
    - Drive 폴더에 같은 파일
    - Gmail 임시보관함에 나에게 보내는 초안 1개 (보내지지 않은 상태)

!!! warning "주의"
    메일이 실제로 보내졌다면 프롬프트 6번 문장을 확인하고 승인 모드를 더 보수적으로 바꿉니다. Gmail 보내기 가능 여부는 계정마다 다를 수 있습니다 (화면 확인).

### 2-8. 브리핑 고치기 → 스킬, 예약 작업에 반영

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
오늘 브리핑에서 [아쉬운 점, 예: 참고 뉴스가 너무 많다 / 영향 숫자 근거가 약하다]. 앞으로 매일 이렇게 나오도록 이슈브리핑 스킬을 고쳐줘.
```

!!! tip "팁"
    형식 문제는 스킬을, 키워드, 시간, 저장 위치 문제는 예약 작업 프롬프트를 고칩니다.

### 2-9. (보너스) 다음 회의 맞춤 브리핑

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
내 캘린더에서 다음 외부 회의를 찾아줘. 참석자 회사의 최근 6개월 이슈, 우리와의 관계(Project 지식 기준), 내가 회의에서 물어야 할 질문 3개, 조심할 점 1개를 1쪽으로 정리해줘.
```

!!! tip "팁"
    도전: 같은 프롬프트를 "내일 회의"로 바꿔 평일 저녁 예약 작업으로 만들면, 매일 저녁 내일 회의 브리핑이 준비됩니다.
