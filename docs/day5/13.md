# 부록 4 — (선택) 혼자 해 보기: Project와 KPI 분석

5회차 수업에서는 기본기와 스킬에 시간을 더 쓰느라 이 내용을 부록으로 옮겼습니다. 시간이 남거나 교육이 끝난 뒤 혼자 해 볼 때 씁니다. 3교시와 6회차는 이 부록을 하지 않아도 진행됩니다.

**목표** 회사 자료와 규칙을 한 번 넣어 두고, 매번 설명하지 않아도 우리 회사 기준으로 답하는 작업방(Project)을 만든다. 엑셀 데이터 분석도 한 번 해 본다.

!!! success "이 부록의 결과물"
    - ① Project '전략 참모, [우리 회사]' (지식 + 지침)
    - ② Project 안과 밖 비교 메모
    - ③ KPI 분석 표와 차트 (Excel)

!!! note "Project는 1교시 개념 지도의 '지식 + 지침'을 한 방에 모은 것"
    - 지식: 작업방에 올려 둔 회사 자료. 그 방의 모든 대화가 참고합니다.
    - 지침: 그 방에서 Claude가 지킬 일하는 방식.
    - 메모리: 방별로 따로 기억합니다 (팀 계정은 기본 꺼짐).

!!! warning "우리 회사로 합니다"
    - 4회차에 만든 00_회사자료의 우리 회사 버전과 4회차 결과물을 씁니다.
    - 99_예시_한빛정밀 파일은 지식에 올리지 않습니다. 올리면 참모가 두 회사 숫자를 섞습니다.
    - [확인 필요]가 남은 숫자는 그대로 두세요. 참모도 '확인 필요'라고 답합니다.
    - 4회차를 한빛정밀로 진행했다면 한빛정밀로 합니다 (예시 상자 값).

### A-1. 지식 파일 준비, 회사 개요 1장 만들기

Project 지식은 '회사 사실의 기준'이 됩니다. 길고 많은 파일보다 정리된 짧은 파일이 낫습니다.

!!! abstract "경로"
    새로 생성 › 폴더 AI전략기획실 연결 › 새 작업

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
00_회사자료의 우리 회사 자료(회사개요, 사업보고서 요약, 밸류체인 메모)를 읽고 Project 지식용 '회사개요_1장'을 만들어줘. 99_예시_한빛정밀 폴더는 다른 회사 예시라 읽지 마.
구성: 회사 한 줄 소개, 사업별 매출 비중, 주요 고객, 생산 거점(또는 사업장), 올해 목표 숫자(KPI), 지금의 핵심 이슈 5개.
자료에 없는 칸은 나에게 3개까지 물어보고, 답이 없으면 [확인 필요]로 둬.
모든 숫자에 출처 파일명을 달고, 표 위주로 2쪽 이내. Word로 00_회사자료에 저장해줘.
```

!!! success "기대 결과"
    00_회사자료/회사개요_1장.docx

!!! tip "팁"
    지식으로 넣을 파일: 회사개요_1장, 경쟁사 공시요약, 밸류체인메모_인터뷰, 4회차 결과물(산업환경_리스크진단, 핵심과제123_정의서).

### A-2. Project 만들기

!!! abstract "경로"
    왼쪽 메뉴 › 더보기 › Projects › + New project (화면 확인)

1. 이름: 전략 참모, [우리 회사]
2. 설명: [우리 회사] 경영 판단을 돕는 전략 참모. 회사 자료와 4회차 진단 결과를 기준으로 답한다.
3. 만들기를 누릅니다.

### A-3. 지식 올리기

!!! abstract "경로"
    Project 화면 › 지식(Knowledge) › + 파일 추가 (화면 확인)

1. A-1에서 정한 파일 5개 안팎을 올립니다.
2. 올린 파일 목록에 모두 보이는지 확인합니다.

!!! warning "주의"
    - Project 안의 대화끼리는 서로의 내용을 모릅니다. 공유되는 것은 지식에 올린 파일과 지침뿐입니다.
    - Project는 공유하지 않습니다. 이 과정의 팀 조직에는 다른 회사 참가자도 있습니다.

### A-4. 지침 넣기, 전략 참모

지침은 이 Project 안의 모든 대화에 적용되는 '일하는 방식'입니다. 역할, 형식, 기준, 금지, 먼저 질문, 다섯 줄이면 충분합니다.

!!! abstract "경로"
    Project 화면 › 지침(Instructions) › 편집 (화면 확인)

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
[역할] 너는 [우리 회사] [내 직책]의 전략 참모야. 모든 답은 지식에 있는 회사 자료와 핵심 과제 1-2-3을 기준으로 판단해.
[형식] 결론부터 말해. 맨 위 한 줄 결론 → 근거 3개 → 우리 회사 영향 → 권고 액션 순서. 권고 액션에는 담당 조직과 기한을 붙여.
[기준] 숫자에는 출처와 기준일을 달고, 사실, 추정, 의견을 구분해 표시해.
[금지] 출처 없는 숫자, 우리 회사와 무관한 일반론, 확인 안 된 내용을 사실처럼 쓰기.
[먼저 질문] 질문이 애매하면 답하기 전에 무엇을 위한 것인지 먼저 물어봐. 질문은 최대 3개까지.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    [우리 회사] [내 직책] = (주)한빛정밀 전략기획실장

!!! tip "팁"
    메모리(지난 대화 기억)는 선택입니다. 설정 › 메모리에서 켤 수 있으면 켭니다. 팀 계정은 기본 꺼짐이고, 꺼져 있어도 지식과 지침만으로 충분합니다.

### A-5. 같은 질문, Project 안과 밖 비교

같은 질문을 Project 밖과 안에서 던져 보면, 회사 자료와 규칙을 넣어 둔 효과가 눈에 보입니다.

1. Project 밖(새로 생성 › 새 대화)에서 아래 질문을 먼저 입력합니다.
2. Project 안 새 대화에서 똑같이 입력합니다.
3. 두 답을 나란히 놓고 아래 비교표를 채운 뒤, 달라진 점 3가지를 메모합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
[요즘 우리 회사의 가장 큰 이슈]가 우리에게 어떤 의미야? 내가 이번 주에 할 일도 하나 알려줘.
```

| 비교 항목 | Project 밖 | Project 안 |
| --- | --- | --- |
| 우리 회사 수치를 인용했나 |  |  |
| 첫 줄이 결론인가 |  |  |
| 먼저 질문을 했나 |  |  |
| 바로 보고에 쓸 수 있나 (1~5점) |  |  |

!!! tip "답이 아쉬우면"
    "방금 답에서 [아쉬운 점]이 아쉬워. 이 Project 지침에 넣을 한 줄 규칙을 제안해줘"라고 하고, 제안받은 한 줄을 지침 맨 아래에 붙여 넣습니다.

### A-6. KPI 엑셀 분석: 데이터 설명부터

엑셀을 주고 '분석해줘'라고만 하면 Claude가 열의 뜻을 잘못 짐작한 채로 시작할 때가 있습니다. 분석 전에 데이터부터 설명하게 하고, 질문은 3개로 좁히고, 계산은 수식으로 남기게 합니다.

!!! abstract "경로"
    새로 생성 › 폴더 AI전략기획실 연결 › 새 작업

1. 1번 결과(열마다 뜻)를 보고 틀린 게 있으면 바로잡은 뒤 "이제 분석해줘"라고 합니다.
2. 알려 준 숫자 2개를 원본 셀에서 직접 찾아 맞는지 봅니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
[KPI 엑셀 파일 이름]을 분석해줘.

1. 먼저 시트와 열마다 뜻, 빈칸, 이상한 값을 표로 보여줘. 분석은 내가 확인한 다음에.
2. 질문: 목표 대비 가장 벌어진 지표 3개는? 데이터로 보이는 이유는?
3. 결과는 같은 엑셀의 새 시트에 표와 차트로. 계산은 수식으로 남겨.
4. 숫자는 원본에 있는 것만 써. 추정은 (E)로 표시해.

다 되면 원본 셀과 대조할 숫자 2개를 골라 위치와 함께 알려줘.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    [KPI 엑셀 파일 이름] = 99_예시_한빛정밀/02_2026_경영목표_KPI.xlsx (회사 원본 대신 연습용으로 써도 됩니다)

!!! success "기대 결과"
    - 엑셀에 분석 시트가 생기고, 표와 차트가 있다.
    - 셀을 눌러 보면 숫자가 아니라 수식이 들어 있다.

!!! tip "팁"
    - 질문을 3개 넘게 주면 답이 얕아집니다. 더 궁금한 것은 다음 대화에서 묻습니다.
    - 잘 되면 "이 분석 방식을 데이터분석 스킬로 만들어줘 (사본은 07_내스킬에)"로 저장해도 좋습니다.
