# 3교시 — 매일 일하는 에이전트

**시간** 16:10–17:00 (같이 하기 16:20–16:35, 16:40–17:00)

**목표** 뉴스 한 건을 '우리 회사 영향'으로 바꾸는 방식을 스킬로 만들고, 평일 아침마다 알아서 돌게 한다.

!!! success "이 교시의 결과물"
    - ① 이슈브리핑 스킬 (exec-issue-briefing)
    - ② 예약 작업 '매일 아침 이슈 브리핑' (평일 09:00)
    - ③ 첫 브리핑 (03_브리핑 폴더)

### 3-1. 뉴스 1건으로 브리핑 써 보기

!!! abstract "경로"
    새로 생성 › 폴더 AI전략기획실 연결 › 새 작업

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
<뉴스>
[기사 링크 또는 본문 붙여 넣기]
</뉴스>

이 뉴스를 우리 회사 경영진용 이슈 브리핑으로 써줘. 아래 순서와 제목을 그대로 써.

1. 한 줄 결론 — 우리에게 좋은지 나쁜지, 얼마나 큰지 한 문장
2. 무슨 일인가 — 사실 3줄 (누가, 무엇을, 언제부터) + 출처와 날짜
3. 우리 영향 — 매출, 원가, 고객, 공급망 4칸 표. 칸마다 영향 범위와 계산 근거
4. 시나리오 3개 — 낙관, 기본, 비관
5. 권고 액션 — 3개 이내, 담당 조직과 기한
6. 지켜볼 지표 — '이 값을 넘으면 다시 보고' 기준

회사 수치는 00_회사자료와 4회차 결과물(01_산업경쟁사, 02_밸류체인)을 기준으로 하고, 99_예시_한빛정밀 폴더는 읽지 마. 1쪽을 넘기지 마.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    뉴스: 미국 USMCA 원산지 요건 강화 (06_뉴스샘플/a_미국_원산지요건_강화.md, 강사 시연용 가상 기사)

!!! tip "팁"
    - 뉴스는 우리 회사와 관련된 기사 1건을 붙여 넣습니다.
    - 기사가 없으면 먼저 "[우리 회사]와 관련된 최근 1주일 뉴스 중 영향이 큰 1건을 찾아 링크와 함께 보여줘"라고 합니다.

### 3-2. 한 가지만 고치기

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
한 가지만 고쳐줘. [예: 권고 액션을 '이번 주, 이번 달, 이번 분기'로 나눠줘]
```

!!! tip "팁"
    내 보고 습관(예: 표 먼저, 3줄 이내)을 여기서 넣어 두면 매일 아침 브리핑이 그 모양으로 옵니다.

### 3-3. 스킬로 저장, 이슈브리핑

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 한 브리핑 방식을 스킬로 만들어줘.
- 이름: exec-issue-briefing
- 설명: 뉴스나 이슈를 받아 우리 회사의 매출, 원가, 고객, 공급망 영향을 추정하고 시나리오와 권고 액션을 담은 1쪽 경영진 브리핑을 쓴다. 이슈 브리핑, 뉴스 영향 분석, 아침 브리핑 요청 시 사용.
- 내가 고친 것을 형식에 넣어줘. 출처와 날짜는 필수.
- 저장하면 사본을 07_내스킬에 남기고 스킬목록.md에 한 줄 추가해줘.
보여주고 확인 후 저장해줘.
```

!!! success "기대 결과"
    - 사용자 지정(Customize) › Skills에 exec-issue-briefing이 켜져 있다.
    - 07_내스킬 스킬목록에 한 줄이 늘었다.

!!! tip "팁"
    막히면 백업 스킬 exec-issue-briefing.zip을 사용자 지정(Customize) › Skills › + 추가 › 업로드로 올립니다.

### 3-4. 예약 작업 만들기, 평일 09:00

예약 작업은 알람처럼 정해진 시간에 알아서 일하는 직원입니다. 한 번 만들어 두면 교육이 끝난 다음 날에도 돌아갑니다.

!!! abstract "경로"
    왼쪽 메뉴 › 더보기 › 예약됨 › 새 작업 (영어 화면: Scheduled › New task › Set up manually) (화면 확인)

1. 아래 표대로 칸을 채웁니다. 'Create with Claude'를 고르면 대화로 설정할 수도 있습니다.

| 칸 | 입력값 |
| --- | --- |
| 이름 | 매일 아침 이슈 브리핑 |
| 프롬프트 | 아래 '예약 작업 프롬프트' 전체를 붙여 넣기 |
| 승인 모드 | 실행 전에 묻는 쪽(가장 보수적인 모드)으로 선택 (화면 확인) |
| 주기 | 평일 (Weekdays), 09:00 |
| 폴더 | AI전략기획실 |

**예약 작업 프롬프트, [대괄호]만 바꿔 붙여 넣기**

```text
너는 [우리 회사]의 아침 이슈 브리핑 담당이다. 이슈브리핑 스킬(exec-issue-briefing)을 사용해.

1. [조사] 지난 24시간(월요일은 지난 72시간) 동안 나온 뉴스 중 우리 회사에 영향이 큰 이슈를 찾아.
   - 관심 키워드: [우리 회사], [경쟁사 또는 비교 기관 3곳], [핵심 고객], [정책, 규제 키워드]
   - 출처가 분명한 언론, 공시, 정부 발표만 쓴다.
2. [선별] 영향이 큰 순서로 최대 3건. 나머지는 제목과 링크만 '참고' 목록에 둔다.
3. [작성] 건별로 스킬 형식으로 쓴다. 회사 수치는 00_회사자료 폴더의 파일을 기준으로 한다.
4. [저장] '브리핑_YYMMDD' 이름의 Word 파일로 03_브리핑 폴더에 저장한다.
5. 새 이슈가 없으면 '특이 이슈 없음'과 확인한 키워드만 한 줄로 남긴다.
```

!!! example "키워드는 우리 회사 값으로"
    - 4회차 2-1에서 답한 값을 그대로 넣습니다: 회사명, 경쟁사 3곳, 핵심 고객, 정책과 규제.
    - 강사 시연(한빛정밀)은 가상 회사라 웹에 뉴스가 없어서, [조사] 줄을 '03_브리핑/뉴스 폴더에 새로 들어온 기사를 읽어'로 바꿉니다.

!!! warning "주의"
    - 팀 계정(Team)에서 컴퓨터가 잠자기 상태이거나 앱이 닫혀 있을 때도 도는지는 문서가 불명확합니다 (화면 확인). 첫 주는 컴퓨터를 켜 두고 확인하세요.
    - 로컬 폴더(03_브리핑)에 저장하는 작업은 그 컴퓨터에서만 실행됩니다.

!!! tip "커넥터는 6회차에 다 같이"
    브리핑을 캘린더, Gmail과 잇는 커넥터는 6회차 시작에 다 같이 연결합니다. 오늘은 03_브리핑 폴더에 저장하는 것까지 합니다.

### 3-7. (선택) 매일 아침 날씨 한 줄, 두 번째 예약 작업

예약 작업은 브리핑 말고도 매일 반복되는 작은 일에 씁니다. 출근 전에 오늘 날씨를 한 줄로 받아 봅니다. 시간이 남는 분만 합니다.

!!! abstract "경로"
    왼쪽 메뉴 › 더보기 › 예약됨 › 새 작업 (화면 확인)

1. 새 작업을 만들고 아래 표대로 칸을 채웁니다.
2. '지금 실행'으로 한 번 돌려 결과를 봅니다.
3. (선택) 휴대폰에 Claude 앱을 설치하고 같은 계정으로 로그인한 뒤 알림을 켭니다. 작업이 끝나면 휴대폰으로 알림이 올 수 있습니다. (화면 확인)

| 칸 | 입력값 |
| --- | --- |
| 이름 | 아침 날씨 한 줄 |
| 프롬프트 | 아래 '날씨 프롬프트'를 붙여 넣기 |
| 주기 | 평일 (Weekdays), 07:30 |
| 폴더 | AI전략기획실 (결과는 답으로만 받고 파일로 저장하지 않음) |

**날씨 프롬프트, [서울]은 내 지역으로 바꿔도 됩니다**

```text
서울 오늘 날씨를 기상청 날씨누리(weather.go.kr) 기준으로 찾아줘.
- 한 줄 요약: 최고, 최저 기온, 우산 필요 여부
- 시간대별: 비가 몇 시부터 몇 시까지 올 예정인지, 그 이후에는 그치는지 (시간별 강수확률 포함)
날씨누리에 없는 값은 네이버 날씨나 다음 날씨에서 채우고, 채운 값 뒤에 (네이버)처럼 출처를 붙여.
출처끼리 숫자가 다르면 날씨누리 값을 쓰고, 끝까지 못 찾은 값은 '확인 필요'로 표시해.
비 소식이 없는 날은 '종일 비 소식 없음' 한 줄로 끝내.
```

!!! success "기대 결과 (10/21 실제 결과 예)"
    - 한 줄 요약: 최고 15~18℃, 최저 9℃(다음) → 오전에 나가면 우산, 점심 이후 필요 없음
    - 시간대별: 아침 9시쯤까지 비(날씨누리 06~09시 한때 비, 다음 9시 60%), 10~11시 약하게 남을 수 있음(30%), 정오부터 비 소식 없음(12시 20%, 오후 0%)

!!! tip "팁"
    - '기상청 기준'과 '못 찾으면 확인 필요'를 넣으면, 출처마다 숫자가 다른 날에도 믿을 만한 한 줄이 옵니다.
    - 문자나 카카오톡으로 바로 보내는 공식 기능은 없습니다. 휴대폰으로 받으려면 Claude 앱 알림을 켜거나, 6회차에 Gmail을 연결한 뒤 '나에게 메일로 보내줘'를 더합니다.
    - 날씨누리는 권역 예보 페이지에 최저 기온과 강수확률이 비어 있을 때가 많아, 빈 값은 포털 날씨로 채우게 했습니다. 네이버가 막히면 다음에서 채웁니다.
