### 2-1. 우리 회사 버전으로 바꾸기: 틀은 두고 내용만 (우리 회사 경로)

1. 지시를 보내면 Claude가 6가지를 묻습니다. 짧게 답합니다.
2. 옮길 파일 목록이 나오면 확인하고 허용합니다. 폴더 지침에 '원본을 고치거나 지우지 않는다'가 있어 한 번 더 물을 수 있습니다. 옮기는 것이니 허용합니다.
3. 작업이 도는 동안(5~10분) 화면을 그대로 두고 앞을 봐 주세요. 강사가 입력창의 /와 +를 설명합니다.
4. 끝나면 [확인 필요] 목록을 보고, 내가 아는 것은 바로 알려 줍니다. 예: "작년 매출은 약 O조 원이야. 출처는 '본인 확인(추정)'으로 적어"

### 2-7. "방금 한 방식을 스킬로 만들어줘"

skill-creator가 이 대화에서 내가 시킨 순서, 기준, 형식, 수정 사항을 모아 SKILL.md로 정리합니다.

!!! abstract "경로"
    확인: 사용자 지정(Customize) › Skills › industry-competitor-analysis (켜짐)

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
방금 한 산업, 정책 환경 리스크 분석 방식을 스킬로 만들어줘.
- 이름: industry-competitor-analysis
- 설명(언제 쓰는지): 산업 동향, 경쟁사(또는 비교 기관), 정책, 규제, 통상 리스크를 분석해 임원 보고용 리포트를 만든다. 경쟁사 분석, 정책, 규제, 관세 영향 질문에 사용.
- 작업 순서: 자료 먼저 읽고 인용 뽑기 → 5개 축 정리 → 교차 확인 → 경쟁 가설과 확신도 → 리스크 매트릭스
- 내가 중간에 고쳐 달라고 한 것(결론 숫자화, 담당, 기한, 반대 근거 확인)도 기준에 넣어줘.
- 출력 형식과 검증 체크리스트를 포함해줘.
다 만들면 내용을 보여주고, 내가 확인한 뒤 저장해줘.
```
