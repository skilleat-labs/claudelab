# 시작 전 체크

아래 항목이 하나라도 안 되면 바로 손을 들어 주세요. 회사 계정은 관리자(Owner)가 먼저 켜야 하는 기능이 있습니다.

| 확인할 것 | 어디서 | OK |
| --- | --- | --- |
| Claude 데스크톱 앱에 회사 계정으로 로그인 | 앱 왼쪽 아래 프로필 › 조직(회사) 이름이 보이는지 (화면 확인) | ☐ |
| 앱이 최신 버전 | 메뉴 › 업데이트 확인 후 재시작. 왼쪽에 Cowork(또는 합쳐진 작업 화면)와 Scheduled가 보이는지 | ☐ |
| 코드 실행, 파일 생성 켜짐 (스킬, Word, PPT 만들기에 필요) | Settings › Capabilities › 코드 실행 및 파일 생성 (화면 확인) | ☐ |
| Skills 켜짐, skill-creator 사용 가능 | Customize › Skills › 목록에서 skill-creator 켜기 (화면 확인) | ☐ |
| 웹 검색, Research 사용 가능 | 입력창에 / 를 쳐서 deep-research가 보이는지, 또는 + 메뉴에 Research가 있는지 (화면 확인) | ☐ |
| Google 커넥터가 목록에 보이는지 (연결은 5회차) | 입력창 + › Connectors › Gmail, Google Calendar, Google Drive | ☐ |
| 메모리 메뉴가 보이는지 (설정은 5회차) | Settings › Memory (회사 계정은 기본 꺼짐) | ☐ |
| 모델 | 입력창 모델 선택 › Opus 5.5 (기본 추천). Fable 모델은 고르지 않기 (스탠다드 시트는 기본 사용량에 포함 안 됨) | ☐ |
| 사용량 확인 | Settings › Usage — 세션, 주간 한도와 초기화 시각 (Team 스탠다드: Pro의 약 1.25배) | ☐ |

!!! note "관리자가 켜야 하는 기능"
    - Team, Enterprise 계정에서는 조직 관리자(Owner)가 Cowork, 코드 실행(Skills), 메모리, Google 커넥터, 웹 검색을 먼저 켜야 개인 화면에 나타납니다.
    - 스킬 관련 조직 설정 위치: 조직 설정 › Plugins & skills (관리자 화면)
    - 사용량은 사람마다 따로 계산됩니다. Cowork, Research는 사용량을 많이 쓰니, 한도에 걸리면 손을 들어 주세요. 강사 백업 자료로 이어서 진행합니다.
