# 시작 전 체크

오늘은 세 가지만 확인하면 됩니다. 설치 6단계에서 이미 봤으면 건너뛰세요. Research, 스킬 같은 나머지 기능은 쓰는 단계에서 함께 켭니다.

| 확인할 것 | 어디서 | OK |
| --- | --- | --- |
| 교육용 팀 계정으로 로그인 | 앱 왼쪽 아래 프로필 › 운영 측 팀 조직 이름이 보이는지 (화면 확인) | ☐ |
| Cowork를 고를 수 있다 | 위쪽 말풍선 아이콘이 선택되어 있고(&lt;/&gt;는 개발자용), 입력창 왼쪽 아래에서 Cowork 선택. 선택 버튼이 없으면 이미 합쳐진 화면 (화면 확인) | ☐ |
| 모델은 Opus 5.5 | 입력창 모델 선택. Fable 모델은 고르지 않기 (스탠다드 시트는 기본 사용량에 포함 안 됨) | ☐ |

!!! note "기능이 안 보이면 강사에게"
    - 이 과정의 팀 조직 관리자는 운영 측입니다. Cowork, 코드 실행(Skills), 메모리, Google 커넥터, 웹 검색이 안 보이면 직접 설정하지 말고 강사에게 알려 주세요.
    - 사용량은 사람마다 따로 계산됩니다. Cowork, Research는 사용량을 많이 쓰니, 한도에 걸리면 손을 들어 주세요. 강사 백업 자료로 이어서 진행합니다.
