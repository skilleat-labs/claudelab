# 설치와 PC 준비 (첫 15분, 강사와 같이)

교육 첫 15분에 강사와 같이 설치합니다. 미리 하지 않아도 됩니다. Cowork는 내 PC 안에 작은 가상 컴퓨터를 띄워 그 안에서 일하기 때문에 가상화가 켜져 있어야 합니다. 가상화는 관리자 권한이 필요해 현장에서 고칠 수 없으니, IT 담당자가 교육 전에 0-1, 0-2만 확인해 두면 좋습니다. 자세한 안내: skilleat-labs.github.io/claudelab/install/

| 확인할 것 | Windows | Mac |
| --- | --- | --- |
| 운영체제 | Windows 10 (2004 이상) 또는 11<br>S 모드는 안 됨 | macOS 14 (Sonoma) 이상 |
| 설치 | claude.com/download에서 Windows용 내려받기 | claude.com/download에서 Mac용 내려받기 |
| 설치 허용 | 'Trusted app installs' 오류가 나면<br>설정 › 시스템 › 개발자용 › 개발자 모드 켜기<br>(회사 PC는 IT가 '신뢰할 수 있는 앱 설치 허용' 정책으로) | – |
| 가상화 | 작업 관리자에서 '가상화: 사용' 확인 (아래 0-1)<br>'사용 안 함'이면 직접 바꾸지 말고 IT 담당자에게 요청 | 따로 할 것 없음 |
| 사양 | 메모리 8GB 이상, 여유 공간 약 20GB | 같음 |
| 관리자 권한 | 설치와 가상화 설정에 필요 | 설치에 필요할 수 있음 |

### 0-1. 가상화가 켜져 있는지 확인 (Windows, 30초)

요즘 노트북은 대부분 처음부터 켜져 있습니다. 확인만 하면 됩니다.

!!! abstract "경로"
    작업 관리자 (Ctrl + Shift + Esc) › 성능 탭 › CPU

1. 오른쪽 아래 정보에서 '가상화' 항목을 찾습니다.

!!! success "기대 결과"
    '가상화: 사용'이면 끝입니다. 다음 단계로 넘어갑니다.

!!! warning "주의"
    '사용 안 함'이면 직접 바꾸지 마세요. BIOS 설정은 노트북마다 다르고, 회사 노트북은 잠겨 있는 경우가 많습니다. 화면을 사진으로 찍어 IT 담당자에게 보내 주세요.

!!! tip "팁"
    IT 담당자용 메모: BIOS에서 Intel VT-x 또는 AMD-V를 켜고, Windows 기능 'Virtual Machine Platform'을 켠 뒤 다시 시작해 주세요.

### 0-2. Cowork 준비 상태 점검 (5분)

Anthropic이 제공하는 점검 프로그램으로 내 PC가 Cowork를 쓸 수 있는지 한 번에 확인합니다. 설치나 로그인 없이 실행됩니다.

1. 내 PC에 맞는 점검 프로그램을 내려받아 실행합니다.
    - Windows (대부분의 노트북): [내려받기](https://claude.ai/api/desktop/win32/x64/cowork-readiness-check/latest/redirect)
    - Windows (Arm 노트북): [내려받기](https://claude.ai/api/desktop/win32/arm64/cowork-readiness-check/latest/redirect)
    - Mac: [내려받기](https://claude.ai/api/desktop/darwin/universal/cowork-readiness-check/latest/redirect)
2. 결과 화면에서 빨간 항목이 있으면 그 줄을 사진으로 찍어 IT 담당자에게 보냅니다.

!!! success "기대 결과"
    'This computer is ready for Cowork'가 나온다.

!!! warning "주의"
    가상화가 꺼져 있어도 채팅은 됩니다. 하지만 Cowork는 '사용할 수 없음'으로 나와서 실습을 따라 할 수 없습니다.

!!! tip "팁"
    설치 후 Claude 앱을 처음 열 때 작업 공간(1GB 이상)을 내려받습니다. 설치하자마자 바로 한 번 실행해 두세요.
