# 막혔을 때

혼자 5분 넘게 막히면 손을 들어 주세요. 강사의 백업 파일, 백업 스킬로 다음 단계부터 이어 갈 수 있습니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 설치 중 'Trusted app installs must be enabled' 오류 | Store 밖 앱 설치가 막혀 있음 | 설정 › 시스템 › 개발자용 › 개발자 모드 켜기. 회사 PC라 잠겨 있으면 IT에 '신뢰할 수 있는 앱 설치 허용' 요청 |
| 'Cowork를 사용할 수 없음' 또는 작업 공간이 시작되지 않음 | 가상화 꺼짐, 메모리 부족 | 작업 관리자에서 가상화 확인(0-1) → 준비 상태 점검(0-2) → 빨간 항목은 IT 담당자에게. 그동안 강사 화면 따라 보기 |
| Chat에서 계속하고 있었다 (폴더가 안 열리고 파일이 안 생긴다) | Chat은 묻고 답하기만 한다 | 입력창 왼쪽 아래에서 Cowork를 고른 뒤 폴더를 연결하고 같은 지시를 다시 보낸다 |
| 위쪽 &lt;/&gt; 화면에서 작업하고 있었다 | &lt;/&gt;는 개발자용 Claude Code | 위쪽 말풍선 아이콘을 누르고 Cowork에서 다시 시작 |
| Cowork 선택 버튼이 안 보인다 | 이미 Chat과 합쳐진 화면, 앱이 예전 버전, 조직에서 꺼짐 | 대화창에 바로 맡겨 본다 → 폴더 연결이 안 되면 앱 업데이트 후 재시작 → 그래도 안 되면 관리자에게 활성화 요청. 그동안 강사 화면 따라 보기 |
| 폴더 연결이 안 된다 / 파일을 못 찾는다 | 다른 폴더를 연결했거나 접근 허용을 안 함 | AI전략기획실 폴더를 다시 연결하고 접근 허용. "폴더에 있는 파일 목록 보여줘"로 확인 |
| 결과 파일이 생기지 않는다 | 코드 실행, 파일 생성이 꺼짐 | Settings › Capabilities에서 켜기 (화면 확인). 안 되면 화면 결과를 복사해 Word에 붙이기 |
| Skills 메뉴가 없다 | 코드 실행 꺼짐, 조직 설정에서 Skills 꺼짐 | Settings › Capabilities 확인 → 관리자에게 조직 설정 › Plugins & skills 확인 요청 |
| skill-creator가 없다 | 기본 스킬이 꺼져 있음 | Customize › Skills에서 켜기 → 없으면 강사 백업 스킬 ZIP 업로드 (2-9) |
| 스킬이 자동으로 안 불린다 | 설명(description)에 쓰는 상황이 안 맞음 | 입력창에 / 를 치고 직접 선택. 또는 "스킬 설명에 '경쟁사 분석'이라는 말을 추가해줘" |
| 출처 없는 숫자가 나온다 | 기준을 안 줬거나 웹에서 확인 실패 | "출처 없는 숫자는 지우고 '자료 부족'이라고 써줘" |
| Research가 너무 오래 걸린다 | 범위가 넓음 | 기간, 지역, 경쟁사 수를 줄여 다시 지시. 3분 넘으면 다른 단계 먼저 진행 |
| 웹 기사가 안 열린다 | 유료 기사, 접근 차단 | 기사 내용을 복사해 00_회사자료에 텍스트 파일로 넣고 "이 파일을 읽어" |
| 사용량 한도 안내가 뜬다 | 여러 단계 작업은 사용량을 많이 씀 | 작업을 작게 나누기. 잠시 뒤 다시 하거나 강사 백업 산출물(한빛정밀)로 연습을 이어 가기. 백업 산출물은 우리 회사 폴더에 섞지 않는다 |
