### 1-1. 빈 폴더를 만들고 Claude에 연결하기

Claude는 격리된 작업 공간(클라우드, 또는 내 PC 안의 작은 가상 컴퓨터)에서 일하고, 내 컴퓨터의 파일은 데스크톱 앱이 요청마다 권한을 확인한 뒤 연결한 폴더 안의 것만 내줍니다. 그래서 연결한 폴더가 곧 '권한'입니다. 공식 안내도 컴퓨터 전체가 아니라 작업 전용 폴더를 만들라고 권합니다.

!!! abstract "경로"
    바탕화면 › 새 폴더 › 이름 'AI전략기획실'  →  Claude 데스크톱 › 위쪽 말풍선 › 입력창 왼쪽 아래 Cowork › 폴더 선택 › AI전략기획실 (화면 확인)

1. Mac은 Finder, Windows는 파일 탐색기에서 바탕화면에 빈 폴더 'AI전략기획실'을 만듭니다. 안에는 아무것도 넣지 않습니다.
2. Claude 데스크톱 위쪽에서 말풍선 아이콘을 누릅니다. 입력창 왼쪽 아래에서 Cowork를 고릅니다. 선택 버튼이 없으면 이미 합쳐진 화면이니 그대로 씁니다.
3. 폴더 선택에서 AI전략기획실을 고르고 접근을 허용합니다.

!!! success "기대 결과"
    입력창 근처에 'AI전략기획실'이 표시된다. 설정 › Trusted folders 목록에도 나온다 (화면 확인).

!!! warning "주의"
    바탕화면 전체나 문서 폴더 전체를 연결하지 마세요. Claude는 연결한 폴더 안의 모든 파일을 읽고 쓸 수 있습니다.

!!! tip "팁"
    Finder(탐색기) 창을 Claude 창 옆에 나란히 띄워 두세요. 다음 단계에서 폴더가 생기는 모습을 직접 볼 수 있습니다.

### 1-2. 하위 폴더 만들기를 Claude에게 맡기기

채팅 AI는 폴더 만드는 '방법'을 알려 줍니다. 에이전트는 권한을 준 폴더 안에서 내 컴퓨터를 '직접' 다룹니다. 이 차이를 눈으로 확인하는 단계입니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 폴더 안에 아래 하위 폴더 7개를 만들어줘. 이름은 그대로 써줘.

00_회사자료 (원본 자료)
01_산업경쟁사 (4회차 1, 2교시 결과)
02_밸류체인 (4회차 3교시 결과)
03_브리핑 (5회차, 매일 아침 쌓임)
04_보고장표 (5회차 3교시)
05_신사업전략 (6회차)
06_최종패키지 (6회차 3교시)

괄호 안은 설명이니 폴더 이름에는 넣지 마. 다 만들면 폴더 목록을 보여줘.
```

!!! success "기대 결과"
    - 옆에 띄운 Finder(탐색기) 창에 00~06 폴더 7개가 생긴다.
    - Claude가 만든 폴더 목록을 보여 준다.

!!! tip "팁"
    - 승인을 묻는 창이 뜨면 무엇을 하려는지 읽고 허용합니다. 폴더를 만드는 것처럼 되돌릴 수 있는 일은 허용해도 됩니다.
    - 강사 질문: "방금 누가 폴더를 만들었나요?" 이것이 '일을 맡기는 AI'입니다.

### 1-3. 자료 정리를 Claude에게 맡기기

자료가 잘 정리되어 있어야 Claude도 잘 찾아 씁니다. 정리 원칙은 네 가지입니다. ① 원본은 00_회사자료 한 곳에 ② 파일 이름은 '번호_내용_연도' ③ 결과물은 회차 폴더에, 원본과 섞지 않는다 ④ 민감 자료(인사 정보, 미공개 계약)는 넣지 않는다.

[:material-download: 실습1_받은자료(정리전).zip](../files/practice1-materials.zip){ .md-button .md-button--primary }

1. 위 링크에서 '실습1_받은자료(정리전)'을 내려받아 압축을 풀고, 안의 파일을 모두 AI전략기획실 맨 위에 끌어다 놓습니다. 내 회사 공개 자료(사업보고서, 공시, 기사)가 있으면 함께 넣어도 됩니다.
2. 파일 이름이 '최종_v3(진짜최종)', '복사본'처럼 뒤죽박죽이어도 괜찮습니다. 정리는 Claude가 합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
AI전략기획실 맨 위에 놓은 파일들을 하나씩 열어서 내용을 확인해줘.

1. 00_회사자료 폴더로 옮기고, 이름을 '번호_내용_연도' 형식으로 바꿔줘. 예: 01_회사개요_2026
2. 내용이 같은 중복 파일이 있으면 최신본만 남기고, 나머지는 옮기지 말고 나에게 알려줘.
3. 다 끝나면 00_회사자료 안에 '자료목록' 파일을 만들어 파일마다 무슨 내용인지 한 줄씩 적어줘.

파일은 지우지 마. 바꾸기 전에 바꿀 이름 목록을 먼저 보여줘.
```

!!! success "기대 결과"
    - 바꿀 이름 목록을 먼저 보여 주고, 확인하면 옮긴다.
    - '회사소개_최종_v2'와 'v3'가 중복이라고 알려 준다.
    - 00_회사자료 안에 자료목록 파일이 생긴다.

!!! tip "팁"
    - "바꾸기 전에 목록을 먼저 보여줘" 한 줄이 안전장치입니다. 중요한 파일을 옮기거나 바꿀 때는 항상 붙이세요.
    - Claude는 허락 없이 파일을 영구 삭제하지 않습니다. 그래도 원본은 따로 백업해 두는 습관을 들이세요.

### 1-4. 폴더 지침 넣기

폴더 지침은 이 폴더에서 일할 때 매번 지킬 규칙입니다. 신입에게 주는 업무 수칙과 같습니다. 한 번 적어 두면 지시할 때마다 '출처 달아', '한국어로'를 반복하지 않아도 됩니다.

!!! abstract "경로"
    연결한 폴더 › 폴더 지침(Instructions) 편집 (화면 확인)  — 메뉴가 안 보이면 아래 입력을 대화창에 붙이고 "이걸 이 폴더의 지침으로 저장해줘"라고 합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 폴더는 [우리 회사] [내 직책]의 AI 전략기획실이다.
- 결과물은 한국어로, 임원 보고용으로 짧고 명확하게 쓴다.
- 모든 숫자에 출처(파일명 또는 링크)와 날짜를 단다. 확인 안 된 내용은 '추정'이라고 쓴다.
- 결과 파일은 알맞은 하위 폴더(01~06)에 '내용_YYMMDD' 형식 이름으로 저장한다.
- 00_회사자료의 원본 파일은 고치거나 지우지 않는다.
- 보내기, 삭제, 공유는 실행 전에 반드시 나에게 묻는다.
```

!!! tip "팁"
    - 처음부터 완벽하게 쓰지 않아도 됩니다. "이 폴더에 맞는 지침 초안을 써줘"라고 시킨 뒤 고쳐도 됩니다.
    - 지침은 언제든 바꿀 수 있습니다. 결과가 마음에 안 들 때마다 한 줄씩 늘려 가세요.

### 1-5. 위임 지시서 5요소로 맡기기

Claude는 '맥락을 모르는 유능한 신입'입니다. 목표, 맥락, 자료, 기준, 형식을 주면 바로 쓸 수 있는 결과가 나옵니다. 강사가 한 줄씩 무엇을 바꿔 쓰는지 설명합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
[목표] 다음 주 경영회의 보고용으로 경쟁사 3곳([경쟁사 A], [경쟁사 B], [경쟁사 C])의 최근 6개월 동향을 1장으로 정리해줘.

[맥락] 우리는 [업종, 주요 제품]을 하는 회사이고, 요즘 가장 큰 걱정은 [예: 미국 관세, 중국 경쟁사 저가 공세]야.
이 보고를 보고 경영진이 '우리가 지금 대응해야 할 경쟁사 움직임'을 판단하려고 해.

[자료] 00_회사자료 폴더의 경쟁사 자료와 업계 리포트를 먼저 읽고, 부족한 최신 내용은 웹에서 찾아줘.

[기준] 모든 숫자에 출처와 날짜를 달아. 확인 안 된 내용은 '추정'이라고 표시하고, 모르면 모른다고 써.

[형식] Word 1장. 맨 위 세 줄 요약 → 3사 비교표(매출, 영업이익률, 전략, 최근 이슈) → 우리에게 주는 시사점 3개.
파일 이름은 '경쟁사동향_1장'으로 01_산업경쟁사 폴더에 저장해줘.

시작 전에 궁금한 점이 있으면 먼저 물어봐.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    - [경쟁사 A/B/C] = 대성오토텍, 화성정공, 브렌텍
    - [걱정] = 멕시코 공장 생산분의 미국 관세, 중국 화성정공의 유럽 저가 공세

!!! tip "팁"
    - 폴더 지침에 이미 쓴 규칙([기준]의 출처, 날짜)은 빼도 됩니다. 그래도 한 번 더 쓰면 더 확실합니다.
    - 마지막 줄 "먼저 물어봐"를 지우지 마세요. 애매한 부분을 Claude가 먼저 확인합니다.

### 1-6. 질문에 답하고, 진행을 지켜보는 시간

일을 맡긴 뒤의 사람 역할은 '답하고 지켜보는 것'입니다. 강사와 같이 화면을 보며 Claude가 어떻게 일하는지 확인합니다.

1. Claude가 먼저 질문하면 짧게 답합니다. 예: "매출은 원화 기준으로", "시사점은 영업 관점으로"
2. 작업 계획과 진행 상황을 봅니다. 보통 파일 읽기 → 웹 검색 → 작성 → 저장 순서로 진행됩니다.
3. 승인을 묻는 창이 뜨면 무엇을 하려는지 읽고 허용합니다.

!!! success "기대 결과"
    - 3~10분 안에 01_산업경쟁사 폴더에 Word 파일이 생긴다.
    - 화면에서 파일을 미리 보거나 열 수 있다.

!!! tip "팁"
    - 기다리는 동안 다른 일을 해도 됩니다. 이것이 '일을 맡기는 AI'입니다.
    - 진행이 엉뚱한 방향이면 중간에 "잠깐, 경쟁사는 3곳만"처럼 바로 말해도 됩니다.
    - 10분이 넘어도 안 끝나면 손을 들어 주세요. 강사 백업 결과물로 다음 단계를 이어 갑니다.

### 1-7. 검증 3가지: 출처, 숫자, 반대 증거

AI는 그럴듯한 문장과 숫자를 잘 만듭니다. 임원 보고에 올리기 전 세 가지만 같이 확인합니다.

1. 출처: 표에 나온 링크 하나를 눌러 실제로 열리는지, 날짜가 최근인지 봅니다.
2. 숫자: 숫자 하나를 골라 00_회사자료의 원본 파일에서 직접 찾아봅니다. 맞나요?
3. 반대 증거: Claude가 찾은 반대 근거를 읽고, 결론을 바꿔야 할지 판단합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 보고서에서 가장 중요한 숫자 3개를 골라, 각각의 출처(파일명 또는 링크)와 날짜를 표로 보여줘.

그리고 이 보고서의 결론에 반대되는 근거가 있으면 찾아줘.
```

!!! warning "주의"
    핵심 숫자 1~2개는 반드시 내 눈으로 원문과 대조합니다. 이 일은 사람이 합니다.

!!! tip "팁"
    '추정' 표시가 붙어야 할 곳에 붙어 있는지도 함께 보세요.

### 1-8. 한 번 고쳐 달라고 하기

처음 결과가 100점일 필요는 없습니다. 주고받으며 다듬는 사람이 결과가 더 좋습니다(Anthropic Economic Index 2026.03).

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
좋아. 세 가지만 고쳐줘.
1. 세 줄 요약을 '그래서 우리는 무엇을 해야 하나'로 끝나게 바꿔줘.
2. 비교표에 '우리 회사' 열을 추가해 같은 기준으로 비교해줘.
3. 시사점마다 담당 조직(예: 영업본부)을 붙여줘.
같은 파일에 덮어쓰지 말고 '경쟁사동향_1장_v2'로 저장해줘.
```

!!! tip "팁"
    - 고칠 때는 '무엇이 마음에 안 드는지'보다 '어떻게 바뀌면 좋은지'를 말하면 빠릅니다.
    - "덮어쓰지 말고 v2로"를 붙이면 처음 결과와 비교할 수 있습니다.
    - 2교시에 이 방식을 스킬로 저장합니다. 마음에 든 지시는 지우지 마세요.
