    - 업종이 달라도 괜찮습니다. 자동차 부품 이야기가 아니라 일을 맡기고, 검증하고, 고치는 방식을 배우는 재료입니다.
    - 우리 회사로 바꾸는 일은 2교시 2-1에서 합니다.

### 1-1. 빈 폴더를 만들고 Claude에 연결하기

Claude는 격리된 작업 공간(클라우드, 또는 내 PC 안의 작은 가상 컴퓨터)에서 일하고, 내 컴퓨터의 파일은 데스크톱 앱이 요청마다 권한을 확인한 뒤 연결한 폴더 안의 것만 내줍니다. 그래서 연결한 폴더가 곧 '권한'입니다. 공식 안내도 컴퓨터 전체가 아니라 작업 전용 폴더를 만들라고 권합니다.

!!! abstract "경로"
    바탕화면 › 새 폴더 › 이름 'AI전략기획실'  →  Claude 데스크톱 › 위쪽 말풍선 › (선택 화면이면 Cowork) › 폴더 선택 › AI전략기획실 (화면 확인)

1. Mac은 Finder, Windows는 파일 탐색기에서 바탕화면에 빈 폴더 'AI전략기획실'을 만듭니다. 안에는 아무것도 넣지 않습니다.
2. Claude 데스크톱 위쪽에서 말풍선 아이콘을 누릅니다. 입력창 왼쪽 아래에 Chat/Cowork 선택이 보이면 Cowork를 고르고, 없으면(통합 화면) 그대로 둡니다.
3. 폴더 선택에서 AI전략기획실을 고르고 접근을 허용합니다.

!!! success "기대 결과"
    입력창 근처에 'AI전략기획실'이 표시된다. 설정 › Trusted folders 목록에도 나온다 (화면 확인).

!!! warning "주의"
    바탕화면 전체나 문서 폴더 전체를 연결하지 마세요. Claude는 연결한 폴더 안의 모든 파일을 읽고 쓸 수 있습니다.

!!! tip "팁"
    Finder(탐색기) 창을 Claude 창 옆에 나란히 띄워 두세요. 다음 단계에서 폴더가 생기는 모습을 직접 볼 수 있습니다.

### 1-2. 하위 폴더 만들기를 Claude에게 맡기기

채팅 AI는 폴더 만드는 '방법'을 알려 줍니다. 에이전트는 권한을 준 폴더 안에서 내 컴퓨터를 '직접' 다룹니다. 이 차이를 눈으로 확인하는 단계입니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 폴더 안에 아래 하위 폴더 7개를 만들어줘. 이름은 그대로 써줘.

00_회사자료 (원본 자료)
01_산업경쟁사 (4회차 1, 2교시 결과)
02_밸류체인 (4회차 3교시 결과)
03_브리핑 (5회차, 매일 아침 쌓임)
04_보고장표 (5회차 3교시)
05_신사업전략 (6회차)
06_최종패키지 (6회차 3교시)

괄호 안은 설명이니 폴더 이름에는 넣지 마. 다 만들면 폴더 목록을 보여줘.
```

!!! success "기대 결과"
    - 옆에 띄운 Finder(탐색기) 창에 00~06 폴더 7개가 생긴다.
    - Claude가 만든 폴더 목록을 보여 준다.

!!! tip "팁"
    - 승인을 묻는 창이 뜨면 무엇을 하려는지 읽고 허용합니다. 폴더를 만드는 것처럼 되돌릴 수 있는 일은 허용해도 됩니다.
    - 강사 질문: "방금 누가 폴더를 만들었나요?" 이것이 '일을 맡기는 AI'입니다.

### 1-3. 자료 정리를 Claude에게 맡기기

자료가 잘 정리되어 있어야 Claude도 잘 찾아 씁니다. 정리 원칙은 네 가지입니다. ① 원본은 00_회사자료 한 곳에 ② 파일 이름은 '번호_내용_연도' ③ 결과물은 회차 폴더에, 원본과 섞지 않는다 ④ 민감 자료(인사 정보, 미공개 계약)는 넣지 않는다.

[:material-download: 실습1_받은자료(정리전).zip](../files/practice1-materials.zip){ .md-button .md-button--primary }

1. 위 버튼으로 zip 파일을 내려받아 압축을 풉니다. Mac은 더블클릭, Windows는 마우스 오른쪽 › 압축 풀기(모두 추출)입니다.
2. 생긴 '실습1_받은자료(정리전)' 폴더를 열고, 안의 파일 8개만 모두 선택해 AI전략기획실 맨 위로 끌어다 놓습니다. 폴더째 넣지 않습니다.
3. 파일 이름이 '최종_v3(진짜최종)', '복사본'처럼 뒤죽박죽이어도 괜찮습니다. 정리는 Claude가 합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
AI전략기획실 맨 위에 놓은 파일들을 하나씩 열어서 내용을 확인해줘.

1. 00_회사자료 폴더로 옮기고, 이름을 '번호_내용_연도' 형식으로 바꿔줘. 예: 01_회사개요_2026
2. 내용이 같은 중복 파일이 있으면 최신본만 00_회사자료에 두고, 나머지는 AI전략기획실 안에 '98_중복보관' 폴더를 만들어 옮긴 뒤 알려줘.
3. 다 끝나면 00_회사자료 안에 '자료목록' 파일을 만들어 파일마다 무슨 내용인지 한 줄씩 적어줘.

파일은 지우지 마. 바꾸기 전에 바꿀 이름 목록을 먼저 보여줘.
```

!!! success "기대 결과"
    - 바꿀 이름 목록을 먼저 보여 주고, 확인하면 옮긴다.
    - '회사소개_최종_v2'와 'v3'가 중복이라고 알려 주고, 옛 버전을 98_중복보관에 둔다.
    - 00_회사자료 안에 자료목록 파일이 생기고, AI전략기획실 맨 위에는 파일이 남지 않는다.

!!! tip "팁"
    - "바꾸기 전에 목록을 먼저 보여줘" 한 줄이 안전장치입니다. 중요한 파일을 옮기거나 바꿀 때는 항상 붙이세요.
    - Claude는 허락 없이 파일을 영구 삭제하지 않습니다. 그래도 원본은 따로 백업해 두는 습관을 들이세요.

### 잠깐: .md 파일은 무엇이고, 왜 .md인가

받은 자료 중 끝이 .md인 파일(01_회사개요.md 등)은 마크다운(Markdown) 형식입니다. 메모장 글에 기호 몇 개를 붙여 제목과 목록을 표시한 것입니다. 메모장(Windows)이나 텍스트 편집기(Mac)로 열면 그대로 읽힙니다.

| 기호 | 뜻 | 예 |
| --- | --- | --- |
| # 제목 | 큰 제목 (# 하나) | # (주)한빛정밀 회사개요 |
| ## 소제목 | 소제목 (# 둘) | ## 사업부 |
| - 내용 | 목록 한 줄 | - 제동: 매출 5,704억 원 |
| **내용** | 굵게 | **2025 매출 1조 2,400억 원** |

!!! note "원리: 반드시 지킬 규칙은 대화가 아니라 파일에 둔다"
    - 대화에서 말한 규칙이 다음 작업에도 항상 적용되는 것은 아닙니다. 메모리 기능이 있어도 무엇을 기억할지는 Claude가 고르고, 새 작업은 앞 대화를 다 알지 못합니다.
    - 그래서 반복해서 지킬 규칙은 파일로 저장하고, 저장된 내용을 확인합니다. 폴더 지침과 스킬이 그것입니다.
    - Claude는 일을 시작할 때 이 파일을 읽고, 적힌 글이 그대로 판단의 기준이 됩니다. 스킬은 평소 이름과 설명만 읽다가 맞는 일이 오면 본문을 읽습니다.
    - 즉 이 파일은 사람이 보는 문서가 아니라 'Claude가 읽는 글'입니다. 글자만 들어가므로 글꼴, 색보다 구조(제목, 목록)가 분명한 .md가 맞습니다.

### 1-4. 폴더 지침 넣기: Claude에게 저장을 맡긴다

폴더 지침은 이 폴더에서 일할 때 매번 지킬 규칙입니다. 신입에게 주는 업무 수칙과 같습니다. 따로 찾을 메뉴는 없습니다. 아래 내용을 대화창에 붙여 넣고 저장을 맡기면, Claude가 이 폴더의 지침으로 저장하고 다음 작업부터 지킵니다 (공식 안내: Claude가 작업 중에 폴더 지침을 직접 업데이트할 수 있음).

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
아래 내용을 이 폴더(AI전략기획실)의 폴더 지침으로 저장해줘. 저장한 뒤 내용을 보여줘.

이 폴더는 (주)한빛정밀(가상 회사) 전략기획실의 작업 폴더다.
- 결과물은 한국어로, 임원 보고용으로 짧고 명확하게 쓴다.
- 모든 숫자에 출처(파일명 또는 링크)와 날짜를 단다. 확인 못 한 숫자는 지어내지 말고 '추정' 또는 [확인 필요]로 둔다.
- 결과 파일은 알맞은 하위 폴더(01~06)에 저장한다. 내가 이름을 정해 주면 그 이름을 쓰고, 정해 주지 않으면 '내용_YYMMDD' 형식으로 쓴다.
- 회사 정보는 00_회사자료 파일을 기준으로 한다.
- 00_회사자료의 원본 파일은 고치거나 지우지 않는다.
- 보내기, 삭제, 공유는 실행 전에 반드시 나에게 묻는다.
```

!!! success "기대 결과"
    Claude가 폴더 지침으로 저장했다고 알려 주고, 저장한 내용을 보여 준다.

!!! warning "주의"
    위쪽 &lt;/&gt; 화면(Claude Code)에서는 이 단계가 다르게 동작합니다. 위쪽 말풍선 화면에서 하세요.

!!! tip "팁"
    - 회사 이름 줄은 2교시 2-1에서 Claude가 우리 회사로 고칩니다.
    - 결과가 마음에 안 들 때마다 "이 규칙을 폴더 지침에 추가해줘"로 한 줄씩 늘려 갑니다.
    - 모든 작업에 적용할 규칙(예: 항상 한국어로)은 전체 지침에 넣습니다: 설정 › Cowork › Global instructions › 편집. 합쳐진 새 화면은 설정 › 일반 › Instructions for Claude (화면 확인).

### 1-5. 위임 지시서 5요소로 맡기기

Claude는 '맥락을 모르는 유능한 신입'입니다. 목표, 맥락, 자료, 기준, 형식을 주면 바로 쓸 수 있는 결과가 나옵니다. 강사가 한 줄씩 왜 들어가는지 설명합니다. 2교시부터 우리 회사로 바꿀 때는 이 다섯 칸의 내용만 바꾸면 됩니다.

**입력, 그대로 복사해 붙여 넣으세요**

```text
[목표] 다음 주 경영회의 보고용으로 경쟁사 3곳(대성오토텍, 화성정공, 브렌텍)의 최근 6개월 동향을 1장으로 정리해줘.

[맥락] 우리는 자동차 부품(제동, 섀시, 전동화 부품)을 만드는 (주)한빛정밀이고, 요즘 가장 큰 걱정은 멕시코 공장 생산분의 미국 관세와 중국 화성정공의 유럽 저가 공세야.
이 보고를 보고 경영진이 '우리가 지금 대응해야 할 경쟁사 움직임'을 판단하려고 해.

[자료] 00_회사자료 폴더의 경쟁사 자료와 업계 리포트만 써. 가상 회사라 웹에서는 찾지 마.

[기준] 모든 숫자에 출처 파일명을 달아. 확인 안 된 내용은 '추정'이라고 표시하고, 모르면 모른다고 써.

[형식] Word 1장. 맨 위 세 줄 요약 → 3사 비교표(매출, 영업이익률, 전략, 최근 이슈) → 우리에게 주는 시사점 3개.
파일 이름은 '경쟁사동향_1장'으로 01_산업경쟁사 폴더에 저장해줘.

시작 전에 궁금한 점이 있으면 먼저 물어봐.
```

!!! tip "팁"
    - 파일 이름을 정해 줬으므로 폴더 지침의 '내용_YYMMDD' 대신 '경쟁사동향_1장'으로 저장됩니다. 조금 다른 이름으로 저장돼도 실패가 아닙니다.
    - 마지막 줄 "먼저 물어봐"를 지우지 마세요. 애매한 부분을 Claude가 먼저 확인합니다.

### 1-6. 질문에 답하고, 진행을 지켜보는 시간

일을 맡긴 뒤의 사람 역할은 '답하고 지켜보는 것'입니다. 강사와 같이 화면을 보며 Claude가 어떻게 일하는지 확인합니다.

1. Claude가 먼저 질문하면 짧게 답합니다. 예: "매출은 원화 기준으로", "시사점은 영업 관점으로"
2. 작업 계획과 진행 상황을 봅니다. 보통 파일 읽기 → 작성 → 저장 순서로 진행됩니다. 승인을 묻는 창이 뜨면 무엇을 하려는지 읽고 허용합니다.
3. 끝나면 Word 파일을 엽니다. 화면의 파일 카드를 누르면 미리 볼 수 있고, Word로 열려면 Finder(탐색기) › AI전략기획실 › 01_산업경쟁사에서 파일을 더블클릭합니다.

!!! success "기대 결과"
    - 3~10분 안에 01_산업경쟁사 폴더에 Word 파일이 생긴다.
    - Word 파일이 열린다.

!!! tip "팁"
    - 기다리는 동안 다른 일을 해도 됩니다. 이것이 '일을 맡기는 AI'입니다. 강사는 이 시간에 .md와 폴더 지침의 원리를 설명합니다.
    - 진행이 엉뚱한 방향이면 중간에 "잠깐, 경쟁사는 3곳만"처럼 바로 말해도 됩니다.
    - 10분이 넘어도 안 끝나면 손을 들어 주세요. 강사 백업 결과물로 검증, 고치기를 이어 갑니다.

### 1-7. 검증 3가지: 출처, 숫자, 반대 증거

AI는 그럴듯한 문장과 숫자를 잘 만듭니다. 임원 보고에 올리기 전 세 가지만 같이 확인합니다.

1. 출처: 표에 나온 파일명이 00_회사자료에 실제로 있는지 봅니다.
2. 숫자: 숫자 하나를 골라 그 원본 파일을 직접 열어 찾아봅니다. 맞나요?
3. 반대 증거: Claude가 찾은 반대 근거를 읽고, 결론을 바꿔야 할지 판단합니다.
4. 틀린 숫자나 출처가 있으면 메모해 둡니다. 다음 단계에서 먼저 고칩니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
이 보고서에서 가장 중요한 숫자 3개를 골라, 각각의 출처(파일명과 위치)를 표로 보여줘.

그리고 이 보고서의 결론에 반대되는 근거가 있으면 찾아줘.
```

!!! warning "주의"
    핵심 숫자 1~2개는 반드시 내 눈으로 원문과 대조합니다. 이 일은 사람이 합니다.

!!! tip "팁"
    '추정' 표시가 붙어야 할 곳에 붙어 있는지도 함께 보세요.

### 1-8. 검증 결과부터 고치고, 한 번 더 다듬기

처음 결과가 100점일 필요는 없습니다. 검증에서 나온 오류를 먼저 고치고, 그다음 표현을 다듬습니다. 주고받으며 다듬는 사람이 결과가 더 좋습니다(Anthropic Economic Index 2026.03).

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
좋아. 먼저 검증에서 발견한 잘못된 숫자와 출처를 원본 파일 기준으로 고쳐줘. 고친 곳은 목록으로 보여줘.

그다음 세 가지를 고쳐줘.
1. 세 줄 요약을 '그래서 우리는 무엇을 해야 하나'로 끝나게 바꿔줘.
2. 비교표에 '우리 회사' 열을 추가해 같은 기준으로 비교해줘.
3. 시사점마다 담당 조직(예: 영업본부)을 붙여줘.
같은 파일에 덮어쓰지 말고 '경쟁사동향_1장_v2'로 저장해줘.
```

!!! success "기대 결과"
    - 고친 숫자와 출처 목록이 화면에 나온다.
    - 01_산업경쟁사에 경쟁사동향_1장_v2가 생기고, 열어 보면 v1과 달라진 점이 보인다.

!!! tip "팁"
    - 고칠 때는 '무엇이 마음에 안 드는지'보다 '어떻게 바뀌면 좋은지'를 말하면 빠릅니다.
    - "덮어쓰지 말고 v2로"를 붙이면 처음 결과와 비교할 수 있습니다.
    - 틀린 숫자가 없었으면 첫 줄은 "틀린 곳이 없는지 한 번 더 확인해줘"가 됩니다.
