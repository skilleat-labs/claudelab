## 참고, 휴대폰으로 일 시키기 (Dispatch)

휴대폰 Claude 앱에서 한 줄로 지시하면, 실제 일은 내 PC의 Cowork가 PC의 폴더, 스킬, 커넥터로 합니다. 끝나면 휴대폰으로 알림이 오고 파일은 PC 폴더에 남습니다. 예약 작업이 '정해진 시간에 알아서'라면, Dispatch는 '내가 아무 때나 밖에서'입니다.

- 조건: PC가 켜져 있고 Claude 앱이 열려 있어야 합니다. 노트북을 덮으면 멈춥니다.
- 대상: 2026년 10월 기준 개인 Pro, Max 계정 베타입니다. 교육용 Team 계정에서는 보이지 않을 수 있습니다.
- 그래서 에이전트를 많이 쓰는 사람들은 작은 컴퓨터(맥 미니 등)를 사무실에 늘 켜 두고 '에이전트 자리'로 씁니다.

!!! warning "회사에서 쓴다면"
    - 회사 계정, 회사 PC는 IT, 보안 승인이 먼저입니다.
    - PC 전체가 아니라 AI전략기획실 폴더만 연결하고, 메일 발송, 삭제, 결제는 맡기지 않습니다(초안까지만).
    - 휴대폰으로 PC에 일을 시킬 수 있으니 휴대폰 잠금이 곧 PC 열쇠입니다.

출처: support.claude.com, Assign tasks from anywhere in Claude Cowork (2026.10 확인). 메뉴 이름과 대상 플랜은 바뀔 수 있습니다.

## 참고, 내 컴퓨터 어디에 무엇이 남나

Claude를 쓰면 내 컴퓨터에 폴더가 몇 개 생깁니다. 평소에 열어 볼 필요는 없고, PC를 바꾸거나 막혔을 때 어디를 보면 되는지만 알아 두면 됩니다.

| 무엇 | Mac | Windows | 역할 |
| --- | --- | --- | --- |
| 내 작업 폴더 | 내가 고른 곳 (AI전략기획실) | 내가 고른 곳 (AI전략기획실) | 결과물. 이것만 백업하면 일은 남는다 |
| .claude 폴더 | ~/.claude | C:\\Users\\[이름]\\.claude | Cowork 엔진의 대화 기록, 전체 지침, 예약 작업, 설정 |
| 앱 데이터 폴더 | ~/Library/Application Support/Claude | C:\\Users\\[이름]\\AppData\\Roaming\\Claude | 앱 설정, 캐시, 설치한 스킬과 플러그인의 사본 |

- 점(.)으로 시작하는 폴더와 AppData, Library는 숨김 폴더입니다. Mac은 Finder에서 ⌘ + Shift + G 후 경로 입력, Windows는 탐색기 주소창에 %USERPROFILE%\\.claude 또는 %APPDATA%\\Claude 입력.
- 스킬의 원본은 계정 안에 있습니다. PC의 앱 폴더에 있는 것은 사본이라, 계정이 회수되면 스킬도 사라집니다. 그래서 07_내스킬 zip으로 가져갑니다(3-3).
- PC를 바꿀 때는 작업 폴더 + 07_내스킬 zip이면 충분합니다. 숨김 폴더는 새 PC에서 로그인하면 다시 생깁니다.
- Windows에서 Microsoft Store로 설치했다면 앱 데이터 폴더 위치가 다를 수 있습니다.

!!! warning "숨김 폴더는 남에게 보내지 않기"
    로그인, 연결된 서비스 인증 정보와 대화 기록이 들어 있습니다. 압축해서 공유하거나 클라우드에 올리지 않습니다. 이상하면 직접 지우지 말고 IT 담당에게 먼저 묻습니다.
