# 시작 전 체크

오늘은 3일 동안 쌓은 폴더 전체를 씁니다. 빠진 결과물이 있으면 그 단계의 스킬로 한 줄 다시 실행해 만듭니다 (예: "우리 회사로 산업분석 해줘"). 강사 백업 산출물(한빛정밀)은 한빛정밀로 진행하는 분만 씁니다.

| 확인할 것 | 어디서 | OK |
| --- | --- | --- |
| 예약 작업이 돌았는지 | 더보기 › 예약됨 › 매일 아침 이슈 브리핑 › 실행 기록 (화면 확인) | ☐ |
| Google 계정 로그인 정보, 휴대폰에 Google 캘린더와 Gmail 앱 | 1교시 끝 1-5 커넥터 연결 (개인 계정이면 됨) | ☐ |
| 03_브리핑에 아침 브리핑 파일이 있다 | AI전략기획실 › 03_브리핑 | ☐ |
| 내 스킬 확인 (없어도 진행됨) | 사용자 지정(Customize) › Skills › 내 항목. 4, 5회차에 만든 산업분석, 주간업데이트, 이슈브리핑 중 있는 것만. 없는 스킬이 있어도 오늘 지시는 그대로 됩니다 (보고서양식은 3교시에 받음) | ☐ |
| 4, 5회차 결과물이 폴더에 있다 | 01_산업경쟁사, 02_밸류체인, 04_보고장표. 02_밸류체인에 핵심과제123_정의서가 없으면 1-0a에서 한 줄로 만듭니다 | ☐ |
| Cowork에 AI전략기획실 폴더 연결 | 새 작업 › 폴더 선택 (화면 확인) | ☐ |
| 노트북 전원 연결 | 3교시에 여러 파일을 한 번에 만듭니다 | ☐ |

## 시작 15분: 개념 한 장 다시 보기

**채팅 → 에이전트 → 스킬 → 매일 일하는 에이전트** 

| 단계 | 한 줄로 | 비유 |
| --- | --- | --- |
| 채팅 | 내가 묻고, 한 번 답하고 끝. 파일도 결과물도 없이 | 전화로 묻기 |
| 에이전트 (Cowork) | 목표를 주면 스스로 단계를 나누고, 도구를 써서 결과물까지. 답변 중간에 파일 읽기, 검색, 명령 실행 같은 작업 줄이 보이면 에이전트로 일한 것 | 일하는 직원 |
| 스킬 | 에이전트가 일할 때 꺼내 보는 업무 매뉴얼 | 업무 매뉴얼 |
| 매일 일하는 에이전트 | 예약 작업으로 정해진 시간에 알아서 | 출근 시간 |

**화면에 나오는 말: 아티팩트, 도구 호출** 

| 말 | 뜻 | 화면에서 |
| --- | --- | --- |
| 아티팩트 (Artifact) | Claude가 대화 옆에 띄워 주는 화면. 대시보드, 표, 인포그래픽, 계산기 | 왼쪽 메뉴 '아티팩트'에 모인다. 파일(Word, 엑셀)은 폴더에, 화면은 여기에. 공유 버튼은 교육 계정에서 누르지 않는다 |
| 도구 호출 (Tool call) | 에이전트가 손을 쓴 기록. 폴더 읽기, 웹 검색, 커넥터, 스킬 실행 | 답변 중간에 접혀 있는 작업 줄(파일 읽기, 검색, 명령 실행 등). 누르면 펼쳐져 무엇을 읽고 무엇을 실행했는지 보인다. 되돌릴 수 없는 도구는 실행 전에 승인을 묻는다 |

**온콜(On-call)은 무엇인가요?** 

| 항목 | 내용 |
| --- | --- |
| 어떤 기능 | Claude를 장애 대응 '당번' 옆에 세운다. 모니터링 알림을 지켜보다가 이상이 생기면 Slack 채널에 원인 후보를 올리고, 장애 채널에 들어가 팀과 같이 조사한다 |
| 어디에 | Team, Enterprise 플랜. claude.ai › Code › 왼쪽 On-call (claude.ai/oncall). Slack, 모니터링 도구, 코드 저장소를 연결해 쓴다. 공개 베타 |
| 언제 쓰나 | 서비스가 24시간 돌아가서 밤이나 주말에도 장애를 빨리 알아채고 원인을 좁혀야 할 때 |
| 많이 쓰는 부서 | 서비스 개발팀, 인프라, 운영팀(SRE, DevOps), IT 운영팀. 경영진은 '장애 보고가 빨라지고 원인이 정리된 채로 올라온다'로 체감 |
| 예시 | 새벽 2시 결제 오류 알림 → Claude가 #incident 채널에 '오후 배포 이후 오류 급증, 관련 로그 3건' 요약 → 당번 개발자가 확인하고 되돌린다. 결정과 수정은 사람이 한다 |
| 비용 | 사용량은 조직에 청구, 월 지출 한도를 걸 수 있다 |

출처: claude.com/docs/claude-tag/admins/setup-oncall (2026.10 확인)

**이럴 땐 이걸 쓰면 어떨까요?** 

| 이런 경우엔 | 이걸 써 보세요 | 왜 |
| --- | --- | --- |
| 회의 5분 전, 'M&A 실사가 뭔지' 간단히 알고 싶을 때 | 채팅 | 짧은 질문, 파일도 결과물도 필요 없다 |
| 맡길 때마다 '결론부터, 숫자엔 출처'라고 매번 쓰고 있을 때 | 지침 | 매번 하는 말은 규정집에 한 번만 |
| 폴더의 계약서 20개를 읽고 만료일, 위약금을 엑셀로 정리할 때 | Cowork (에이전트) | 파일 여러 개, 여러 단계, 결과물이 파일 |
| 매달 실적 엑셀로 같은 형식의 경영회의 보고서를 만들 때 | 스킬 | 반복되고, 우리 회사만의 형식이 있다 |
| 매일 아침 출근 전에 경쟁사 뉴스 브리핑을 받고 싶을 때 | 예약 작업 + 스킬 | 시간은 예약이, 형식은 스킬이 |
| 매주 지점 50곳의 엑셀을 합쳐 사내 시스템에 자동으로 올릴 때 | Code (개발자와 함께) | 결과물이 계속 돌아가는 프로그램일 때 |

!!! tip "헷갈리면 세 가지만"
    파일이 필요하면 Cowork, 매번 하면 스킬, 정해진 시간이면 예약

## 어제(5회차) 질문에 대한 답

| 질문 | 답 |
| --- | --- |
| 내가 만든 스킬은 어디서 보나요? | 가장 확실한 곳은 07_내스킬/스킬목록. 사용자 지정 › Skills › 내 항목에는 저장할 때 '내 전체'를 골랐거나 zip으로 업로드한 스킬만 보인다. 없으면 07_내스킬의 그 스킬 폴더를 zip으로 묶어 + 추가 › 업로드, 올린 뒤 새 작업에서 / 로 확인 |
| 토큰(사용량)을 줄이려면? | 주제가 바뀌면 새 대화, 큰 파일은 필요한 부분만, 지시를 구체적으로 써서 다시 하기 줄이기, 안 쓰는 스킬은 끄기. 교육 계정(Team)은 쓴 만큼 돈을 더 내는 방식이 아니라 사용 한도가 있는 방식 (내 이름 › 사용량) |
| 아티팩트, 온콜은 무엇인가요? | 아티팩트 = 대화 옆에 뜨는 화면(대시보드, 표). 온콜 = Team 플랜 Code 메뉴의 장애 대응 기능 (아래 표) |
| 에이전트끼리 주고받는 모습을 보고 싶어요 | 오늘 2교시 'AI 검토자 4명 동시 검증'(2-2)에서 직접 봅니다. 각자 혼자 하는 실습입니다 |

**여러 폴더, 여러 일을 나눠 쓰려면? 폴더와 Project** 

| 방법 | 이렇게 합니다 |
| --- | --- |
| 한 가지 일 = 한 폴더 | 새 작업을 열 때 폴더를 고릅니다. 입력창 근처의 폴더 이름을 눌러 다른 폴더로 바꿀 수 있습니다 |
| 자주 쓰는 폴더는 '환경으로 저장' | 화면 위 안내의 '환경으로 저장'을 누르면, 다음부터 클릭 한 번으로 그 폴더에서 시작합니다 |
| 일마다 규칙이 다르면 Project | 왼쪽 Projects › + → 처음부터(새 폴더를 만듦), 기존 폴더 사용(AI전략기획실 같은 폴더를 그대로), Chat 프로젝트 가져오기. 폴더, 지침, 파일을 한 방에 둡니다 |
| Project 열기 | 왼쪽 Projects에서 누르면 그 폴더와 지침이 적용된 새 작업이 열립니다. 메모리도 Project마다 따로 기억합니다 |
| Team 계정 주의 | 내 PC 폴더로 만든 Project는 그 PC에만 있어서 다른 PC에서는 안 보일 수 있습니다 (화면 확인) |

예: AI전략기획실(전략), 영업보고, 개인업무를 각각 Project로 만들어 두면, 왼쪽에서 눌러 바로 그 일로 들어갑니다. 출처: Claude 도움말 'Organize your tasks with projects in Claude Cowork'

**PC가 꺼져 있어도 예약 작업이 도나요?** 

| 경우 | 답 |
| --- | --- |
| 내 PC 폴더가 필요한 작업 (03_브리핑에 저장하는 브리핑) | 그 PC에서만 돕니다. PC가 꺼져 있으면 돌지 못합니다 (공식: 로컬 파일이나 앱이 필요한 예약 작업은 로컬에서만 실행) |
| 폴더가 필요 없는 작업 (날씨처럼 답만 받기) | Pro, Max는 클라우드에서 돌아 PC가 꺼져 있어도 됩니다 (강사 계정 확인). Team 교육 계정은 확인 중 |
| 그래서 이렇게 | ① 밤새 PC와 Claude 앱을 켜 두고 잠자기 끄기 ② 예약 시간을 출근 후로 (예: 09:15) ③ 결과를 폴더 대신 답으로 받고 휴대폰 알림으로 보기 |
| 아침에 확인 | 더보기 › 예약됨 › 실행 기록에서 돌았는지 봅니다. 안 돌았으면 '지금 실행'을 한 번 누릅니다 |

## 오늘 나오는 말

| 말 | 쉽게 말하면 |
| --- | --- |
| 신사업 | 새로 시작할 사업. 공공기관, 대학은 '새로 시작할 사업이나 서비스'로 읽는다 |
| 스크리닝, 가중치 | 같은 잣대로 점수를 매겨 좁히기, 잣대마다 얼마나 중요하게 볼지 정한 비율 |
| BM 캔버스 | 사업 모델을 9칸으로 그린 한 장 그림 (누구에게, 무엇을, 어떻게 팔고, 무엇으로 버는지) |
| 중단 기준 (kill criteria) | 시작 전에 정해 두는 '이러면 접는다' 조건 3개 |
| 서브에이전트 | 하위 작업자. 큰 일을 나눠 여러 AI가 동시에 따로 맡는 것 |
| 경쟁 가설 | 한 가지 움직임에 대한 여러 해석. 각각 확신도와 확인할 신호를 붙인다 |
| C-Level | CEO, CFO 같은 최고경영진 |
| 플러그인 | 스킬, 커넥터 등 여러 기능을 한 묶음으로 설치하는 것 |

!!! note "오늘도 천천히 갑니다"
    - 단계마다 '개념 한 장 → 강사와 같이 → 화면 확인 → 다음 단계' 순서로 갑니다.
    - (선택)이 붙은 단계는 시간이 남는 분만 합니다. 못 해도 오늘 결과물에는 문제가 없습니다.
    - 막히면 그 단계는 강사 화면을 보고, 다음 단계에서 다시 같이 합니다.
