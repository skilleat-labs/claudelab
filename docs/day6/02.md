## 시작 15분: 개념 한 장 다시 보기

**채팅 → 에이전트 → 스킬 → 매일 일하는 에이전트** 

| 단계 | 한 줄로 | 비유 |
| --- | --- | --- |
| 채팅 | 내가 묻고, 한 번 답하고 끝. 파일도 결과물도 없이 | 전화로 묻기 |
| 에이전트 (Cowork) | 목표를 주면 스스로 단계를 나누고, 도구를 써서 결과물까지. 화면에 '사용한 도구 N개'가 보이면 에이전트로 일한 것 | 일하는 직원 |
| 스킬 | 에이전트가 일할 때 꺼내 보는 업무 매뉴얼 | 업무 매뉴얼 |
| 매일 일하는 에이전트 | 예약 작업으로 정해진 시간에 알아서 | 출근 시간 |

**이럴 땐 이걸 쓰면 어떨까요?** 

| 이런 경우엔 | 이걸 써 보세요 | 왜 |
| --- | --- | --- |
| 회의 5분 전, 'M&A 실사가 뭔지' 간단히 알고 싶을 때 | 채팅 | 짧은 질문, 파일도 결과물도 필요 없다 |
| 맡길 때마다 '결론부터, 숫자엔 출처'라고 매번 쓰고 있을 때 | 지침 | 매번 하는 말은 규정집에 한 번만 |
| 폴더의 계약서 20개를 읽고 만료일, 위약금을 엑셀로 정리할 때 | Cowork (에이전트) | 파일 여러 개, 여러 단계, 결과물이 파일 |
| 매달 실적 엑셀로 같은 형식의 경영회의 보고서를 만들 때 | 스킬 | 반복되고, 우리 회사만의 형식이 있다 |
| 매일 아침 출근 전에 경쟁사 뉴스 브리핑을 받고 싶을 때 | 예약 작업 + 스킬 | 시간은 예약이, 형식은 스킬이 |
| 매주 지점 50곳의 엑셀을 합쳐 사내 시스템에 자동으로 올릴 때 | Code (개발자와 함께) | 결과물이 계속 돌아가는 프로그램일 때 |

!!! tip "헷갈리면 세 가지만"
    파일이 필요하면 Cowork, 매번 하면 스킬, 정해진 시간이면 예약

## 어제(5회차) 질문에 대한 답

| 질문 | 답 |
| --- | --- |
| 내가 만든 스킬은 어디서 보나요? | 입력창에 /, 사용자 지정 › Skills › 내 항목, 07_내스킬/스킬목록, "내가 쓸 수 있는 스킬을 표로 보여줘" |
| 토큰(사용량)을 줄이려면? | 주제가 바뀌면 새 대화, 큰 파일은 필요한 부분만, 지시를 구체적으로 써서 다시 하기 줄이기, 안 쓰는 스킬은 끄기. 교육 계정(Team)은 쓴 만큼 돈을 더 내는 방식이 아니라 사용 한도가 있는 방식 (내 이름 › 사용량) |
| 아티팩트, 도구 호출은 무엇인가요? | 아티팩트 = 대화 옆에 뜨는 화면(대시보드, 표). 도구 호출 = 에이전트가 폴더, 검색, 커넥터를 쓴 기록 ('사용한 도구 N개') |
| 에이전트끼리 주고받는 모습을 보고 싶어요 | 오늘 2교시 '검토자 4명 동시 검증'(2-2)에서 직접 봅니다 |

## 오늘 나오는 말

| 말 | 쉽게 말하면 |
| --- | --- |
| 신사업 | 새로 시작할 사업. 공공기관, 대학은 '새로 시작할 사업이나 서비스'로 읽는다 |
| 스크리닝, 가중치 | 같은 잣대로 점수를 매겨 좁히기, 잣대마다 얼마나 중요하게 볼지 정한 비율 |
| BM 캔버스 | 사업 모델을 9칸으로 그린 한 장 그림 (누구에게, 무엇을, 어떻게 팔고, 무엇으로 버는지) |
| 중단 기준 (kill criteria) | 시작 전에 정해 두는 '이러면 접는다' 조건 3개 |
| 서브에이전트 | 하위 작업자. 큰 일을 나눠 여러 AI가 동시에 따로 맡는 것 |
| 경쟁 가설 | 한 가지 움직임에 대한 여러 해석. 각각 확신도와 확인할 신호를 붙인다 |
| C-Level | CEO, CFO 같은 최고경영진 |
| 플러그인 | 스킬, 커넥터 등 여러 기능을 한 묶음으로 설치하는 것 |

!!! note "오늘도 천천히 갑니다"
    - 단계마다 '개념 한 장 → 강사와 같이 → 화면 확인 → 다음 단계' 순서로 갑니다.
    - (선택)이 붙은 단계는 시간이 남는 분만 합니다. 못 해도 오늘 결과물에는 문제가 없습니다.
    - 막히면 그 단계는 강사 화면을 보고, 다음 단계에서 다시 같이 합니다.
