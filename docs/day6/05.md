### 3-0. 보고서양식 스킬 받아 우리 색으로

회사 공식 양식이 없으니 보고서양식을 스킬로 씁니다. 처음부터 만들지 않고, 강사가 만든 스킬을 받아 색과 글꼴만 우리 회사 것으로 바꿉니다. 스킬은 받아서 고쳐 써도 됩니다.

!!! abstract "경로"
    사용자 지정(Customize) › Skills › + 추가 › 업로드 › exec-report-style.zip

[:material-download: exec-report-style.zip](../files/exec-report-style.zip){ .md-button .md-button--primary }

1. 위 버튼으로 zip을 내려받습니다. 압축을 풀지 않습니다.
2. 사용자 지정(Customize) › Skills › + 추가 › 업로드로 올리고 켜져 있는지 봅니다.
3. 아래 지시로 우리 회사 색과 글꼴로 바꿉니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
exec-report-style 스킬의 색과 글꼴을 우리 회사 것으로 바꿔줘.
- 메인 색 #[000000], 강조 색 #[000000], 글꼴 [맑은 고딕]
- 로고: 00_회사자료/logo.png (없으면 회사명 글자로)
- 바꾼 스킬 사본을 07_내스킬에 남기고 스킬목록.md에 한 줄 추가해줘.
```

!!! example "예시, (주)한빛정밀 (가상 회사)"
    메인 #1F3B66 (네이비), 강조 #1D6FE0 (블루), 글꼴 맑은 고딕

!!! success "기대 결과"
    사용자 지정(Customize) › Skills에 exec-report-style이 켜져 있고, 색 규칙에 우리 회사 색이 들어 있다.

!!! tip "팁"
    - 회사 대표 색은 홈페이지나 로고에서 찾습니다. 로고 이미지를 올리고 "이 로고의 주요 색 hex 코드를 알려줘"라고 물어도 됩니다.
    - 이 스킬의 규칙: 제목은 결론 한 문장, 한 장에 메시지 하나, 근거는 셋까지, 숫자 표기 통일

!!! tip "테스트: 5회차 주간 업데이트에 우리 양식 입히기"
    - 바꾼 스킬이 잘 되는지 한 줄로 확인합니다. 5회차 '월요일 아침 주간 업데이트' 이야기의 마지막 단계입니다.
    - "04_보고장표의 주간업데이트_1017을 보고서양식 스킬로 우리 회사 양식 Word 1장으로 다시 만들어줘"
    - 우리 회사 색과 글꼴로 나오면 3-1로 넘어갑니다.

### 3-1. 폴더 전체를 넘겨 한 번에 지시

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
AI전략기획실 폴더 전체를 읽고(99_예시_한빛정밀 폴더는 다른 회사 예시라 빼고), 경영회의 보고용 C-Level 패키지를 06_최종패키지에 만들어줘.

① 진단리포트.docx (Word, 10쪽 이내): 산업, 경쟁사 → 밸류체인 → 핵심 과제 1-2-3
② 전략서.pptx (PPT, 12장 이내): Strategy123_전략서_v2 기반. 방금 바꾼 보고서양식 스킬 적용, 전략마다 6단 구조
   (문제 → 목표 → 전략 → 실행 과제 → KPI → 리스크). 첫 장은 결론과 요청할 결정, 마지막 장은 90일 실행 계획.
(선택) ③ 요약.xlsx (Excel): 전략별 KPI, 투자, 일정. 계산은 수식으로 남겨.

모든 숫자 옆에 원천 파일명을 달아. [확인 필요]로 남은 숫자는 채우지 말고 그대로 표시해.
파일끼리 숫자가 다르면 만들기 전에 먼저 물어봐.
만들기 전에 작업 계획과 파일별 목차를 먼저 보여주고, 내가 승인하면 시작해.
```

!!! success "기대 결과"
    - 먼저 계획과 목차가 나온다 → 승인하면 하위 작업으로 나눠 파일을 만든다.
    - 06_최종패키지에 진단리포트.docx와 전략서.pptx (Excel은 선택)

!!! tip "팁"
    - 시간이 빠듯하면 ③ Excel 줄은 지우고 보냅니다.
    - 한 번에 안 되면 파일 하나씩 따로 요청합니다.

### 3-2. 숫자 출처 일치 검증

숫자가 하나라도 어긋나면 패키지 전체의 신뢰가 무너집니다. 고치기 전에 먼저 보고받고, 어느 값이 맞는지는 내가 정합니다.

1. 다른 숫자는 원천 파일을 직접 열어 보고 어느 값이 맞는지 내가 정합니다.
2. "[지표]는 [원천 파일]의 값으로 세 파일 모두 맞춰줘"라고 지시합니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
패키지 파일들의 숫자를 서로 대조해줘.

1. 숫자마다 어느 원천 파일에서 왔는지 표로
2. 같은 지표인데 파일마다 다른 숫자 목록
3. 원천을 찾을 수 없는 숫자는 따로 표시

고치기 전에 먼저 보고해줘. 대조표는 '숫자_출처확인.xlsx'로 같은 폴더에 저장해줘.
```

!!! tip "내 눈으로 마지막 확인"
    - 전략서.pptx 제목만 넘겨 읽습니다. 하나의 이야기로 이어지나요?
    - 진단리포트 첫 쪽만 읽고 결론을 말할 수 있는지 봅니다.

### 3-3. 가져가기 키트: 07_내스킬 정리

이 교육 계정은 일정 기간 뒤 회수됩니다. 작업 폴더는 내 PC에 남지만 스킬, 지침, 예약 작업은 계정 안에 있습니다. 사본을 폴더에 남겨 두면 회사 계정으로 옮겨도 30분이면 다시 세울 수 있습니다.

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
AI전략기획실/07_내스킬에 가져가기 키트를 만들어줘.

1. 내가 만든 스킬 5개의 SKILL.md 사본을 최신으로 맞추고, 스킬마다 업로드용 zip도 만들어줘.
2. 스킬목록.md를 최신으로 고쳐줘.
3. 이 폴더의 폴더 지침과 전체 지침을 '지침_사본.md'로 저장해줘. ('전략 참모' Project를 만들었다면 그 지침도)
4. '매일 아침 이슈 브리핑' 예약 작업의 프롬프트와 설정(주기, 승인 모드)을 '예약작업_사본.md'로 저장해줘.
5. 새 계정에서 다시 세우는 순서를 '다시세우기.md'로 써줘: 스킬 업로드 → 지침 붙여 넣기 → (만들었다면) Project 만들기 → 예약 작업 다시 만들기.
```

!!! success "기대 결과"
    07_내스킬에 스킬 폴더 5개, zip 5개, 스킬목록.md, 지침_사본.md, 예약작업_사본.md, 다시세우기.md가 있다.

!!! tip "팁"
    - 전체 지침, Project 지침(만든 분만), 예약 작업 내용을 Claude가 못 읽으면, 화면에서 복사해 붙여 넣고 "이 내용을 저장해줘"라고 합니다. (화면 확인)
    - AI전략기획실 폴더 전체를 회사 드라이브나 USB에 한 번 더 백업해 두세요.

### 3-4. (선택) 발표 준비 3분

**입력, 그대로 복사해 [대괄호]만 바꿔 넣으세요**

```text
전략서.pptx로 3분 발표 원고를 써줘. 1분 결론과 요청할 결정, 1분 근거(숫자 3개), 1분 실행 계획과 리스크.
말하듯 짧은 문장으로. 그리고 이사회가 물을 예상 질문 3개와 30초 답변도 붙여줘.
```

!!! tip "팁"
    지원자 2~3명이 발표하고 피드백을 받습니다.
