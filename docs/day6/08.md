# 부록 1 — 프롬프트 카드

오늘 쓴 지시문을 한 줄로 모았습니다. 전체 문장은 해당 단계의 '입력' 상자를 보세요. 회사에 돌아가서 이 표만 보고 다시 쓸 수 있게 만들었습니다.

| 단계 | 언제 | 핵심 지시 (요약) |
| --- | --- | --- |
| 1-0 | 1교시, 아침 브리핑 확인 (5분) | 아침 브리핑 아쉬운 점 → 스킬/예약 작업 수정 |
| 1-0b | 1교시, 커넥터 연결, 캘린더 일정 → 알리는 메일 초안 (15분) | 캘린더 일정 만들기(승인) → 이번 주 일정 정리 → 그 일정을 알리는 Gmail 초안 (보내지 않음, 받은편지함 읽지 않음) |
| 1-2 | 1교시, 발산, 롱리스트 20개 | [목표] 과제별 20개 이상 [방향] 인접 시장, 역량 재활용, 고객 문제 [경쟁 가설] [기준] 평가 금지, '왜 우리가?' |
| 1-3 | 1교시, 채점, 숏리스트 3개 | 4개 기준 채점 (시장30, 역량30, 실행25, 리스크15, 1~5점 + 근거, 근거 없으면 '자료 부족' ≤3점) → Excel |
| 1-4 | 1교시, "이 스크리닝 방식을 스킬로 만들어줘" | "이 스크리닝 방식을 스킬로 만들어줘" (new-biz-screening) |

| 2-1 | 2교시, 전략서 쓰기 | Strategy 1-2-3: 과제별 문제→목표→전략→실행 과제→KPI→리스크, 앞에 결론 3줄, 요청 결정, Word 5쪽 |

| 2-3 | 2교시, (선택) 경쟁 가설과 확신도 | 경쟁사 움직임 1개 → 경쟁 가설 3개 (근거, 확신도, 바꿀 점, 확인할 신호) |
| 2-4 | 2교시, 보완, 무엇을 받아들일지는 내가 정한다 | 공통 지적 반영, 충돌은 선택지 제시 후 내 결정 → v2 + 검토 반영 기록 |
| 3-0 | 3교시, 보고서양식 스킬 받아 우리 색으로 | 보고서양식 스킬 올리기 → 색, 글꼴, 로고를 우리 회사 것으로 (사본은 07_내스킬) |
| 3-1 | 3교시, 폴더 전체를 넘겨 한 번에 지시 | 폴더 전체 → ① 진단리포트 Word ② 전략서 PPT(보고서양식, 6단) ③ 요약 Excel(수식), 원천 파일명, 숫자 다르면 먼저 묻기 |
| 3-2 | 3교시, 숫자 출처 일치 검증 | 패키지 3개 숫자 대조 (원천, 파일마다 다른 숫자, 원천 없는 숫자) "고치기 전에 먼저 보고" |
| 3-3 | 3교시, 가져가기 키트: 07_내스킬 정리 | 07_내스킬 가져가기 키트: 스킬 사본 + zip, 스킬목록, 지침_사본, 예약작업_사본, 다시세우기 |
