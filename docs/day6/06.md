# 막혔을 때

혼자 5분 넘게 막히면 손을 들어 주세요. 강사의 백업 파일, 백업 스킬로 다음 단계부터 이어 갈 수 있습니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 아침 브리핑이 없다 | 컴퓨터 꺼짐, 앱 닫힘, 실행 실패 | Scheduled 실행 기록 확인 (화면 확인) → 지금 실행 |
| 아이디어가 뻔하다 | 방향 제약이 없음 | "5개 방향마다 4개씩, 그중 1개는 업계에서 아직 안 한 것"으로 다시 지시 |
| 스크리닝 점수가 다 비슷하다 | 점수 정의가 모호함 | "1, 3, 5점 정의를 더 구체적인 숫자로 바꿔줘" → 스킬에 반영 |
| 하위 작업으로 안 나뉜다 | 화면, 계정에 따라 다름 | 새 작업 4개를 열어 검토자 한 명씩 실행 |
| 검토자 의견이 다 비슷하다 | 서로의 의견을 봤거나 역할 설명이 짧음 | "서로의 의견을 보지 마", 역할마다 관심사를 더 구체적으로 |
| 파일 3개 중 일부만 생겼다 | 작업이 커서 중간에 멈춤, 사용량 한도 | 빠진 파일만 따로 요청. 한도면 잠시 뒤 또는 강사 백업 사용 |
| PPT에 회사 양식이 안 들어갔다 | 스킬이 안 불림 | 입력창 / 로 exec-report-style을 직접 고른 뒤 "전략서.pptx에 이 양식을 적용해줘" |
| Excel에 수식이 없다 | 값으로만 넣음 | "계산되는 칸은 모두 수식으로 바꿔줘" |
| 파일끼리 숫자가 다르다 | 원천이 여러 개 | "00_회사자료의 [파일]을 유일한 원천으로 삼아 모두 맞춰줘" |
